// =============================================================================
//  Washoi / SHAG Engine -- NetRadiant entity classes
// =============================================================================
//
//  Every class below was derived from the engine's own readers, not guessed:
//
//    SpawnPointTable.ts            info_player_*, team_CTF_*spawn
//    TriggerTable.ts               trigger_teleport, trigger_push + dest classes
//    LiftSystem.ts                 func_door, func_plat, func_button,
//                                  trigger_once, trigger_multiple
//    BombSiteTable.ts              team_CTF_*flag, trigger_capture_area,
//                                  misc_capture_area_indicator, target_explosion
//    PickupTable.ts                weapon_*, ammo_*, item_armor_*, item_health_*
//    MapAreaLightEntities.ts       light_area
//    MapGodRayEntities.ts          light_volumetric, sun lights
//    MapRenderer.ts (raw path)     misc_model, sprite*, npc_sprite, info_npc,
//                                  street_lamp, build_zone, info_debris_zone
//
//  Two entity paths exist and are NOT interchangeable (docs/reference/entities.md):
//    * compiled-BSP path  -- the FPS route. Everything in the first five
//                            sections below is read out of the .bsp entity lump.
//    * raw-.map path      -- editor / MapRenderer only, listed at the bottom.
//  Only BSP-path classes affect gameplay.
//
//  SHAG coordinate convention: the .map is Z-up Quake style, converted
//  X Y Z -> X Z Y on load. Author normally.
//
//  Engine quirks that will bite you, called out inline below:
//    * BRUSH triggers/movers have NO reliable "origin". LiftSystem computes
//      AABB = submodel AABB + origin, so the engine ADDS your origin to an
//      already-world-space box. Leave origin at "0 0 0" for func_door,
//      func_plat, func_button, trigger_once and trigger_multiple.
//      trigger_teleport / trigger_push use the submodel AABB directly and
//      ignore origin entirely.
//    * The engine honours only SURF_SKY (0x4), SURF_NODRAW (0x80) and
//      CONTENTS_DETAIL (0x8000000) from the BSP. nolightmap / nonsolid /
//      trans must be expressed in the .shader, not in brush face flags.
//    * SURF_HINT and SURF_SKIP are not filtered, so hint/skip brushes are
//      meshed like anything else. Keep them out unless you mean it.
//    * max 4 lightmap styles per surface (MAX_LIGHTMAPS). A surface needing
//      more will not render correctly, and a surface must not straddle a
//      lightmap page.
// =============================================================================
