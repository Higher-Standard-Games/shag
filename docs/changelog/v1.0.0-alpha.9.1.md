# v1.0.0-alpha.9.1

**Release Date:** unreleased — living changelog

A bugfix release on v1.0.0-alpha.9.

## Changes

### Raw mouse input

The game captures the mouse with raw movement where the browser offers it
(Chrome and Edge on Windows and macOS). The view turns by the mouse's own
counts, without Windows' pointer acceleration ("Enhance pointer precision"), so
the same hand movement always turns the same amount. Firefox does not offer raw
movement and keeps the system's pointer settings; where the system refuses it,
the mouse is captured as before.
