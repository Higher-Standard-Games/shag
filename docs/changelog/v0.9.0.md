# v0.9.0 - Next-Generation Server Architecture

**Release Date:** TBD (In Development)

## Summary

Major version bump introducing the next-generation multiplayer server architecture with deterministic simulation, multi-rate tick system, and CLI-first testability.

## Goals

### Core Architecture
- [ ] Three-layer design: Simulation → Network → Game
- [ ] Deterministic simulation with fixed timestep
- [ ] Immutable state transitions
- [ ] TypeScript branded types for unit safety

### Multi-Rate Tick System
- [ ] Main orchestrator with subsystem independence
- [ ] Configurable tick rates per subsystem (FPS: 125Hz, RTS: 30Hz)
- [ ] Performance budgeting for mobile/browser
- [ ] Spiral of death prevention

### Network Layer
- [ ] Server-authoritative model
- [ ] Client prediction with input buffering
- [ ] Binary serialization (MessagePack + custom hot paths)
- [ ] Delta compression for bandwidth optimization

### Testability
- [ ] CLI commands for every subsystem
- [ ] Deterministic replay system
- [ ] Headless match simulation
- [ ] Fuzz testing and regression tests

## Breaking Changes

> [!WARNING]
> This version will introduce breaking changes to the network protocol.
> Old clients will not be compatible with v0.9.0 servers.
