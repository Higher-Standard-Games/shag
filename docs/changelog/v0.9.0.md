# v0.9.0 - Next-Generation Server Architecture

**Release Date:** 2026-02-15

## Summary

Major version bump introducing the next-generation multiplayer server architecture with deterministic simulation, multi-rate tick system, CLI-first testability, Q3-faithful collision physics, and developer tooling.

## Implemented Features

### Core Architecture ✅

- [x] Three-layer design: Simulation → Network → Game
- [x] Deterministic simulation with fixed timestep (125Hz default)
- [x] Copy-on-Write (COW) WorldState for immutable state transitions
- [x] TypeScript branded types utility (`BrandedTypes.ts`) for unit safety
- [x] Server-authoritative collision with Q3-style physics

### Multi-Rate Tick System ✅

- [x] Main orchestrator at configurable tick rates
- [x] Subsystem tick independence (FPS: 125Hz, RTS: 30Hz configurable)
- [x] Performance budgeting and spiral-of-death prevention
- [x] Benchmarked: 64 players at 22,000+ ticks/sec

### Network Layer ✅

- [x] Server-authoritative model with client prediction
- [x] Input buffering and command acknowledgment
- [x] Binary serialization with MessagePack
- [x] Delta compression for bandwidth optimization
- [x] Snapshot interpolation for smooth rendering
- [x] WebTransport (QUIC/UDP) implementation ready
- [x] Drift-compensated server tick loop
- [x] Frame-synchronized reconciliation to eliminate jitter
- [x] Input queue to prevent last-writer-wins loss

### Client-Side Prediction ✅

- [x] BSP collision world injection into prediction simulation
- [x] Smooth correction for small prediction errors
- [x] Snap correction for large discrepancies
- [x] Fixed spawn point Y-offset (origin vs feet level)
- [x] Reconciliation error: 0.0 units (was 24-40 units)
- [x] Skip legacy reconciliation in V2 mode

### Lag Compensation ✅

- [x] Server-side entity rewind for hit detection
- [x] History buffer with configurable depth
- [x] Q3-to-CS2 evolution research documented

### Testability ✅

- [x] CLI headless server (`npm run net:server`)
- [x] Deterministic replay system with verification
- [x] Fuzz testing command for protocol robustness
- [x] `server:tick` - Single tick simulation test
- [x] `server:bench` - Performance benchmarking

### V2NetworkClient - Q3-Style Prediction ✅

- [x] New prediction client replacing NetworkGameHost prediction
- [x] Same FPSMovementProfile on client and server for physics parity
- [x] Input history with replay on server snapshot
- [x] Wait for valid server position before FPSController init
- [x] `docs/research/V2_NETWORK_CLIENT.md` design document

### Collision & Physics ✅

- [x] Q3-style ground plane clipping before stepSlideMove (PM_GroundMove parity)
- [x] Remove wall-climb prevention from slideMove (caused slope stuck bug)
- [x] Q3-faithful clip-plane thresholds (0 instead of 0.1)
- [x] Single physics engine via FPSMovementProfile (eliminated AdvancedCharacterController)
- [x] Walljump ground clearance trace from feet level
- [x] Shared CollisionWorld + death spiral fix

### Developer Tooling ✅

- [x] Developer bar (FPS/PING/SPEED/POS status bar via `developer 1`)
- [x] Speed display uses position-delta for accuracy
- [x] Developer cvar registration fix (ESM-compatible imports)
- [x] Clickable help commands and log forwarding in dev bar

### Camera & Movement ✅

- [x] Slide/ledge camera uses absolute pitch offsets instead of per-frame accumulation
- [x] Camera effect phases and developer bar integration

## Breaking Changes

> [!WARNING]
> This version introduces breaking changes to the network protocol.
> Old clients will not be compatible with v0.9.0 servers.

- Network protocol uses new binary format
- Simulation runs at fixed 125Hz (was variable)
- WebTransport replaces WebSocket for UDP benefits
- `AdvancedCharacterController` removed — all physics via `FPSMovementProfile`

## Known Issues

- LightGrid dimension mismatch warnings on some FBSP maps
- Debug logging is verbose (will be reduced for release)
