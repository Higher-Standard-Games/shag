# v0.5.0 - Camera System Refactoring

**Release Date:** January 1, 2026

## Summary

Major refactoring of the camera system to support multiple swappable camera controllers. The engine now cleanly separates camera control logic from game-specific input handling, enabling per-map camera modes and runtime controller switching.

## Major Features

### Modular Camera Controller System
- **ICameraController interface** - Clean abstraction for camera behaviors
- **CameraSystem singleton** - Central manager for controllers, modes, and presets
- **Runtime controller switching** - Hot-swap between camera types via console or code
- **Per-map camera mode** - Maps can specify camera controller in worldspawn entity

### Camera Controllers

| Controller | Description | Controls |
|------------|-------------|----------|
| **IsometricController** | RTS-style pan/drag camera | Left-click drag to pan, edge scrolling |
| **FPSController** | First-person camera | W/S move, A/D turn, Q/E strafe, right-click look |
| **SideScrollController** | 2D platformer camera | WASD to pan, true camera panning |
| **FollowController** | Target following camera | Attach to TransformNode with offset |

### Console Commands

```bash
camera controller <type>    # Switch controller (isometric|fps|sidescroll|follow)
camera controllers          # List registered controllers
camera info                 # Show camera status
camera fov <radians>        # Set field of view
camera pos <x> <y> <z>      # Teleport camera
camera target <x> <y> <z>   # Set camera target
camera reset                # Reset to default isometric view
```

## Features

- **GameInputHandler** - Separated game-specific click logic from camera controller
- **Configurable FOV** - FPS controller supports configurable field of view
- **Right-click mouse look** - FPS controller works without pointer lock
- **Per-map camera settings** - Worldspawn `camera_controller` property

## Fixes

- Fixed camera angle override that prevented non-isometric controllers from working
- Fixed FPS controller initial orientation (now looks forward, not at ground)
- Fixed SideScrollController movement axes and directions
- Fixed camera restoration when switching back to isometric from FPS

## Technical

- Removed legacy `RTSCameraController.ts` (replaced by `IsometricController`)
- Camera controllers now properly attach/detach input handlers
- `CameraSystem` stores original camera for restoration after FPS mode
- `MapRenderResult` now includes `cameraController` property

## Breaking Changes

- `RTSCameraController` removed - use `IsometricController` via `CameraSystem`
- Game click handling moved from camera controller to `GameInputHandler`

## Migration

```typescript
// Old
import { RTSCameraController } from "./engine/camera/RTSCameraController";
new RTSCameraController(scene, camera, canvas);

// New
import { CameraSystem, IsometricController } from "./engine/camera";
const cameraSystem = CameraSystem.getInstance();
cameraSystem.init(scene, canvas);
cameraSystem.setCamera(camera);
cameraSystem.registerController("isometric", new IsometricController());
cameraSystem.setController("isometric");
```
