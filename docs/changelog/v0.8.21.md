# v0.8.21 - 2026-01-20

**Release Date:** 2026-01-20

## Summary

Added crouchslide movement mechanic with camera effects, crouch collision, favicons, and dynamic page titles with random taglines.

## Changes

### New Features

- **Crouchslide Movement System**: Sprint → Crouch to slide
  - Requires 425+ speed (sprint only, won't trigger when walking)
  - 800ms slide duration with 1500ms cooldown
  - Speed preserved for 400ms, then decays to crouch walk speed
  - Jump cancel available after 400ms grace period
  - Boost jump: hold jump during slide for 1.3x velocity boost
  - ADS automatically disabled during slide

- **Slide Camera Effects**
  - Camera tilts up ~12° during slide (look-up effect)
  - Smooth 400ms ease-in / 400ms ease-out using smoothstep
  - Vertical look axis locked during slide animation
  - Walk bob disabled during slide for stability

- **Regular Crouch System**
  - Camera lowers 20 units when crouching
  - Crouch walk speed: 50% of normal (`cl_crouchmult`)
  - Crouch forces walk mode (no sprinting while crouched)
  - Instant camera response on key press

- **Crouch Collision**
  - Player bounding box shrinks when crouching/sliding (56 → 36 units)
  - Ceiling check prevents standing up when blocked
  - `getCrouchState()` for server-side hitbox sync

- **Debug Bbox Visualization** (Developer)
  - `cl_debugbbox 1` shows wireframe of player collision box
  - Configurable offset via `cl_debugbbox_offset` (0-500 units)
  - Correctly shows Q3-style crouch: feet stay on ground, head lowers

- **Favicons & PWA Support**
  - Apple touch icon, PNG favicons, favicon.ico
  - Updated site.webmanifest with proper branding

- **Dynamic Page Title**
  - Random SHAG tagline shown in browser tab
  - Updates via `EngineVersion.setDocumentTitle()`

### Improvements

- **Ctrl+Key Shortcut Blocking**: All Ctrl+key browser shortcuts blocked when pointer locked (fixes Ctrl+W closing tab)
- **PlayerState Extended**: Added `isSliding` flag for viewport effects
- **Speed Display**: Shows actual movement speed (position-based) instead of input velocity
- **Wall Jump Tuning**: Speed-based push direction (80% min horizontal, 20% vertical boost at low speed)
- **Wall Jump Min Height**: Increased from 24 → 32 units to prevent accidental triggers near ground
- **Wall Jump Eye-Level Check**: Skip wall jump on low obstacles (fences/railings) by tracing at eye level
- **Ceiling Collision**: Zeroes vertical velocity immediately on ceiling hit (no more floating)
- **Anti-Stuck Collision**: Epsilon bbox shrink (0.125u margin) + gravity escape when stuck in 3+ planes

### Technical Details

- **MovementVars.ts**: Added 10 crouchslide cvars (`sv_slide*`)
- **FPSController.ts**: `updateCrouchslide()` state machine, `getCurrentHeight()`, `getCrouchState()`, `updateDebugBbox()`
- **PlayerState.ts**: Added `isSliding` optional field
- **WalkBobEffect.ts**: Disabled bob when sliding
- **EngineVersion.ts**: Dynamic page title with random taglines
- **index.html**: Favicon links and webmanifest

### Console Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `sv_slide` | 1 | Enable crouchslide (0/1) |
| `sv_slideDuration` | 800 | Max slide time (ms) |
| `sv_slideMinSpeed` | 425 | Min speed to trigger |
| `sv_slideCooldown` | 1500 | Cooldown between slides (ms) |
| `sv_slideSpeedMultiplier` | 1.2 | Entry speed boost |
| `sv_slideJumpBoost` | 1.3 | Boost jump multiplier |
| `cl_debugbbox` | 0 | Show player collision box wireframe |
| `cl_debugbbox_offset` | 100 | Distance ahead to show debug box (units) |

### Collision Physics Overhaul

- **Patch/Mesh Collision Support**: Full collision detection for curved surfaces (bezier patches) and triangle soup meshes
  - `PatchTessellator.ts` - Pure math bezier tessellation for collision geometry
  - `traceTriangleSwept()` - Swept AABB vs triangle using separating axis projection
  - 2D Box-Triangle overlap test for accurate corner/edge collision

- **Collision Robustness Fixes**
  - **LOD 5 Tessellation**: Increased collision mesh density to prevent pass-through on curved surfaces
  - **Horizontal Contour Sliding**: Project velocity onto wall's horizontal curve to prevent climbing
  - **Depenetration Nudge**: Active push-out (0.05 units) when stuck in geometry
  - **Normal Flipping**: Two-sided collision for patches (detects back-face entry)
  - **StartSolid Handling**: Epsilon relaxation (0.001) for grazing slides
  - **Wall Climb Prevention**: Zero upward velocity when hitting steep walls (slope < 0.7)

- **CharacterController Refactor**: Delegates all movement resolution to `CollisionManager.slideMove()`
  - Uses robust Quake 3-style multi-plane clipping (up to 5 planes)
  - Proper overbounce handling and crease sliding
