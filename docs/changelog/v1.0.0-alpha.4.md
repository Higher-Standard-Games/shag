# v1.0.0-alpha.4

**Release Date:** October 25, 2026

## Changes

- The Play page prepares common assets and the selected room map in the
  background, with a compact download indicator beside the version and links.
  Joining shares in-flight downloads and gives required assets priority.
  The download popup sits clear of its button and shares the settings popup's
  cut-corner yellow panel, heading, close control and raised-key styling;
  its footer button shares the neighboring buttons' font size and padding.
  Its details list the prepared packages and their queued, active or ready status.
  Clicking outside the popup dismisses it.
- Downloaded packages with published content hashes persist in browser storage
  across reloads. Unchanged media survives code updates, while changed or corrupt
  packages are refreshed. Unavailable browser storage falls back to HTTP.
- Cancelling optional downloads and immediately joining a match cannot strand
  a replacement request for the same package. Cache eviction preserves smaller
  packages that still fit after a large package is removed.
- Slow initial loading no longer trips the two-minute spectator-only server
  timeout. Admitted players receive a finite loading allowance, and terminal
  connection failures offer a return to the lobby instead of a frozen match.
- **Water reflections are captured behind the loading screen.** Each pool's
  reflection cubemap renders the map six times, and it was captured the first
  time the pool came into view during play: a hitch the moment you turned
  towards water. Map loading now captures every pool's reflection before the
  loading screen closes.
- **Shaders can reflect the map with `map $cubemap`.** A stage with
  `map $cubemap`, the Qfusion convention, reflects a cubemap of the map
  captured where the surface stands, without the object itself in it. Curved
  models with smooth normals become curved mirrors; a flat surface reflects its
  room, projected so the reflection holds still as you move. Mixed with other
  stages it draws as its own pass, blended by its `blendFunc`, so
  `blendfunc add` puts a shine over a lightmapped surface. Captures (up to
  eight a map) are taken behind the loading screen. Before, `$cubemap` was not
  understood as a stage source.
