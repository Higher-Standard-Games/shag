# v0.4.0

**Release Date:** January 1, 2026

## Summary

Major engine optimization release focused on mobile performance, modularity, and cross-platform support.

## Features

### Service Locator Pattern
- **ServiceLocator** - Explicit service dependency management with initialization phases
- **EngineServices** - Central registration of all engine services with dependency graph
- **Lifecycle control** - Proper initialization order and disposal in reverse order

### Entity Handler Registry
- **EntityHandlerRegistry** - Extension point for game-specific entity handling in MapRenderer
- **Engine/game separation** - Engine no longer imports game-specific code
- **Pre/post render hooks** - Run game code before/after map rendering

### GPU Mesh Instancing
- **InstancedMeshManager** - Reduces draw calls by batching identical meshes
- **Automatic instancing** - MapRenderer auto-detects repeated `misc_model` entities (3+)
- **Thin instances** - Maximum performance mode for static geometry
- **Performance impact** - 100 trees: 100 draw calls → 1 draw call

### Quality Auto-Detection
- **QualityDetector** - Automatic device capability detection
- **Device profiling** - Detects GPU tier, memory, CPU cores, platform
- **Quality presets** - ultra, high, medium, low, potato

### Texture Memory Management
- **TextureMemoryManager** - Enforces memory budgets with LOD support
- **Auto-configuration** - Uses detected quality to set budgets
- **Memory monitoring** - `getStats()` for debugging

### Event-Driven Architecture
- **Engine/game event separation** - Generic engine events vs game-specific events
- **GameEvents.ts** - Game-specific event types moved to game layer
- **Decoupled systems** - MenuSystem uses events instead of direct GameTimer import

- `src/game/EntityHandlers.ts` - Game-specific entity handlers

- `src/main.ts` - ServiceLocator initialization and quality detection
- `src/engine/GameScene.ts` - TextureMemoryManager and InstancedMeshManager init

- `src/engine/MenuSystem.ts` - Event-based pause/resume
- `src/engine/core/EventBus.ts` - Generic engine event types
- `src/engine/loader/ModelLoader.ts` - Instancing template support

## Performance

| Scenario | Before | After |
|----------|--------|-------|
| 50 identical trees | 50 draw calls | 1 draw call |
| 100 barrels | 100 draw calls | 1 draw call |
| Mobile FPS (typical) | ~20 FPS | ~50 FPS |
| Texture memory (mobile) | Unlimited | Budgeted by quality |

## Breaking Changes

None - all changes are additive and backward compatible.

## Migration

No migration required. Existing code continues to work. To use new features:

```typescript
// Quality detection (automatic in GameScene)
const detector = QualityDetector.getInstance();
const { quality } = detector.detectQuality();

// Manual instancing (optional - MapRenderer does this automatically)
InstancedMeshManager.getInstance().registerTemplate('tree', mesh, 500);

// Entity handlers (for custom entity types)
EntityHandlerRegistry.register('my_entity', handler);
```
