# v1.0.0-beta.8

**Release Date:** unreleased — living changelog

## Changes

- Watched-player death cameras use presentation time, keeping the audio preparation and encoded video on the same camera path even when shader compilation pauses rendering.
- Shared bullet-hole and pellet materials rebuild after scene replacement or material disposal, preventing a later video export from binding a previous scene's shader resources.

- Highlight video export: choose a 1/2/3-minute reel, generate 1080p60 H.264/AAC MP4 with game audio and reel cards, then download the finalized file. An isolated WebGL2 session preserves the original viewer; fixed frame timestamps, encoder backpressure, bounded temporary storage and two-pass sound/camera agreement protect offline rendering. Available in release builds with `developer 0`, through `videoexport` or the Demos highlight menu. Video rendering, audio mixing, encoding and temporary storage run locally in the user's browser.
- Demo rewinds reset sound-variant counters; manual rendering waits for lazy teleport effects. A superseded weapon-model load cannot finish setting up a disposed viewmodel.
- Highlight export uses the shared yellow dialog style and a full-width menu action. Optional background music includes every packaged OST track, a game-audio-only default and a song start timestamp; music keeps its tempo through cuts and slow motion.
- Export cancellation releases a renderer waiting on fonts. Failed temporary-video deletion preserves the result for download or another discard attempt. Periodic map sounds use repeatable presentation timing in the isolated exporter while live play retains its wall timers.
- Selected export music uses fixed 80% gain, with game effects at 35% of their game-only level underneath it. The highlight-menu export label is reduced to 22 px.
- Third-person guns retain their imported hierarchy, skin joints and muzzle transforms in a hand attachment, including parked weapons and the winner showcase. Animation visibility changes no longer restart locomotion over an active attack.
- Hitscan effect resources rebuild when a map reload clears their meshes in the same scene. This restores Voltaic beams and the associated procedural effects in the video export's encoded pass and same-scene playback restarts.

- The live local Voltaic beam traces the current view each rendered frame instead of holding server endpoints between packets. Predicted player contacts stop at the nearest rendered hitbox before map geometry; damage stays server-authoritative, and remote/demo beams retain their server endpoints.
- Camera-dependent fog shader materials declare their dynamic uniforms before the first WebGPU snapshot recording, so procedural effects and map shaders refresh from the first replay. Other materials retain bounded change detection and snapshots remain enabled.
- `loadout status` reports the selected kit, last server weapon state, local inventory, HUD, displayed weapon/readiness/switch state and viewed-player identity without changing gameplay, to diagnose intermittent missing-kit reports.

- Refresh the loose Washoi brand logo with the supplied fixed PNG.

- Accept `target_push` point entities as jumppad targets, restoring DM3's `j1_2` pad in server movement and client prediction.

- Animated shader stages keep updating from their first WebGPU snapshot recording, including teleporter sparkle rotation, stretch and brightness. Static materials retain their cached rendering path.
- Inline door decals honor authored image paths, blending, vertex alpha and polygon offset, fixing DM3 number panels and teleporter direction signs.
- Package the supplied DM1/DM3 levelshots with the standard JPEG menu previews.

- Coplanar map decals use constant depth bias as well as slope bias, preventing missing strips when viewed straight on. Multiplicative overlays receive the same depth separation.

- Add Washoi DM1 and DM3 to Duel and FFA, and refresh DM5 and DM7 from the updated compiled maps. DM7 remains FFA-only. Per-map texture banks include the author-corrected DM1/DM3 decal media and compatibility aliases for compiled model-material paths.
