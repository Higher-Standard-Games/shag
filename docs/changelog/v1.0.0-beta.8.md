# v1.0.0-beta.8

**Release Date:** unreleased — living changelog

## Changes

- Development-only highlight video export: choose a 1/2/3-minute reel, generate 1080p60 H.264/AAC MP4 with game audio and reel cards, then download the finalized file. An isolated WebGL2 session preserves the original viewer; fixed frame timestamps, encoder backpressure, bounded temporary storage and two-pass sound/camera agreement protect offline rendering. Accessible through `developer 1` and `videoexport`, or the development Demos highlight menu. Public release acceptance is still in progress.
- Demo rewinds reset sound-variant counters; manual rendering waits for lazy teleport effects. A superseded weapon-model load cannot finish setting up a disposed viewmodel.
- Highlight export uses the shared yellow dialog style and a full-width menu action. Optional background music includes every packaged OST track, a game-audio-only default and a song start timestamp; music keeps its tempo through cuts and slow motion.
- Export cancellation releases a renderer waiting on fonts. Failed temporary-video deletion preserves the result for download or another discard attempt. Periodic map sounds use repeatable presentation timing in the isolated exporter while live play retains its wall timers.
