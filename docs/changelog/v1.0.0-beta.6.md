# v1.0.0-beta.6

**Release Date:** unreleased — living changelog

## Changes

- Controller focus starts on the main menu's left rail and on map voting when entering a room, falling back to Ready after a vote. The pause menu walks its items in a fixed Up/Down order, and controller-focused raised keys use the same highlighted face as keyboard focus.

- Hardened controller handoffs and menu focus after code review: neutral checks use the configured radial stick dead zones, blocked gameplay actions cannot stay held, and releasing one device does not release an action or scoreboard still held by another. Dropdowns close with their settings page; dialog focus restores safely; Back takes priority over simultaneous Confirm. A failed controller subscriber releases gameplay without stopping gamepad polling. Spectator prompts reflect remaps and swapped sticks when returning to play.

- Fixed Controller stick-tuning fields running together: the controls use the shared settings spacing, and On/Off rows stay compact on wide screens instead of stretching across the card and overlapping the next label.

- Added controller input selected by a controller button on the loading screen, with an explicit input switch in Settings. Plugging in a pad does not change modes. The existing menus support directional selection and visible focus; the Controller settings tab adds an Xbox diagram, Standard/Bumper jump presets, editable bindings, live readings, and stick tuning. Controller bindings stay separate from keyboard edits and follow the account. Gameplay includes arbitrary-angle movement, frame-independent looking, ADS/aim assist, match actions and spectator controls, with neutral-input checks around menus, focus loss and reconnects. The implementation and hardware acceptance plan is in `docs/research/controller.md`.
