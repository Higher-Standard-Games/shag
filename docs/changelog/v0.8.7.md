# v0.8.7 - PVS Culling

**Release Date:** January 4, 2026

## New Features

### PVS (Potentially Visible Set) Culling
Real-time visibility culling using precomputed BSP visibility data:

```
pvs on      - Enable PVS culling
pvs off     - Disable PVS culling
pvs status  - Show detailed statistics
pvs cluster - Show current cluster info
pvs debug   - Toggle debug overlay
```

### How It Works
1. BSP maps are divided into "clusters" (leaf nodes of the BSP tree)
2. Each cluster has a precomputed bitfield showing which other clusters are visible
3. At runtime, the system finds which cluster the camera is in
4. Only meshes belonging to visible clusters are rendered

### Performance Optimizations
- **Cached `hasPVS`** - Computed once at construction, not every frame
- **Tuple-based sampling** - Avoids Vector3 allocations during mesh registration
- **Cached stats** - Visibility counts computed during update loop, not separately
- **Conditional visibility updates** - Only sets `mesh.isVisible` when changed
- **Babylon render loop integration** - Uses `scene.onBeforeRenderObservable` instead of `requestAnimationFrame`
- **Reverse cluster→mesh map** - `Map<cluster, meshes[]>` for faster lookups

### Technical Details

#### New Files
- `src/engine/loader/bsp/PVSCuller.ts` - PVS culling manager

#### PVSCuller Features
- `registerFromWorldMesh(mesh)` - Auto-assign meshes to clusters via bounding box sampling
- `update(cameraPosition)` - Update visibility based on camera position
- `getStats()` - Get culling statistics (visible/culled mesh counts)
- `findClusterAtPosition(pos)` - Find which cluster a point is in
- `getVisibleClusters(cluster)` - Get all clusters visible from a given cluster

#### Mesh-to-Cluster Assignment
Each mesh is assigned to ALL clusters its bounding box intersects by sampling:
- 8 corners of the bounding box
- Center point
- 6 face centers (15 sample points total)

### Debug Overlay
`pvs debug` shows real-time stats:
- Current cluster
- Visible clusters / total clusters
- Visible meshes / total meshes
- Culled percentage
- Update time (ms)

## Usage

```bash
# Load a map
map wdm1

# Enable PVS culling
pvs on

# Check statistics
pvs status

# Toggle debug overlay
pvs debug

# Disable when done
pvs off
```

## Performance Impact

PVS culling can significantly reduce draw calls by hiding geometry that cannot possibly be seen from the current camera position. The effectiveness depends on the map's cluster layout and visibility precomputation.
