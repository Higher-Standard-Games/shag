# v0.8.14 - Documentation & Console Improvements

**Release Date:** 2026-01-08

## Summary

Major documentation overhaul with VitePress-powered manual, MIT license addition, and improved console command help/autocomplete.

## Changes

### Documentation

- **Comprehensive manual documentation** - 45+ markdown files covering all engine systems
  - Introduction, Getting Started, Tutorials, Guides, Tools, Deployment, FAQ, Contributing
  - Beginner/Intermediate/Advanced tutorials
  - Recipes section with quick how-tos

- **VitePress documentation site** - Modern documentation with full sidebar navigation
  - Custom theme with Inter + JetBrains Mono fonts
  - Local search enabled
  - 64px logo, Nunito font, orange/teal colors matching HSG site

- **MIT License** - Added MIT license to repository root and updated documentation

- **Refined messaging** - Cross-platform WebGL engine with idTech3 tooling integration
  - Clarified idTech3 asset loading vs full compatibility
  - Added AI-agent ready and headless mode messaging

### Console Improvements

- **Improved help command** - All commands now have proper descriptions
  - Added missing definitions for: `pk3`, `mem`, `scene`, `fog`, `ui`, `hud`, `game`, `con_size`, `console_debug`
  - Complete subcommand documentation for `map`, `debris`, and other commands
  - Better category grouping (System, Debug, Game)

- **Enhanced tab autocomplete**
  - Common prefix completion (fills shared beginning of matches)
  - Double-tap to list all matches (terminal-style behavior)
  - Cycling through suggestions still works as fallback

- **Case-insensitive commands** - Command names normalized to lowercase for consistent lookup

### Housekeeping

- Removed duplicate `CHANGELOG.md` from repo root
- Moved `FEATURES.md` to `docs/`
- Added VitePress cache to `.gitignore`
