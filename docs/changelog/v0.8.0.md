# v0.8.0 - Quake 3 / Warsow Map Support

**Release Date:** January 2, 2026

## Summary

Major release adding support for loading and rendering Quake 3 and Warsow BSP maps with textures from PK3 archives. This enables importing existing game maps into the engine.

## Features

### PK3 Archive System

- **Multi-path PK3 loading** - Search multiple directories for PK3 files
- **PK3 indexing** - Fast file-to-package lookup with localStorage caching
- **Auto-load required PK3s** - Automatically load texture PK3s needed for a map
- **Texture loading** - Load TGA, JPG, PNG, KTX textures from PK3 archives

### BSP Map Loading

- **IBSP format** - Quake 3 Arena maps (v46/v47)
- **FBSP format** - Warsow maps (v1)
- **Face types** - Polygons, bezier patches, mesh faces
- **Texture mapping** - UV coordinates with proper Q3→Babylon.js conversion
- **Separate mesh per texture** - Optimal for mobile rendering

### Q3 Shader System

- **Shader file parsing** - Parse .shader files from PK3s
- **Shader registry** - Central lookup with underscore→slash name conversion
- **Material properties** - cull, blendFunc, alphaFunc, polygonOffset
- **Alpha testing** - Proper cutout transparency for fences, leaves, etc.
- **Double-sided rendering** - `cull none` support

### Console Commands

#### PK3 Commands
- `pk3 load <file>` - Load a PK3 archive
- `pk3 list [filter]` - List files in loaded PK3s
- `pk3 path <path>` - Add search path for PK3s
- `pk3 index build` - Build file→package index
- `pk3 index find <file>` - Find which PK3 contains a file
- `pk3 index search <term>` - Search indexed files
- `pk3 index clear` - Clear the index

#### BSP Commands
- `bsp load <mapname>` - Load BSP from map PK3
- `bsp info` - Show BSP details
- `bsp render` - Render BSP to scene
- `bsp clear` - Remove BSP from scene
- `bsp textures` - List textures used by map
- `bsp loadrequired` - Auto-load PK3s needed for textures
- `bsp applytextures` - Apply textures to rendered meshes

#### Shader Commands
- `shader load` - Load shaders from all PK3s
- `shader list [filter]` - List loaded shader names
- `shader info <name>` - Show shader definition
- `shader resolve <name>` - Show resolved material properties
- `shader clear` - Clear shader registry

## Quick Start

```bash
# Load a Warsow map with full textures
pk3 path game/basewsw/
pk3 index build
scene empty
bsp load wdm11
bsp loadrequired
shader load
bsp render
bsp applytextures
```

## Known Issues

- Alpha blending may not work correctly for some transparent textures
- Some decals may still z-fight
- Lightmaps are parsed but not yet applied to materials

## Technical Details

### New Files
- `src/engine/loader/PK3Loader.ts` - PK3 archive loading
- `src/engine/loader/PK3Index.ts` - File indexing system
- `src/engine/loader/PK3TextureLoader.ts` - Texture loading from PK3
- `src/engine/loader/BspLoader.ts` - BSP file parsing
- `src/engine/loader/BspMeshBuilder.ts` - Mesh generation
- `src/engine/loader/Q3ShaderParser.ts` - Shader file parsing
- `src/engine/loader/Q3ShaderRegistry.ts` - Shader lookup
- `src/engine/loader/Q3ShaderTypes.ts` - Type definitions

### Architecture
- Singleton pattern for PK3Loader, PK3Index, Q3ShaderRegistry
- Separate mesh per texture group for efficient rendering
- Incremental shader loading from multiple PK3s
- localStorage caching for PK3 index
