# v0.8.1 - BSP Rendering Fixes

**Release Date:** January 3, 2026

## Summary

Patch release fixing transparency, alpha blending, and adding lightmap support for BSP maps.

## Bug Fixes

### Alpha Blending Material Timing
- Fixed issue where transparent textures didn't render correctly when shaders loaded after mesh creation
- Material alpha properties are now reapplied after texture loading
- Properly sets `texture.hasAlpha = true` for textures with alpha channels

### Double Extension Texture Path Bug
- Fixed texture paths incorrectly getting double extensions (e.g., `.tga.tga`)
- Added extension stripping before trying alternative extensions

### Transparency Sorting
- Improved sorting for overlapping transparent meshes (halos, fences, etc.)
- Added `alphaIndex` property to transparent meshes for proper render order
- Additive blending (halos, lights) now renders last with higher alpha index
- Enabled `mustDepthSortFacets` for transparent meshes

## New Features

### Lightmap Application
- Added `BspMeshBuilder.applyLightmaps()` static method
- Supports two rendering modes:
  - **Desktop mode**: Uses `lightmapTexture` for high-quality lightmap blending
  - **Mobile mode**: Uses `ambientTexture` for better performance
- Configurable intensity multiplier

### Console Commands
- `bsp applylightmaps [mobile|desktop] [intensity]` - Apply lightmaps to rendered BSP

## Technical Details

### BspMeshBuilder Changes
- Extended `TextureGroup` interface to track lightmap indices per group
- Added primary lightmap detection (most commonly used lightmap per texture group)
- Lightmap index stored in mesh metadata for later application

### Material Improvements
- Transparent meshes now use proper Babylon.js alpha modes
- Alpha testing materials correctly configure `transparencyMode` and `alphaCutOff`
- Additive blending correctly uses `ALPHA_ADD` mode

## Usage

```bash
# Full BSP loading with lightmaps
pk3 path game/basewsw/
pk3 index build
scene empty
bsp load wdm11
bsp loadrequired
shader load
bsp render
bsp applytextures
bsp applylightmaps desktop 1.5
```

## Known Issues

- Decal z-fighting may still occur in some cases
- Lightmaps may appear too bright or dark depending on the map
