# v0.9.2 - Network Polish & Interpolation

**Release Date:** 2026-02-18

## Summary

Network layer polish: time-based entity interpolation via SnapshotBuffer, WebTransport dual-channel (reliable streams + unreliable datagrams), command redundancy for packet loss resilience, decoupled snapshot rate, client-predicted explosions with server dedup, visual reconciliation smoothing, and a Quake 3–style NetGraph overlay.

## Changes

### Network Transport

- **WebTransport dual-channel** — Reliable messages use unidirectional QUIC streams (auth, welcome, game events); unreliable uses QUIC datagrams (input commands, snapshots)
- **`readIncomingStreams()`** — Client reads incoming server-initiated unidirectional streams, reconstructing chunked messages for reliable delivery
- **Command redundancy buffer** — Client sends last 3 commands per packet; server deduplicates by sequence number to prevent triple-processing
- **Server input deduplication** — `handleInput()` rejects commands with `seq <= lastInputSeq` to guard against redundant command replay

### Snapshot & Interpolation

- **Configurable snapshot rate** — `--snapshotrate` CLI flag and `GameServerConfig.snapshotRate` decouple snapshot broadcast from tick rate (default 30Hz vs 125Hz tick)
- **`SnapshotBuffer`** — New time-based interpolation buffer for remote entities: auto-adjusting interp delay based on snapshot arrival jitter, linear interpolation between snapshots, velocity-based extrapolation on packet loss
- **`cl_timenudge` / `cl_interp` CVars** — Fine-grained control over interpolation delay (Q3/Source-style)
- **RemotePlayerRenderer V2** — Refactored to `pushSnapshot()` + `render()` architecture, decoupling snapshot ingestion (~30Hz) from rendering (per-frame interpolation via SnapshotBuffer)

### Client Prediction

- **Visual reconciliation smoothing** — `V2NetworkClient.visualOffset` absorbs reconciliation corrections and decays them over ~83ms instead of teleporting the camera
- **`getVisualPosition()` / `decayVisualOffset()`** — Smoothed camera position API for jitter-free rendering
- **Client-predicted explosions** — Rockets/grenades/plasma explode immediately on client impact; server events are deduplicated via `ProjectileManager.hasRecentPrediction()` (position + defId matching within tolerance)

### Developer Tools

- **NetGraph overlay** — Quake 3 / Source-style `cl_netgraph` CVar (0=off, 1=text, 2=text+graph) showing ping, snapshot rate, command rate, reconciliation count, and interp delay with rolling history graphs

### Bug Fixes

- **Player rotation sync** — Transmit yaw/pitch rotation in `BinaryProtocol` via flag `0x08` for correct remote player facing direction
- **Server-side grenade physics** — Fix grenade bounce, timeout, and gravity logic on server
- **Solid shockwave disc** — Render explosion shockwave as solid disc instead of wireframe
- **`engine.json` cleanup** — Remove hardcoded `title` field; game title now sourced from `game.json` via `GamePaths.init(gameTitle)`

## Known Issues

- LightGrid dimension mismatch warnings on some FBSP maps
