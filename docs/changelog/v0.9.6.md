# v0.9.6

**Release Date:** 2026-02-23

## Summary

Complete FPS HUD overhaul: new "Washiki" manga-themed UI framework with custom fonts, value-bar widgets, weapon rack, frag counter, scoreboard, chat, pickup toasts, damage indicators, kill feed, death screen, and ESC pause menu. Full CSS-driven theming with scalable UI.

## Changes

### HUD Framework (FPSHud.ts)

- **New HUD system** — Replaced `MatchHUD.ts` with comprehensive `FPSHud.ts` (~2400 lines); singleton architecture with 9 anchor areas (top-left/center/right, left/center/right, bottom-left/center/right)
- **Washiki Theme CSS** — 1800+ line manga-panel themed stylesheet (`WashikiTheme.css`) with CSS custom properties, glassmorphism panels, corner brackets, neon glows, and `--ui-scale` multiplier
- **Custom fonts** — Orbitron (display) and Rajdhani (body) loaded locally via `UITheme.loadFont()`, bundled in `public/engine/fonts/`

### HUD Widgets

- **Health & Armor bars** (`FPSValueBar`) — Horizontal bars with icon, label, numeric value, and fill-bar percentage; low-value warnings with pulsing animation; flash-on-damage effect
- **Ammo counter** (`FPSAmmoCounter`) — Value-bar layout matching health/armor; gold fill bar driven by `WEAPON_MAX_AMMO` lookup; infinite ammo displayed as `∞`
- **Frag counter** (`FPSFragCounter`) — Static-width box with number + "FRAGS" label; sits inline next to the match timer in top-center row
- **Match timer** (`FPSTimer`) — Fixed-width display with `font-variant-numeric: tabular-nums` to prevent jiggling; warning/critical color states
- **Weapon rack** (`FPSWeaponRack`) — Left-side vertical stack showing all 10 weapon slots with slot number, abbreviation, and ammo count; active weapon highlighted in cyan
- **Speedometer** (`FPSSpeedometer`) — Horizontal speed display scaled by movement speed
- **Crosshair** (`FPSCrosshair`) — SVG-based crosshair overlay

### HUD Overlays

- **Scoreboard** (`FPSScoreboard`) — TAB-held overlay showing all players ranked by frags with ping, deaths, and damage columns
- **Chat** (`FPSChat`) — Message display with T-key input; auto-fade messages
- **Damage indicators** (`FPSDamageIndicators`) — Directional damage arrows on screen edges
- **Kill feed** (`FPSKillFeed`) — Top-right scrolling kill notifications
- **Pickup toast** (`FPSPickupToast`) — Center-screen weapon pickup notification; `white-space: nowrap`, no emoji icons
- **Death screen** (`FPSDeathScreen`) — "YOU DIED" overlay with killer info and respawn timer

### Dialogs & Menus

- **Pause menu** (`FPSPauseMenu`) — ESC releases pointer lock → shows Resume / Settings / Disconnect buttons; game continues rendering in background (no actual pause); Resume re-requests pointer lock; Disconnect reloads page
- **Settings overlay** (`FPSSettingsOverlay`) — Placeholder settings dialog wired from pause menu
- **MangaPanelDialog base class** — Reusable dialog with backdrop, header, body, footer, and ESC-to-close

### Layout & Sizing Polish

- **Timer & frag counter** — Side-by-side in top-center row (`flex-direction: row`); both have explicit `height: 46px`, `min-width: 120px` for visual consistency
- **Weapon rack** — Font 18px, padding 6/14px, min-width 110px, gap 3px between slots
- **Pickup toast** — Font reduced to 24px, `white-space: nowrap`, removed icon element

### Optimization — Easy Gains (#1-24)

- **Dead code removal (~200 lines)** — Removed `FPSGame.ts` skeleton, dead methods (`_checkGrounded`, `_moveWithCollision`, `_createGlowLight`, `setPickupImmunity`), dead fields/constants across 18 files, and unused imports
- **Import fix** — Corrected `FPSPhysicsSystem` → `CharacterPhysicsSystem` in `server-replay.ts` and `FPSServerGame.ts`
- **TS error cleanup** — Resolved all TS6133 (unused vars), TS2339 (missing props), TS2552 (typos), and TS2564 (uninitialized fields in `FPSHud.ts`)
- **Verbose log stripping (~120 `console.log` calls)** — Stripped debug logging from `FPSGameManager`, `BspCollision`, `SweepCollisionBackend`, `FPSSimulation`, `Pickup`, `PickupSystem`, `DroppedWeaponSystem`; removed 60-line collision test diagnostic block; preserved all `console.error` and critical `console.warn` calls

### Engine Changes

- **FPSController** — Added gamepad deadzones and pointer lock click-to-capture refinements
- **Pickup system** — Adjusted pickup vertical range and radius for better reliability

## Technical Notes

- **Architecture:** FPSHud is a singleton (`FPSHud.getInstance()`) managing widget lifecycle. Widgets implement `FPSHudWidget` interface (getElement, update, show, hide, destroy). CSS theming via `UIStyles.injectCSS()`.
- **Pointer lock integration:** `pointerlockchange` event on `document` drives pause menu visibility. FPSController resets movement keys on pointer lock loss. No game loop interruption — server connection stays active.
- **Feature branches:** `feature/ui` (both `shag` parent repo and `src/games/fps` submodule)
