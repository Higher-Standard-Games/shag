# v0.9.34

**Release Date:** 2026-10-19

## Changes

- Fixed mouse fire and aim being lost when Babylon cancels pointer events and
  the browser suppresses compatibility mouse events, reproduced in Firefox.
  Mouse button chords, cancellation and focus recovery retain consistent state.
- The gameplay scene preserves compatibility mouse events so mouse-look also
  continues while holding a firing button.
- Extra mouse buttons no longer fall through to the left-button fire binding.
- Failed mouse capture after joining, changing a kit or resuming now gives
  visible retry guidance instead of an unhandled promise rejection.
