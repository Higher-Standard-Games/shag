# v1.0.0-beta.11

**Release Date:** Nov 12, 2026

## Changes

- The native client's **Settings** key over a match opened the settings behind
  the lobby's rail panel, so the player saw the lobby instead. The settings now
  sit above it.

### One leaderboard: the Overall rating

The leaderboard and Profile had a **Public / Private** switch over two separate
ladders, so a new player's bot games and their public games landed on
different boards. Both now show one board per mode, **Overall**, which rates
every eligible match: public or private, against people or bots.

- **A third rating pool.** Each eligible result now updates its own
  visibility's pool (Public or Private, kept as before) and Overall, each from
  that pool's own ratings. Leaderboard and stats queries take `scope:
  "overall"`, the default when omitted; `public` and `private` remain for
  tools and diagnostics.
- **Bots play at fixed strengths.** A bot preset used to be an account rated
  like a player, so with few matches its rating drifted anywhere: on the live
  data Easy had climbed above Insane in Duel. Each preset now plays at a fixed
  strength from the rating policy (Easy 16.7, Medium 25, Hard 33.3, Insane
  41.7, all σ 2.8), and only the people's ratings move. Beating Insane is worth
  far more than beating Easy. Bot accounts keep their win/loss records but
  have no rating.
- **Automatic bot choice** (**+ Add bot**) picks the preset nearest the
  inviter's Overall rating, from those fixed strengths.
- **Ranking schema 4, policy `shag-trueskill-v2`.** The first lobby start with
  this code rebuilds `rating_updates` keyed by pool and re-rates every stored
  result in order, filling Overall from the start of history. Snapshots,
  records and accounts are unchanged. Tested on a copy of the live
  `players.db`: 230 results, 137 records and 1647 accounts kept; the replay
  verifies consistent. Back up the data directory before deploying.
