# v0.1.0

**Release Date:** December 2025

## Summary

Map transitions, camera system, and indicator scoping.

## Features

- Map transition system with fade effects
- Camera state persistence across map changes
- World indicator system with map-specific scoping
- Plant status indicators (water, harvest, pot action)

## Fixes

- Camera target position saved correctly during map transitions
- Camera alpha/beta angles reset when loading new maps
- Plant indicators filtered by current map to prevent cross-map leaking
- World indicators cleared on map change
- Trigger positions use mesh bounding box center

## Technical

- RTSCameraController syncs target position on map load via EventBus
- Consolidated camera state management (save/restore target + alpha + beta per map)
