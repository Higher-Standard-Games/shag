# v0.8.9 - BSP Entity Support & func_door

**Release Date:** January 4, 2026

## New Features

### BSP Entity Processing Bridge

BSP entities are now processed through the same `EntityHandlerRegistry` as `.map` files, enabling consistent entity handling across both formats.

- Added `processBspEntities()` in MapLoader
- BSP entities are parsed and routed to registered handlers
- Enables game-specific entity logic for BSP maps

### func_door Support

Full implementation of Quake/Warsow-style `func_door` entities for BSP maps:

**Geometry:**
- Builds brush model meshes from BSP inline models (`*N`)
- Proper triangle indices using meshVerts (not triangle fan)
- Correct Q3→Babylon coordinate conversion

**Textures & Lighting:**
- Loads textures from PK3 with shader path resolution
- Applies lightmaps from BSP per-face data
- UV2 coordinates for lightmap mapping

**Animation:**
- Calculates movement direction from `angle` property
  - `-1` = UP, `-2` = DOWN, degrees = horizontal
- Travel distance = brush size - lip (default 8)
- Smooth open/close animations at configurable speed

**Grouped Doors:**
- Multiple doors with same `targetname` animate together
- Each door maintains its own direction (e.g., top goes UP, bottom goes DOWN)
- Tested with complex multi-brush doors (wdm17 tech door)

### Console Commands

```
bsp door list              - List all door targetnames
bsp door open <name>       - Open door(s) by targetname
bsp door close <name>      - Close door(s) by targetname
bsp door toggle <name>     - Toggle door(s) by targetname
```

### Freefly Collision (Native + Clip Brushes)

Freefly camera collision now combines Babylon mesh collision with BSP clip brushes (fullclip/playerclip) for robust movement without light halos/effects blocking.

**New debug commands:**

```
freefly_collision clipviz [off|clear|last|brush <index>|<max>]
freefly_collision clipdump [last|brush <index>|<index>]
freefly_collision cliptrace [dist] [radius] [height] [debug]
```

**Notes:**

- FBSP brushside parsing fixed (12-byte RBSP struct), enabling correct plane indices for Warsow maps
- Clip brush collision handles FBSP plane convention ambiguity
- Clip collision traces now match Babylon ellipsoid origin (no phantom floor height offsets)

## Technical Notes

- Brush models are built with child meshes per texture group
- Lightmaps created from BSP raw RGB data using `RawTexture`
- Door groups use shared controller for synchronized animation
- Compatible with both IBSP (Q3) and FBSP (Warsow) formats
