# v0.2.1

**Release Date:** December 28, 2025

## Summary

SHAG Engine branding update with new logo and improved loading screen.

## Branding

- Renamed engine to **SHAG Engine** (Standards, High And Games)
- New vibrant logo with colorful "SHAG" lettering
- Added `EngineVersion` singleton for centralized version management
- Version displayed in debug console header and `version` command

## Loading Screen

- Moved `LoadingScreen` from game to engine (`src/engine/ui/`)
- Added "tap to start" ready phase that unlocks browser audio
- Animated background glow cycles through logo colors (Orange, Yellow, Teal, Pink, Green)
- Smooth crossfade transitions between glow colors
- Pulsing dot and ripple rings use logo color palette

## Audio

- Added `AudioManager.unlockAudio()` for browser audio policy compliance
- Audio unlock now handled by engine loading screen, not game menu

## Documentation

- Removed Quake/Warsow brand references from all docs
- Updated to Q3map2/NetRadiant-compatible format terminology
- Added SHAG Engine branding to README and architecture docs

## Technical

- `EngineVersion.getEngineName()` - Returns "SHAG Engine"
- `EngineVersion.getEngineTagline()` - Returns "Standards, High And Games"
- `EngineVersion.getFullVersionString()` - Returns "SHAG Engine v0.2.1"
- `LOGO_PALETTE` constant with 5 colors extracted from logo
