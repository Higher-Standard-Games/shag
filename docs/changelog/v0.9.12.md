# v0.9.12

**Release Date:** 2026-04-14

## Summary

Cinematic demo player pipeline (DemoAnalyzer highlights, SequenceBuilder, CinematicCameraPaths), demo archive UI redesign with levelshot banners and inline playback, Warsow-style deluxe material pipeline for BSP maps, DemoReader endianness fix, and engine-wide type-safety cleanup across networking, animation, and console commands.

## Changes

### Warsow Deluxe Material Pipeline [NEW]

- **Shader parser and types** - `Q3ShaderParser` and `Q3ShaderTypes` now preserve Warsow/QFusion `material` payloads with variable arity, explicit placeholder tokens, unconditional stages, and `if deluxe` / `if ! deluxe` conditional branch metadata.
- **Shader resolution** - `Q3ShaderRegistry.resolveMaterialProps()` now resolves deluxe-aware stage stacks, normalizes diffuse/normal/gloss/glow channels from structured `material` data, preserves explicit blank-channel intent, and keys cached results by deluxe mode.
- **Classic lightmap safety** - the resolver now avoids misclassifying classic base + `$lightmap` shaders as multiply-transparent decal materials, keeping the legacy lightmap path opaque unless a real transparent/material case is selected.
- **BSP material consumption** - `BspMeshBuilder` now prefers resolved deluxe/material metadata over suffix guessing for diffuse, normal, gloss, and glow textures. Suffix-based `_norm`, `_normal`, `_bump`, `_gloss`, and `_spec` fallback remains available only when the channel is truly absent.
- **Glow/emissive preservation** - BSP lightmap application no longer clears emissive state for surfaces that deliberately use glow or additive/emissive material channels, so deluxe glow metadata survives the lightmap pass.
- **Build-time deluxe toggle** - persisted render cvar `r_deluxe` selects deluxe vs non-deluxe shader branches at BSP/material build time. It defaults to `1`, and changing it while a BSP map is already loaded logs that the change applies on the next map reload instead of attempting a live material rebuild.
- **BSP PBR/spec-gloss path** - persisted render cvar `r_bsp_pbr` enables generated `PBRMaterial` usage for richer BSP companion-map surfaces. It remains reload-only and defaults to `1` for new BSP loads alongside `r_deluxe`.
- **Warsow gloss semantics** - generated BSP PBR materials now treat `_gloss` as spec/gloss-style surface response data through `microSurfaceTexture` while keeping `metallic = 0`, which produced the first successful live results on both `wdm2` and `wdm15`.
- **Lightmap index safety** - BSP lightmap application now correctly handles `lightmapIndex = 0`, fixing surfaces that previously missed their baked lightmap and looked flat or incorrectly lit.
- **Projectile trail cleanup** - grenade launcher trails now use a single ribbon path instead of the old X-shaped double ribbon that could visually read like a delayed duplicate trail.

### Demo Player - Cinematic Pipeline [NEW]

- **DemoAnalyzer** - scans demo frames for highlight moments: frags, multi-kills, airborne frags, first-blood, and high-speed movement. Scores and ranks highlights by context tags (`airborne`, `rocket_jump`, `high_speed`, `first_blood`). Emits `DemoAnalysis` with sorted `HighlightCandidate[]`.
- **SequenceBuilder** - converts `HighlightCandidate[]` into a timed sequence of camera cuts with configurable padding, deduplication, and total-duration budgeting. Produces `SequenceEntry[]` ready for cinematic playback.
- **CinematicCameraPaths** - generates smooth Bezier-spline camera paths between sequence entries. Supports focus-target tracking, easing, and orientation interpolation for cinematic fly-throughs.
- **DemoPlayCommand** - wired to `CameraSystem` so `demoplay cinematic` triggers full cinematic mode in-game.

### Demo Archive UI - Redesign [CHANGED]

- **Levelshot banners** - demo cards now show 140px map screenshot banners (`/data/levelshots/<map>.png`). CRT scanlines overlay (`repeating-linear-gradient`) and dark bottom vignette for text readability. Graceful 404 fallback: reverts to gametype-hue gradient and removes scanlines class.
- **Levelshot preloading** - `LobbyPanel` eagerly preloads levelshots on `lobby:state` (all gametype map pool maps) and `demos:list_response` (all demo maps) via hidden `<img>` elements to warm the browser cache.
- **Card redesign** - players as primary Orbitron heading inside banner, map name as small secondary label, corner bracket accents matching matchmaking mode cards, hover lift + gold glow shadow.
- **Inline playback buttons** - PLAY launches `DemoViewer` + `DemoService.loadAndPlayNormal()` directly from the lobby; HIGHLIGHTS launches `loadAndPlayCinematic()` with `CameraSystem` for cinematic mode. Both buttons disable with `LOADING...` state during async ops and hide the lobby panel on success.
- **Error toasts** - `_showDemoError()` appends a styled error div to the card with 4-second auto-dismiss. Animated slide-in remains.
- **DemoTab.css** - all demo tab styles extracted from inline template-string in `LobbyPanel.ts` to `src/engine/ui/panels/styles/DemoTab.css`, imported via `?raw`. Overrides `GamePanel` width constraint so the demo grid uses full panel width.

### Demo Reader [FIXED]

- **Endianness alignment** - `DemoReader` byte-order handling corrected; previously mismatched endianness caused malformed frame reads on real `.shagdemo` files recorded by the server.

### Type Safety [CHANGED]

- **BinaryProtocol** - added `Vec3` / `Vec4` / `QuatShape` interfaces to replace `any` casts in transform delta encoding. `ServerMessage` (0x09) `encodeServerMessage` / `decodeServerMessage` helpers formalised with typed signature.
- **Console commands** - replaced `const` with `let` for lazy-assigned singleton references across 16 command files (`AudioCommand`, `CameraCommand`, `ClipCommand`, `ConsoleDebugCommand`, `EntityCommand`, `FogCommand`, `GameCommand`, `GravityCommand`, `InspectCommand`, `JoinCommand`, `LightCommand`, `MapCommand`, `PK3Command`, `PhysicsCommand`, `PositionCommand`, `RenderCommand`, `ScreenshotCommand`, `ShadowCommand`, `SkyboxCommand`). `NetworkTestCommand` gains explicit `Vec3` interface.
- **AnimationLoader / PlayerModelManager** - animation group lifecycle cleanup (stop + dispose on reload), child mesh visibility guard.
- **FreeflyController** - typed Babylon camera ellipsoid access behind `biome-ignore` with explanatory comment.

## Technical Notes

- `RenderVars.ts`: `r_deluxe` and `r_bsp_pbr` are persisted but intentionally excluded from live `applyToScene()` updates; they behave as build-time render settings rather than hot-toggles.
- `MapLoader.ts`: captures `r_deluxe` and `r_bsp_pbr` once per BSP load and threads those values through mesh build and texture application so branch/material selection stays stable for the lifetime of the loaded map.
- `Q3ShaderRegistry.ts`: resolved material cache keys include deluxe mode; normalized props expose `normalTexture`, `glossTexture`, `glowTexture`, raw material tokens, blank-channel flags, and selected branch metadata.
- `BspMeshBuilder.ts`: deluxe/material-aware BSP surfaces bypass the older glow-overlay shortcut path that only understands flattened legacy stages; generated BSP PBR materials now use spec/gloss-oriented `microSurfaceTexture` semantics for Warsow `_gloss` assets.
- `RenderVars.ts`: PBR gloss scaling now covers `microSurfaceTexture` in addition to reflectivity/roughness shaping.
- `ProjectileManager.ts`: grenade trails now use a single ribbon path, which avoids curved GL shots reading as a second desynced trail.
- `DemoAnalyzer.ts`: `HighlightType` union collapsed to single line; `analyze()` signature kept; multi-kill grouping window (`MULTI_KILL_WINDOW`) unchanged.
- `SequenceBuilder.ts`: total sequence duration is clamped to `maxDurationMs`; overlapping entries are merged before output.
- `CinematicCameraPaths.ts`: Bezier control points derived from entry positions + forward-vector offset; `buildPath()` returns `CameraKeyframe[]`.
- `LobbyPanel.ts`: `_preloadedLevelshots: Set<string>` tracks already-queued maps to avoid duplicate `<img>` creation; `_showDemoError()` replaces any prior error on the same card before appending.
- `DemoTab.css`: `.game-panel:has(.lobby__demos)` selector overrides `max-width` and `padding` on the GamePanel scroll container; grid uses `auto-fit minmax(280px, 1fr)` instead of fixed column count.
