# v0.7.1 - Configurable Console Size

**Release Date:** January 2, 2026

## Summary

Added Warsow-style configurable console height with the `con_size` command.

## Features

### Console Size Control

New `con_size` command to adjust debug console height:

- **Range**: 0.1 (10%) to 1.0 (100% fullscreen)
- **Default**: 0.5 (half screen height)
- **Persistence**: Saved to localStorage, persists across sessions

### Usage

```
con_size           # Show current size
con_size 0.3       # Small console (30%)
con_size 0.5       # Half screen (default)
con_size 0.75      # Three quarters
con_size 1         # Full screen
```

## Technical Details

- Size stored in localStorage as `debug_console_size`
- Applied via inline styles on console container
- Smooth transition when console opens/closes

## Files Changed

- `src/engine/debug/DebugConsole.ts` - Size state, load/save, con_size command
- `src/engine/debug/debug-console.css` - Updated default height handling
