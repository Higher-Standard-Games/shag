# v1.0.6

**Release Date:** unreleased — living changelog

## Changes

- **The itch.io build goes out with the deploy.** EU's deploy pushes the public
  itch.io build (`higherstandardgames/washoi:html5`) for each release, once
  every region's lobby runs it: each region's activation now writes
  `release.json` (`{"pair":"<pair id>"}`) beside its game client, and EU builds
  `dist-itch` once and pushes when EU and US both name the pair. Before, the
  build was pushed by hand from a developer machine after a release. The
  staging page is still pushed by hand. The surface needs butler and an API
  key on EU (`/srv/washoi/bin/butler`, `/srv/washoi/env/itch-butler.key`), and
  is skipped without them.
