# v0.8.15 - Cvar System & Engine Refactoring

**Release Date:** 2026-01-09

## Summary

Unified Quake/Warsow-style Cvar (console variable) system for engine and game configuration, major engine/game code separation, and documentation updates.

## Changes

### Cvar System (Console Variables)

- **Unified Cvar system** - Type-safe console variables with automatic persistence
  - Supports `bool`, `int`, `float`, `string` types with validation
  - Min/max bounds checking for numeric types
  - Change callbacks for reactive updates
  - Automatic localStorage persistence
  - Export/import config strings

- **Console integration** - Cvars auto-register as commands with autocomplete
  - `cvarlist [filter]` - List all cvars, optionally filtered by prefix
  - `toggle <cvar>` - Toggle boolean cvars
  - `reset <cvar>` / `resetall` - Reset cvars to defaults
  - `set <cvar> <value>` - Explicit set command
  - `cvarexport` - Export modified cvars as config text
  - `help <cvar>` - Shows type, value, default, range

- **Registered cvars:**
  - `r_*` - Render variables (r_bloom, r_wireframe, r_lightmap, etc.)
  - `s_*` - Sound variables (s_volume, s_musicenabled, s_sfxvolume, s_sfxenabled)
  - `m_*` - Mouse variables (m_sensitivity, m_invertY)
  - `g_*` - Game variables (g_autosave, g_cheats)

### Engine Refactoring

- **EngineScene base class** - Split GameScene into reusable EngineScene + game-specific GameScene
- **GameAudio class** - Moved game audio orchestration out of AudioManager
- **MenuSystem decoupling** - SettingsPanel decoupled via callbacks instead of hard dependency
- **AudioManager fix** - Properly stops current music when starting new playlist
- **GameClock moved to engine** - `src/game/GameClock.ts` → `src/engine/core/GameClock.ts`
- **GameTimer moved to engine** - `src/game/GameTimer.ts` → `src/engine/core/GameTimer.ts`
- **mobile.css moved to engine** - `src/game/ui/styles/mobile.css` → `src/engine/ui/styles/mobile.css`

### File Organization

- `src/data/` → `src/game/data/` - Game data with game code
- `src/ui/` → `src/game/ui/` - Game-specific UI components
- Game-specific docs moved to `src/game/docs/`

### GamePaths Configuration

- **engine.json required** - No silent fallbacks, errors if missing
- **defaultGame required** - Must specify game directory in config
- **allowGameOverride option** - Security flag to enable/disable `?game=` URL parameter
  - Default: `false` (disabled for production security)
  - Set `true` in development to allow testing different game directories

```json
{
  "defaultGame": "game",
  "engineAssetsPath": "/engine",
  "title": "My Game",
  "allowGameOverride": true
}
```

### Browser Title

- Browser tab shows game title from `engine.json` config if set
- Falls back to "SHAG Engine v0.8.15" if no title configured
- Example game set to "Isometric Game Test"
