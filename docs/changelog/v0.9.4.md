# v0.9.4 - Weapon Fixes & Polish

**Release Date:** 2026-02-20

## Summary

Weapon system reliability, gib system, death/respawn flow, crosshairs, network jitter fixes, and visual polish. Major focus on fixing weapon pickup/drop lifecycle, death animation flow, and eliminating reconciliation-induced camera jitter.

## Changes

### Gib System

- **Physics-based gibs** — Death by overkill damage spawns bone-mapped gib pieces with velocity inherited from death force vector
- **Gib pooling** — Object pool prevents GC spikes from rapid gib creation/destruction
- **Wall collision** — Gibs collide with BSP geometry and settle naturally
- **Configurable thresholds** — `gib_threshold`, `gib_count`, `gib_lifetime` CVars for tuning

### Death & Respawn Flow

- **Warsow-style death** — Camera freeze on death position, ragdoll-like model collapse, weapon drop on death
- **Weapon drop system** — Dropped weapons use Havok physics simulation for realistic tumbling
- **Dropped weapon pickup** — Other players can pick up dropped weapons with ammo
- **Dead entity lifecycle** — Proper cleanup of dead player entities, model disposal, and state reset
- **Ghost model fix** — Fixed phantom player models appearing from item/projectile entities

### Crosshair System

- **Configurable crosshairs** — `cg_crosshairSize`, `cg_crosshairColor`, `cg_crosshairAlpha` CVars
- **Per-weapon crosshairs** — Different crosshair styles per weapon type
- **Hit marker** — Brief crosshair flash on confirmed damage

### Network Jitter Fixes

- **Reconciliation grounded state fix** — Server snapshots reported `grounded=false` for stationary players; client now preserves its own grounded state when no inputs need replay (`unacked=0`) and position error is small (<1.0)
- **Visual offset smoothing** — Faster visual offset decay (`dt*20`) with snap-to-zero threshold to prevent endless micro-drift from reconciliation corrections
- **Movement state sync** — `getCurrentMovementState()` called after tick loop to ensure visual effects see the final predicted state, not intermediate reconciliation states

### Idle Breathing Fix

- **CVar fallback values fixed** — `cg_idleamplitude` fallback was 0.3 (6× too strong), corrected to 0.02; `cg_idlefrequency` fallback was 1.5 (2.5× too fast), corrected to 0.6

### Bug Fixes

- **BinaryDecoder buffer underflow** — Fixed crash from reading past end of network packet buffer
- **Weapon texture disposal** — Fixed textures not being disposed when switching weapons
- **Floating damage numbers** — Fixed damage numbers appearing at wrong positions
- **Splash damage dedup** — Prevented duplicate explosion events from client prediction + server confirmation

## Known Issues

- Server-side `grounded` state in snapshots can be stale for stationary players (client-side workaround in place)
