# v0.9.10

**Release Date:** 2026-03-18

## Summary

Remote player animation overhaul: crouchslide, crouch walk, crouch idle, walljump, and blade attack animations now display correctly for remote players. Fixed delta compression desync for movement state flags. Hitbox visualization corrected for crouch direction. Plasmagun tuning (recoil, ADS). Riotgun light optimization. Third-person weapon rendering via bone attachment. Plasmagun barrel positioning. Barrel sub-models on dropped/spawned ground weapons.

## Changes

### Remote Player Animations [FIXED]

- **Crouchslide animation** — remote players now correctly display slide animation when crouchsliding, with model anchor lowered 20 units to match shorter hitbox (Mixamo slide anim doesn't lower the skeleton)
- **Crouch walk animation** — remote players play directional crouch walk animations with speed-proportional playback. Backward crouch walk uses reversed animation (negative speedRatio) instead of a separate animation
- **Crouch idle** — when crouching and stationary, displays frozen first frame of `crouch_walk_forward` as a crouching stance (speedRatio = 0)
- **Crouch model offset** — split Y offset: -10 for crouch walk/idle (Mixamo partially lowers), -20 for crouchslide (Mixamo doesn't lower at all)
- **Walljump animation** — added `wallrun.glb` animation for wall jump state, transmitted via bit 2 in the movementState bitmask
- **Blade attack lock-out** — one-shot attack animations (blade slash) now temporarily block locomotion group, preventing walk animation from overriding the swing

### Hitbox Crouch Direction [FIXED]

- **Hitbox shrinks from top** — crouch hitbox wireframe now correctly shrinks from the head (top) down, keeping the bottom at feet level. Previously shrank from the bottom, making the hitbox appear to float

### Movement State Sync [FIXED]

- **Sticky flags fix** — movement state bitmask (crouch/slide/walljump) is now always sent without delta compression (1 byte per entity per snapshot). Previously, baseline ACK mismatches could cause flags to get permanently stuck
- **Component name mismatch** — `BinaryProtocol.decode` was placing movement state on `velocity` component instead of `movementState`, causing `RemotePlayerRenderer` to never see the flags

### Remote Player Weapons [NEW]

- **Bone attachment** — equipped weapons now render correctly on remote players using Babylon.js `attachToBone()` API, attached to `mixamorig:RightHand` bone with proper scale compensation (36x model scale)
- **Weapon orientation** — per-weapon rotation corrections for IQM→GLB coordinate system differences (barrel points forward, correct grip angle)
- **Scale tuning** — weapons sized proportionally for third-person view with `defScale / MODEL_SCALE * 0.5` factor

### Plasmagun Barrel Positioning [FIXED]

- **Dual barrel alignment** — both barrel sub-models now correctly positioned in their barrel slots using Z-axis offsets (`z: -4` and `z: 0`), matching the `.cfg` barrel definitions
- **Barrel axis correction** — identified correct separation axis (Z = left/right in GLB weapon space) through Q3 `.cfg` analysis

### Barrel Sub-Models on Ground Weapons [NEW]

- **Dropped weapons** — barrel GLBs now load and attach to dropped weapon models (`DroppedWeaponRenderer`), filling previously empty barrel slots on the plasmagun
- **Map-spawned pickups** — barrel GLBs also load on map-spawn weapon pickups (`Pickup.loadModel`), with fire-and-forget async loading to avoid blocking `dropToGround()` raycasting
- **Bone-based positioning** — both systems use `loadTags`/`findTag` for `tag_barrel` bone position lookup + tag offset + barrel def offset, matching `WeaponBarrels.load()` first-person positioning

### Plasmagun Tuning [CHANGED]

- **Recoil scale** — added `recoilScale: 0.4` (was default 1.0). Fast-firing energy weapon at 12.5 shots/sec needs reduced kick for proper visual feedback
- **ADS Y offset** — tuned from -23 to -22 for better sight alignment

### Riotgun Light Optimization [CHANGED]

- **Pellet impact lights** — consolidated multiple per-pellet PointLights into a single light at the centroid of impact points, reducing GPU light overhead for shotgun blasts

## Technical Notes

- All changes on branch `feature/weapon-model-tuning` (previously `feature/remote-crouch-anim`)
- `BinaryProtocol.ts`: flag `0x10` now always set when `movementState` component exists (no delta compression for this 1-byte field)
- `SnapshotBuffer.ts`: added `wallJumping` field to `EntitySnapshot` and `InterpolatedEntity` interfaces
- `RemotePlayerRenderer.ts`: refactored `deriveAnimation()` and `updateModel()` for full crouch/slide/walljump support; added `updateWeaponModel()` with `attachToBone()` for third-person weapon rendering
- `PlayerModelManager.ts`: added `wallrun.glb` to default animation list
- `TagsLoader.ts`: new utility for loading `tags.txt` bone-position data used by barrel sub-model attachment
- `WeaponBarrels.ts`: weapon barrel sub-model management for first-person spinning chambers
- `Pickup.ts`: added `_loadBarrels()` fire-and-forget method for ground weapon barrel loading
- `DroppedWeaponRenderer.ts`: integrated barrel sub-model loading with bone-based positioning
- `plasmagun.ts`: barrel offsets tuned to `z: -4` / `z: 0` for correct slot placement
