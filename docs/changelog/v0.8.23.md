# v0.8.23 - 2026-01-26

**Release Date:** 2026-01-26

## Summary

Movement system fixes addressing wall jump exploits, ledge grab animation improvements, and `debug player` visualization command.

## Fixes

### Wall Jump
- **Height Check Fix**: Ground distance trace now uses eye level (position + 24) instead of origin level, matching original FPSController behavior
- **Key Consumption Fix**: Wall jump now requires releasing space after ground jump - holding space from ground no longer triggers wall jump
- **Eye-Level Wall Check**: Added trace at eye level to prevent wall jumping on stairs and low obstacles (fence, railings)
- **Key Release Reset**: Removed ground-based reset of `wallJumpKeyReleased` - only resets when key is actually released

### Ledge Grab
- **Smoother Animation**: Replaced complex phased animation with simple `easeInOutQuad` interpolation (matching old behavior)
- **Camera Pitch Effect**: Added smooth camera tilt during ledge grab (look down during grab, return to normal during climb)
- **Extended Duration**: Animation time increased to 0.8s for smoother feel

## Features

### Debug Commands
- **`debug player`**: New toggle command to visualize player collision volume
  - Cyan wireframe capsule showing collision shape (56h × 32w)
  - Yellow ring at eye level (+24 from origin)
  - Orange ring at waist level (+8 from feet)
  - Updates each frame to follow player position

## Technical

### AdvancedCharacterController
- Added `ledgeCameraPitch` and `ledgeEntryPitch` fields for camera animation
- Added `isLedgeGrabActive` to PhysicsState interface
- Fixed `wallJumpKeyReleased` consumption on ground jump

### FPSController
- Added ledge grab camera pitch application (mirrors slide camera behavior)
