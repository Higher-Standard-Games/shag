# v0.8.23 - 2026-01-27

**Release Date:** 2026-01-27

## Summary

Major network movement debug session fixing direction, speed, and advanced movement mechanics. Wall jump and ledge grab now work correctly in server-authoritative mode.

## Network Movement Fixes (2026-01-27)

### Core Movement
- **Direction Calculation**: Fixed inverted movement by correcting yaw rotation to Babylon.js left-handed coordinates (`forward = sin(yaw), cos(yaw)`)
- **Tick Rate**: Added fixed timestep accumulator in `LocalGameHost` - simulation now runs at 60Hz regardless of render framerate
- **Stair Smoothing**: Added `cl_smoothfactor` lerp to network mode camera Y position - prevents screen shake on stairs

### Air Movement
- **3-Mode Air Acceleration**: Ported complete air movement logic from local controller:
  - Mode 1: W-only forward acceleration (Warsow-style bunny hopping)
  - Mode 2: A/D-only strafe bunny acceleration (CPMA strafe jumping)
  - Mode 3: Default air control (Q3-style)
- **Strafe Jumping**: Now works correctly with momentum building

### Wall Jump
- **Momentum Preservation**: Uses reflection formula `R = V - 2(V.N)N` to bounce off walls while preserving speed
- **Multi-Direction Detection**: Checks 5 directions (forward, forward-diagonals, sides) for walls
- **Eye-Level Validation**: Prevents wall jumping on low obstacles
- **Grace Timer**: 100ms delay before exiting 'available' state prevents detection flicker
- **Charging State**: Wall grab freeze with boost on release

### Ledge Grab
- **4-Trace Detection**: Waist trace, head clearance, downward ledge surface, room-to-stand check
- **Cancel Protection**: 50ms minimum grab duration before cancel allowed
- **Push-Away Cancel**: Can cancel grab by pushing backward from wall

## Local Mode Fixes (2026-01-26)

### Wall Jump
- **Height Check Fix**: Ground distance trace now uses eye level (position + 24) instead of origin level
- **Key Consumption Fix**: Wall jump now requires releasing space after ground jump

### Ledge Grab
- **Smoother Animation**: Replaced complex phased animation with `easeInOutQuad` interpolation
- **Camera Pitch Effect**: Added smooth camera tilt during ledge grab
