## Changes

QA/architecture work orders from the v0.9.18 audit — all *(merged to main)* unless noted:

- **QA-WO11** — CLI/headless gates now truthful: `runCli` wrapper exits non-zero on top-level throw; explicit `CommandFailure`/`executeChecked` so a failed batch command sets the exit code; headless asset-preflight `assets` gate.
- **QA-WO1** — protocol smoke suite: real `GameServer` on an ephemeral port driven by a socket client, incl. the chat→echo regression guard.
- **QA-WO2** — lobby lifecycle tests (create/join/full-reject, empty-destroy vs keep-alive grace, server-exit reset, match-start/revert).
- **QA-WO12** — one server timing contract (`ServerTiming`): tick/snapshot/lifecycle timers derive from a single validated value; 7 subsystems moved off hardcoded `tickRate:125`; demos record the *effective* snapshot cadence.
- **QA-WO3** — deleted armed foot-guns: `handleReliable` collapsed into `handleDatagram` (one router for both channels — the silent chat-drop class), dead KillFeed widget removed. (WebTransport kept — preferred future transport, blocked on Node libs.)
- **QA-WO4/QA-5** — wire-type dedup + identity codec: `MatchStateManager` imports the shared match types instead of a drifted hand-copy; `ClientEntityKey` owns the `player_<id>` format (~20 sites routed through it).
- **QA-WO5** — `SnapshotEvent` discriminated union + exhaustive switch dispatch at the client boundary (kills the silent-unrouted-event class).
- **QA-WO6** — CI (GitHub Actions) + pre-commit hook + biome count-ratchet gate + coverage visibility.
- **QA-WO8** — `shared/` is downward-only: net cluster + collision contract moved into `shared/`, engine keeps re-export shims; `SharedCollisionWorld` is pure structural math with a `SweepBackendAdapter` on the engine side. Determinism proven bit-identical (unchanged checksum).
- **QA-WO9** — WeaponViewManager live/demo instance split: demo playback owns its own instance, so `demoplay stop` can no longer destroy the live viewmodel. *(merged to main; in-game visual pass still owed)*
- **QA-WO13** — reset-on-dispose service lifecycle: `ServiceLocator.dispose()` clears the 9 stateful singletons so a re-init gets fresh instances. *(merged to main; browser scene-reload pass still owed)*
- **QA-WO7 (part 1)** — dependency-inversion `GameFrameHook` seam; `SpectatorController` is now fully game-free. *(remaining relocations deferred — browser-gated)*
- **QA-WO10 (core)** — `log` leveled façade + rate-limited warn; 5 dangerous silent catches de-silenced; hidden source maps + prod `console.log/debug` stripping. *(console.log migration + magic-number pass ongoing)*
