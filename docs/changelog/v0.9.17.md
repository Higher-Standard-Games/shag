Now tracked as `PlayerModelInstance.attachedWeapon` and disposed with the model on both death paths (gib + ragdoll), so the blade rides the corpse and vanishes with it. *(merged to main)*

## Changes

### Fall Damage Band Retune [CHANGED] — merged to main

- Default thresholds +128u across the band: `sv_falldamage_min` 128→**256**, `_full` 256→**384**, `_fatal` 384→**512** (map units; runtime-tunable per server). ~5 jump-heights (51u apex) are now damage-free.
- `[FallDamage]` server-console diagnostic on every landing: raw drop, crouch-softened effective drop, resulting band (SAFE/RAMP/CRUSH/FATAL) — units confirmed 1:1 BSP (the Q3→Babylon transform is axis-swap only; no world scale anywhere in the sim path).
- FallDamage regression tests shifted to the new bands (8 tests).

### First-Person Projectile Muzzle Convergence [FIXED]

- Your own projectiles visually spawned at the EYE (the crosshair-accurate authoritative trajectory), so the trail pointed back at the camera and never read as "from the barrel". Q3-family fix, cosmetics-only: when a freshly spawned server projectile is recognizably your own shot (spawned near the camera, flying along the view), its VISUAL starts at the view-model muzzle (34u forward, 9u down) and converges onto the true trajectory over 220ms. The trail prefills at the barrel and bends onto the real path. Wire positions untouched.

### Crouch Get-Up Flick [FIXED]

- Standing up from crouch/crouchslide snapped like a flick instead of a smooth rise. Root cause: `crouchViewOffset` (per-call exponential lerp) and the slide-exit tilt fade (`slidePhase *= 0.85` per call) advanced once per `simulate()` CALL — so reconciliation replays fast-forwarded both animations (the same replay-acceleration class as the v0.9.16 slide-timer bug; these two fields had kept the old pattern).
- Both are now pure functions of the sim clock: crouch view transitions smoothstep over fixed durations (**down 140ms — snappy; up 260ms — deliberate**), slide-exit tilt fades over an anchored 250ms. Replay-idempotent by construction; 5 regression tests incl. "replaying the same sim time ten times changes nothing".

### Blade Drop Mesh Leak [FIXED]

- `PlayerModelInstance.attachedWeapon`: the bone-attached 3rd-person weapon is now disposed with the player model (`disposeInstance`, `RagdollSystem.disposeModel`), covering both gib and ragdoll death paths; cleared on weapon swap. Dropped blades ride the ragdoll and vanish with the corpse (~5s) instead of accumulating over a match.

### Teleporters & Jumppads [ADDED]

Full feature; plan + progress log in `docs/research/triggerbrushes-and-targets.md`:

- **Shared `TriggerTable`** (`extractTriggerVolumes`): `trigger_teleport` → `misc_teleporter_dest`, `trigger_push` → `target_position` from BSP entities + submodel AABBs; deterministic BSP-order ids; fail-closed on bad refs. The SAME table is installed on the server at map load and into `V2NetworkClient` prediction — pads and teleporters are client-predicted with **zero reconciliation snap by construction**, and exact under demo re-simulation.
- **Jumppads** in the shared `MovementProfile`: Q3 `AimAtTarget` solved **per-position/per-fire** (removes the fixed-velocity re-fire apex overshoot, +28u measured, without Q3's replay-hazardous `jumppadEnt` contact state); crouch-aware AABB overlap; `jumppadLaunch` result flag for one-shot effects.
- **Teleporters** in the profile: exit at dest + waist lift; at most one trigger fires per step (chained triggers can't loop within a tick); exit velocity redirects the **full 3D momentum** along the exit yaw (Warsow — falling into a tele converts drop speed into exit speed; config policy, Q3 fixed-400 selectable, deliberately NOT a live cvar so re-sim needs no cvar snapshots). Local camera rotates to the exit yaw on fresh predicted teleports (`FPSController.setViewYaw` — writes the mouse accumulator AND the camera).
- **Server side effects**: telefrag (`DamageType.Telefrag`, 9999 armor-piercing, credited to the teleporting player), `[Authority]` position tripwire whitelisted on teleport ticks, fall-damage tracking cleared on teleport (mid-fall teleport no longer lands as a fatal drop).
- **Washoi VFX** (`client/TeleportEffect.ts`): generic pooled afterimage ghosts — flat unlit team-color vanguard silhouettes with a posterized 4-step fade — at BOTH entry and exit, including your OWN afterimage at the entry (arcade-deliberate: tele usage is trackable info); spinning radial speed-line bursts; local exit burst thrown ahead so you fly through it. Remote teleports detected from the snapshot stream (>256u frame delta — no protocol changes); `SnapshotBuffer` snaps instead of lerping across >256u inter-snapshot jumps (kills cross-map streaking, helps demo playback too).
- Coverage: 30+ tests (TriggerTable / JumppadTrigger / TeleporterTrigger / subsystem telefrag+tripwire / FallDamage teleport-clear); tick/fuzz determinism green throughout; browser-validated on wdm2.
