# v0.8.22 - 2026-01-24

**Release Date:** 2026-01-24 (Updated)

## Summary

Major update introducing a new Player Animation System, refining Wall Jump physics, and completing major engine documentation.

## Features

### Player Animation System
- **AnimationBlender**: New layered animation system with weighted blending
- **Procedural Implementation**: Procedural recoil, landing, and movement layers
- **Humanoid Rig**: Standardized bone mapping for player models
- **FBX/glTF Pipeline**: Added tools and scripts for animation import

### Physics & Movement
- **Wall Jump Logic Overhaul**:
  - Fixed instability ("shaking") when sticking to walls by isolating physics state
  - **Momentum Preservation**: Charging now correctly captures incoming velocity for realistic reflection
  - **CVar Compliance**: Strict adherence to `sv_walljump_minheight` and `sv_walljump_chargetime`
  - Added strict ground checks to prevent jumping from low elevations
- **FPS Controller**:
  - Reactivated visual components (PlayerVisuals)
  - Improved state management and inputs
  - Refactored `FPSPlayer` for clearer game-code separation
