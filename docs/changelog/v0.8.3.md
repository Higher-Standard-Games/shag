# v0.8.3 - Loader Reorganization & Texture Fixes

**Release Date:** January 3, 2026

## Refactoring

### Loader Module Reorganization
Reorganized `src/engine/loader/` into logical subdirectories for better maintainability:

- **`bsp/`** - BSP loading (BspLoader, BspMeshBuilder, BspTest)
- **`map/`** - .map file parsing (MapParser, BrushGenerator, PatchGenerator)
- **`model/`** - Model/prefab loading (ModelLoader, PrefabLoader, PrefabInstance)
- **`pk3/`** - PK3 archive management (PK3Loader, PK3Index, PK3TextureLoader)
- **`shader/`** - Q3 shader system (Q3ShaderParser, Q3ShaderRegistry, Q3ShaderTypes)
- **`texture/`** - Texture management (TextureManager, SkyboxLoader, KTX1Loader)

Each subdirectory has an `index.ts` barrel file for clean imports.

### Code Quality Improvements
- Fixed 12 unused variable warnings across the codebase
- Added getters: `Q3ShaderRegistry.isLoaded()`, `InputSystem.getScene()`, `TextureMemoryManager.getScene()`
- Exported utilities: `q3ToBabylonVec3()`, `reverseTriangleWinding()`, `MAX_LIGHTMAPS`, `createCustomStages()`

## Bug Fixes

### Texture Tiling Fix
- **Fixed textures being stretched instead of tiled** - PK3-loaded textures now correctly repeat/tile on surfaces
- Root cause: `PK3TextureLoader` was not setting wrap modes, causing Babylon.js to default to CLAMP instead of WRAP

## New Features

### Normal Map Support
- **Companion texture loading** - Automatically loads `_norm`, `_normal`, and `_bump` companion textures for BSP materials
- Normal maps are applied to `material.bumpTexture` for surface detail rendering

## Technical Details

### Files Modified (45 files)
- All loader imports updated across codebase
- New barrel files: `loader/index.ts`, `bsp/index.ts`, `map/index.ts`, etc.
- Resolved `PatchControlPoint` export conflict in `map/index.ts`

## Testing
- Build passes cleanly with no TypeScript errors
- Verified with Warsow maps - textures tile correctly
