# v0.8.3 - Texture Tiling & Normal Map Support

**Release Date:** January 3, 2026

## Bug Fixes

### Texture Tiling Fix
- **Fixed textures being stretched instead of tiled** - PK3-loaded textures now correctly repeat/tile on surfaces
- Root cause: `PK3TextureLoader` was not setting wrap modes, causing Babylon.js to default to CLAMP instead of WRAP

## New Features

### Normal Map Support
- **Companion texture loading** - Automatically loads `_norm`, `_normal`, and `_bump` companion textures for BSP materials
- Normal maps are applied to `material.bumpTexture` for surface detail rendering

## Technical Details

### Files Modified
- **`src/engine/loader/PK3TextureLoader.ts`** - Added `wrapU`/`wrapV = WRAP_ADDRESSMODE` for all loaded textures
- **`src/engine/loader/BspMeshBuilder.ts`** - Added normal map companion texture loading in `applyTextures()`

## Testing
Verified with Warsow maps - ceiling/floor textures now tile correctly matching qfusion renderer output.
