# v0.9.1 - Warsow Weapons & COD-Style Pickup System

**Release Date:** 2026-02-15

## Summary

Warsow weapon ecosystem — full entity definitions for all 8 weapons, ammo types, and projectiles. COD-style 2-weapon limit with F-key pickup interaction, drop-and-swap, scroll wheel switching, and HUD prompt system.

## Changes

### Features

- **Warsow Weapon Definitions** — All 8 weapons with full EntityRegistry defs (gunblade, machinegun, riotgun, grenade launcher, rocket launcher, electrobolt, lasergun, instagun)
- **Ammo Entity Definitions** — Matching ammo pickups for all weapons
- **Projectile Definitions** — Grenade, rocket, and gunblade blast with physics properties
- **COD-Style 2-Weapon Limit** — `InventoryManager.MAX_WEAPONS = 2` caps weapon slots
- **F-Key Weapon Pickup** — Weapons require pressing F to pick up (ammo/health remain auto-pickup on touch)
- **HUD Pickup Prompt** — Shows `PRESS [F] TO PICKUP <name>` or `PRESS [F] TO SWAP TO <name>` when near a weapon
- **Drop & Swap** — Picking up a weapon at capacity drops the active weapon as a new world pickup
- **Pickup Immunity Timer** — Dropped weapons have 0.8s immunity to prevent instant re-acquisition
- **Scroll Wheel Weapon Switching** — Mouse wheel cycles between weapon slots 0 and 1

### Improvements

- `giveWeapon()` returns `{ acquired, dropped }` for precise caller control
- New `dropWeapon()` method on `InventoryManager` with auto-switch fallback
- Server-side `WeaponState` tracks owned weapons array (max 2)
- Server weapon switching validates against owned weapons instead of global registry
- `FPSController` gains `onUse` callback and `use` key state
- `FPSPlayer` wires F-key to `Pickup.triggerUseAction()` static dispatcher
- `GiveWeaponCommand` and `EntityManager.pickupEntity` updated for new return type

## Known Issues

- LightGrid dimension mismatch warnings on some FBSP maps
