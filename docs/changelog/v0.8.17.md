# v0.8.17 - Console System Refactor & Q3 Collision

**Release Date:** 2026-01-11

## Summary

Major console system refactoring with modular command classes and unified Cvar (console variable) system. Q3-style collision with slideMove and stair stepping. Babylon.js tree-shaking for 58% smaller bundles. Memory leak prevention and automated testing infrastructure.

## Highlights

- **Modular Console Commands** - 45+ commands migrated to individual class files with auto-discovery
- **Cvar System** - Unified console variables with r_, s_, g_ prefixes
- **Q3-style Collision** - SlideMove, stair stepping, clip brush support
- **Tree-shaking** - ES6 imports reduce bundle from 8MB to 3.4MB
- **Headless Testing** - CLI for automated command and leak testing

## Changes

### Console System Refactor

Complete overhaul of the console command system:

- **Modular Commands** - Each command in its own file under `src/engine/console/commands/`
- **CommandRegistry** - Central registry with auto-discovery of command files
- **Command Base Class** - Standard interface with definition, execute, completions
- **Developer Mode** - Commands can require `developer 1` for access

New commands added:
- `cvarlist [filter]` - List all cvars
- `toggle <cvar>` - Toggle boolean cvars
- `set <cvar> <value>` - Set cvar value
- `reset <cvar>` / `resetall` - Reset cvars to defaults
- `exec <file>` - Execute script files
- `bind <key> <command>` - Key bindings
- `developer 0|1` - Toggle developer mode

### Cvar (Console Variable) System

Unified variable system with persistent storage:

```typescript
// Register a cvar
Cvar.register('r_shadows', true, {
  type: 'bool',
  description: 'Enable shadows',
  onChange: (v) => updateShadows(v)
});

// Get/set values
Cvar.get('r_shadows');     // true
Cvar.set('r_shadows', 0);  // false
```

Cvar categories:
- `r_*` - Render variables (RenderVars)
- `s_*` - Sound/audio (AudioManager)
- `g_*` - Game variables
- `m_*` - Mouse settings
- `cam_*` - Camera settings

### Q3-style Collision System

New collision backend with Quake 3 movement physics:

- **SlideMove** - Smooth wall sliding with multi-plane clip
- **StepSlideMove** - Automatic stair stepping (18 unit max)
- **Clip Brush Support** - fullclip, playerclip, caulk collision meshes
- **Content/Surface Flags** - Proper SOLID, PLAYERCLIP, DETAIL, NONSOLID handling

```bash
# Console commands
freefly_collision on|off|mode  # Toggle/set collision mode
freefly_speed 500              # Movement speed
```

### Babylon.js Tree-Shaking

Migrated from barrel imports to granular ES6 imports:

```typescript
// Before (pulls entire Babylon.js)
import { Scene, Vector3 } from "@babylonjs/core";

// After (tree-shakeable)
import { Scene } from "@babylonjs/core/scene";
import { Vector3 } from "@babylonjs/core/Maths/math.vector";
```

Results:
- Main bundle: 8.0MB → 3.36MB (58% reduction)
- Total JS: 4.24MB with code splitting
- Side-effect imports for optional features

### Memory Leak Prevention

- **Map Ownership Tagging** - All map objects tagged with `mapOwned: true` metadata
- **Proper Disposal** - EventBus subscriptions, observers, handlers cleaned up
- **Leak Test Commands** - `leaktest maprenderer`, `leaktest mapcycle`

### Headless Mode Improvements

Enhanced CLI for testing and automation:

```bash
# Run commands
npm run cli:game -- --command "developer 1; freefly_speed"

# Multi-command execution
npm run cli:game -- --command "map wdm7; bsp info; quit"

# Leak testing
npm run cli:game -- --command "leaktest mapcycle 10 wdm7"
```

Features:
- PK3 indexing in headless mode
- Batch command execution with semicolons
- Exit codes for CI integration

- **screenshot** - Added screenshotTools side-effect import
- **freefly_speed** - Fixed cvar registration (moved after class definition)
- **Cvar registration** - Services now register cvars in constructors

## Migration Notes

### Console Commands
Commands now use the new registry system. Legacy `EngineCommands.ts` removed.

### Cvars
Use `Cvar.get/set` instead of direct property access:
```typescript
// Before
RenderVars.getInstance().shadows = false;

// After
Cvar.set('r_shadows', false);
```

### Tree-Shaking
If you get "X needs to be imported" errors, add the appropriate side-effect import:
```typescript
import "@babylonjs/core/Lights/Clustered/clusteredLightingSceneComponent";
import "@babylonjs/core/Collisions/collisionCoordinator";
import "@babylonjs/core/Animations/animatable";
```
