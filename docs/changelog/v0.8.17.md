# v0.8.17 - Memory Optimization & Leak Prevention

**Release Date:** 2026-01-10

## Summary

Memory leak prevention and disposal improvements. Adds automated leak testing infrastructure for CI/CD and fixes several resource leaks in scene lifecycle management.

## Changes

### Memory Leak Fixes

- **EngineScene disposal cleanup**
  - Resize handler now properly removed on dispose
  - EventBus subscriptions (`map:loaded`, `app:state_change`, `app:back_button`) now unsubscribed
  - Scene-scoped systems (`InputSystem`, `CameraSystem`, `SpriteManager`, `WorldIndicatorSystem`) disposed on scene teardown
  - Render loop explicitly stopped before disposal

- **GameScene listener cleanup**
  - Performance settings listener now stored and removed on dispose

- **BillboardSprite observer cleanup**
  - `onBeforeRenderObservable` observer now removed in `dispose()`

### Map Ownership Tagging

New metadata-based disposal system for reliable map cleanup:

```typescript
// All map-created objects now tagged with:
mesh.metadata = {
  mapOwned: true,
  mapName: "wdm7"
};
```

Objects tagged include:
- Point lights
- Sprites and shadow meshes
- Brush meshes and patch meshes
- Prefab instances and model meshes
- Sprite buildings
- Instanced mesh entries

`MapRenderer.clearMap(scene, mapName?)` now disposes by metadata (with legacy prefix-based fallback).

### Leak Testing Commands

New headless CLI commands for automated leak detection:

```bash
# Test MapRenderer create/clear cycle
npm run cli:game -- --command "leaktest maprenderer 10 testmap"

# Test full map load/unload cycle
npm run cli:game -- --command "leaktest mapcycle 10 wdm7 wdm1"
```

Features:
- Compares resource counts (meshes, nodes, lights, materials, textures) before/after
- Sets `process.exitCode = 1` on failure for CI integration
- Detects retained `ClusteredLightContainer` after clear
- Optional GC trigger between iterations

### PK3 Indexing in Headless Mode

- PK3 files now indexed during headless initialization
- Supports both `./public/game` and `./public/games/default/basewsw` paths
- PK3 files sorted for deterministic loading order

### Batch Command Execution

Headless mode now supports multi-command strings with semicolon or newline separators:

```bash
npm run cli:game -- --command "map wdm7; bsp info; quit"
```

## Testing

Run the leak test suite:

```bash
# Quick smoke test
npm run cli:game -- --command "leaktest maprenderer 5"

# Full map cycle test (requires PK3 with maps)
npm run cli:game -- --command "leaktest mapcycle 10 wdm7"
```

Expected output on success:
```
LeakTest OK (maprenderer) iterations=5 map='leaktest'
LeakTest OK (mapcycle) iterations=10 baseline=m=0 n=0 l=0 mat=0 tex=0
```

## CI Integration

Add to GitHub Actions:

```yaml
- name: Memory Leak Test
  run: npm run cli:game -- --command "leaktest maprenderer 10"
```

The command exits with code 1 on failure, failing the CI job.
