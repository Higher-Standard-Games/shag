# v0.1.1

**Release Date:** December 25, 2025

## Summary

Camera and weather fixes.

## Features

- Comprehensive weather system (rain, snow, thunder, fog) with ambient sounds
- Particle-based rain weather effect with camera tracking and auto-scaling
- Indoor map flag to disable rain/snow effects indoors
- Graphics settings (bloom, vignette, SSAO) in Settings menu
- PostProcessingManager with bloom, vignette, color grading

## Fixes

- Camera drift when transitioning between maps
- Rain/snow not stopping when entering indoor maps
- Standardized camera settings across all maps (perspective mode)
- Perspective camera clipping at distance
- Plant dialog closes after water/fertilize action for better UX

## Documentation

- Added post-processing effects documentation
