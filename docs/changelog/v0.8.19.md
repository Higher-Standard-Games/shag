# v0.8.19 - SpawnModel Command, BSP LightGrid, Day/Night Cycle & Warsow Movement

**Release Date:** 2026-01-15

## Summary

New developer command for spawning and manipulating 3D models at runtime, with automatic BSP LightGrid lighting integration. Dynamic day/night cycle system for BSP maps. **Major FPS movement overhaul** implementing authentic Warsow-style physics with Q3 friction, acceleration, air control, auto-bunny hop, and strafe jumping mechanics.

## Changes

### New Features

- **`spawnmodel` console command** - Developer tool for testing glTF/GLB models in-game
  - Spawn models at camera position or specific coordinates
  - Default scale of 100 to match glTF meters to BSP/Quake units
  - Transform manipulation: rotate, move, scale spawned models
  - Animation control: play, stop, loop animations
  - Model management: list, info, remove, clear
  - Lighting refresh: `spawnmodel lighting <index>` to reapply BSP lighting
  - Tab autocomplete for subcommands and animation names

- **BSP LightGrid integration** - Models automatically lit by BSP lightgrid data
  - Trilinear interpolation of ambient/directional light from Q3 lightgrid
  - Per-model DirectionalLight scoped to only affect that model's meshes
  - Spherical coordinate decoding for light direction (Q3 lat/long format)
  - Gamma-correct color conversion from BSP byte values
  - Fallback lighting for maps without lightgrid data

- **Dynamic Day/Night Cycle** - Time-based lighting for BSP maps
  - `daynight` console command with presets: noon, midnight, sunrise, sunset
  - Configurable cycle length in minutes (`daynight cycle <min>`)
  - Animated time progression (`daynight start/stop`)
  - Worldspawn key support for map-specific configuration
  - BSP world geometry: Diffuse color modulation (0.1x - 1.5x)
  - Skybox: Tint from bright white (noon) to dark blue (midnight)
  - Spawned models: Automatic lighting to match world
  - Street lamp integration: Auto on/off based on time period

- **Worldspawn Day/Night Keys** - Map authors can configure defaults
  - `daynight_enabled` - "1" to enable cycle on load
  - `daynight_time` - Starting time (0.0 = midnight, 0.5 = noon)
  - `daynight_cycle` - Full cycle length in minutes
  - `daynight_animate` - "1" to auto-start animation

- **Warsow-style FPS Movement** - Complete physics overhaul based on Warsow `gs_pmove.c`
  - **Q3 Ground Physics**: Friction (`sv_friction`), acceleration (`sv_accelerate`), velocity persistence
  - **Auto-bunny hop** (`sv_autohop`): Hold jump to chain hops, preserves momentum
  - **Air movement modes** from Warsow source:
    - Forward-only (`PM_AirAccelerate`): Bunny speed gain up to 925 u/s soft cap
    - Strafe-only: High acceleration (70) with capped wishspeed (30)
    - Forward+strafe: Standard Q3 air acceleration
  - **Ground strafe**: 50% speed when strafing without forward (Warsow behavior)
  - **Jetpack bug fix**: Ground detection only when velocity.y ≤ 0

- **Weapon System Overhaul** - Full Quake/Warsow style weapon implementation
  - **MD3 Weapon Models**: Native loading of weapon models with tags (`tag_weapon`, `tag_flash`)
  - **Muzzle Flashes**: Correctly oriented, billboarded, additive-blended flashes with smooth fadeout
  - **Projectiles**: Physical projectile system (`ProjectileManager`) supporting MD3 models and ballistics
  - **Weapon Bob & Sway**: Smooth procedural movement for walk, run, jump, land, and strafe sway
  - **Recoil System**: Visual kickback and recovery
  - **Visual Tuning**: Opacity and fade speed tuning for muzzle flashes

- **`join` command** - Quick game entry from spectator mode
  - Spawns at random `info_player_*` entity
  - Sets `spectator 0` automatically
  - No developer mode required

- **Mouse sensitivity** (`m_sensitivity`) - Float support for precise tuning

- **`bsp debug_grid` command** - Visualize BSP lightgrid data
  - Spawns colored spheres showing ambient light values at grid points
  - Useful for debugging lighting issues
  - `bsp debug_grid clear` to remove debug visualization

- **`bsp lightgrid` command** - Query light values at camera position
  - Shows ambient RGB, directional RGB, and direction angles

- **ModelLoader animation support** - Production-ready API for animated models
  - `playAnimation()` - Play animations with loop/speed options
  - `stopAnimation()` - Stop specific or all animations
  - `pauseAnimation()` - Pause animations
  - `getAnimationNames()` - List available animations
  - `hasAnimations()` - Check if model has animations
  - `getAnimationInfo()` - Get animation details (duration, playing state)
  - `ModelLoadResult` now includes `animationGroups`, `skeletons`, and `lights`

### Improvements

- **MD3 Loader Upgrades**
  - **TGA Support**: Fixed 24/32-bit TGA loading with proper alpha parsing
  - **Autosprite**: Baked rotation fix for billboarded meshes (muzzle flashes)
  - **Additive Blending**: Fixed material property handling for transparent surfaces

## Command Reference

```bash
# Enable developer mode first
developer 1

# Basic spawning
spawnmodel <model>                      # Spawn at camera (scale 100)
spawnmodel <model> <scale>              # Custom scale
spawnmodel <model> <scale> <x> <y> <z>  # At position
spawnmodel <model> <scale> <x> <y> <z> <angle>  # With rotation

# Subcommands
spawnmodel list                   # List spawned models
spawnmodel info <index>           # Show model details
spawnmodel clear                  # Remove all
spawnmodel remove <index>         # Remove specific

# Transform
spawnmodel rotate <index> <angle> # Rotate (or +/- for relative)
spawnmodel move <index> <x> <y> <z>
spawnmodel scale <index> <scale>

# Animation
spawnmodel anim <index> <name>       # Play (loops)
spawnmodel anim <index> <name> once  # Play once
spawnmodel anim <index> stop         # Stop all
```
