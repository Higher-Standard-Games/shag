# v0.3.1

**Release Date:** December 28, 2025

## Summary

TypeDoc API documentation setup with custom SHAG Engine theme.

## Documentation

- **TypeDoc integration** - Engine API documentation generator
- **Custom SHAG theme** - Dark theme using logo color palette
- **Nunito font** - Google Fonts integration for headers
- **Version sync** - Docs version reads from `version.txt`

## Technical

- Added `typedoc` as dev dependency
- Created `typedoc.json` config (engine-only, excludes game code)
- Created `docs/api-theme.css` with SHAG color palette
- Created `scripts/build-docs.js` for version injection
- Added `npm run docs:api` script
- Engine README.md for docs landing page

## Usage

```bash
npm run docs:api
# Opens docs/api/index.html
```
