# v1.0.0-alpha.3

**Release Date:** unreleased — living changelog

## Changes

- **Engine separation: Washoi owns pickup spawning.** The pickup entity manager
  and `spawn_pickable_entity` command move into the game. The map loader uses a
  registered game adapter at the same definition, spawn and disposal boundaries,
  preserving pickup IDs, placement, visual readiness and cleanup order.

- **Engine separation: Washoi owns its first-person controller.** The concrete
  FPS controller, player-visuals helper and `spectator`/`giveweapon` commands
  move into the game. Their controller ID, command behavior and player logic
  remain the same. Engine debug overlays use the generic position capability.
  Freefly retains ownership of its speed cvar across the module-load change.

- **Engine separation: freefly gets its input mapping from the game.** The
  engine camera no longer imports Washoi's FPS actions. Washoi supplies the
  same movement, jump, crouch and sprint actions, preserving player rebindings
  and input contexts. Game-free scene tools have engine-local freefly controls.

- **Engine separation: joining uses the registered game adapter.** The engine's
  `join` command no longer imports Washoi. Washoi supplies its existing join
  flow through the network adapter, preserving seat admission, team and loadout
  handling and the command's connection, success and failure responses.

- **Engine separation: scene tools use the registered network adapter.** The
  `scene empty` command no longer imports Washoi to check connection state.
  Its freefly controls remain disabled during an active network connection;
  without a registered game adapter, it enables local freefly controls.

- **The Private lobby key says it hosts bot matches.** Its hint read only
  "Invite only", so a player who wanted a match against bots had no reason to
  open it. It now reads "Invite only or bot matches".
- **The play screen drops the mode tags.** Under each mode's tagline sat a row
  of tags ("One on one", "Control pace", "Rail · Rocket · Blade") that repeated
  the tagline and the mode's subtitle. The tagline now leads straight to the
  Find match and Private lobby keys.
- **Chat is a size larger everywhere.** In a match and over the end-of-match
  board, chat lines were 14px and hard to read mid-fight; they are now 16px,
  with a wider, taller box so as many lines fit. The lobby chat goes from 16px
  to 18px and a room's chat from 14px to 16px, sender names and times with them.
