# v0.4.1

**Release Date:** January 1, 2026

## Summary

UI refactoring release that extracts inline CSS styles from engine components into centralized CSS classes in `UIStyles.ts`.

## Technical

### CSS Refactoring
- **MenuSystem.ts** - Pause panel now uses `ui-pause-panel` and `ui-pause-title` CSS classes instead of inline `style.cssText`
- **LoadingScreen.ts** - All elements refactored to use CSS classes (`ui-loading-screen`, `ui-loading-logo`, `ui-loading-progress`, etc.)
- **ThunderEffect.ts** - Flash overlay uses `ui-thunder-flash` CSS class
- **ScreenTransition.ts** - Transition overlay uses `ui-screen-transition` CSS class

### UIStyles.ts Additions
- **`getPauseMenu()`** - CSS for pause menu panel, title, and hide animation
- **`getLoadingScreen()`** - CSS for loading screen container, logo, progress bar, branding, glow effects, and ripple animations
- **`getEffects()`** - CSS for thunder flash, screen transition, and debug overlays
- **Export added** - `UIStyles` now exported from `engine/ui/index.ts`

## Benefits

- **Maintainability** - Styles centralized in one location
- **Consistency** - All engine UI follows the same CSS class pattern
- **Performance** - CSS classes are more efficient than inline styles
- **Theming** - Easier to customize engine appearance in the future
