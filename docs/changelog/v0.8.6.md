# v0.8.6 - PK3 Indexing & Unified Map Loading

**Release Date:** January 4, 2026

## New Features

### PK3 Index System
- **Automatic indexing** - Scans all PK3 files and indexes their contents
- **Shader extraction** - Parses .shader files to index shader names
- **Map detection** - Indexes BSP maps for quick lookup
- **Cache with checksum** - Uses djb2 hash of `pk3name:size` pairs for cache invalidation
- **Persistent storage** - Index saved to localStorage, survives browser refresh

### Unified Map Command
Load maps like Quake/Warsow - just `map wdm1`:
```
map <name>      - Load a map (auto-detects BSP from PK3)
map list        - List all available maps from index
map current     - Show current map name
map reload      - Reload current map
map unload      - Dispose current map
```

### Automatic Dependency Resolution
When loading a BSP map, the system automatically:
1. Finds which PK3 contains the map
2. Resolves texture and shader dependencies
3. Loads required PK3s
4. Applies textures, shaders, skybox, and lightmaps

### Enhanced PK3 Commands
```
pk3 index build   - Build/rebuild the index
pk3 index stats   - Show index statistics (files, shaders, maps, checksum)
pk3 index clear   - Clear cached index
```

## Technical Details

### New Files
- `src/engine/loader/pk3/PK3Index.ts` - Index management with localStorage cache
- `src/engine/loader/map/MapLoader.ts` - Unified map loading with dependency resolution

### PK3Index Features
- `findFile(path)` - Find which PK3 contains a file
- `findShader(name)` - Find which PK3 has a shader definition
- `findMap(name)` - Find which PK3 has a BSP map
- `findPK3sForTextures(paths)` - Resolve texture dependencies
- `getMapNames()` / `getShaderNames()` - List indexed content

### MapLoader Flow
```
loadMap(name) → findMap → loadBsp → resolveMapDependencies 
  → loadRequiredPK3s → loadShaders → buildMesh 
  → applyTextures → applySkybox → applyLightmaps
```

## Usage

```bash
# First time: build the index
pk3 index build

# List available maps
map list

# Load a map (one command does everything!)
map wdm1
```

## Performance

- Index build: ~2-5 seconds for 20+ PK3s
- Index size: ~100-500KB in localStorage
- Map load: Significantly faster due to dependency pre-resolution

## Known Limitations

- Requires `pk3_manifest.json` in game folder for PK3 discovery (or uses fallback patterns)
- Local .map file loading not yet integrated (BSP only)
