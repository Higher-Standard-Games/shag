# v0.8.5 - Glow Overlay Shader Support

**Release Date:** January 4, 2026

## New Features

### Fullbright Surface Support
- **`surfaceparm nolightmap` detection** - Surfaces marked as fullbright now render with emissive textures
- **Lightmap skip** - Fullbright surfaces bypass lightmap application to maintain brightness

### Glow Overlay Shader System
- **Q3ShaderMaterialFactory** - Centralized shader pattern detection and material routing
- **GlowOverlayShaderMaterial** - Custom GLSL shader implementing `(base * lightmap) + glow` formula
- **Pattern analysis** - Detects `glow_overlay`, `base_lightmap`, `nolightmap_emissive`, and other patterns
- **Dual blend modes** - Supports both additive (`GL_ONE, GL_ONE`) and alpha blend (`GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA`) for glow stages

### New Console Commands
- `shader pattern <path>` - Analyze and display shader pattern detection results
- `shader glow <intensity>` - Adjust glow intensity on all glow overlay materials (default: 1.0)
- `shader lightmap <intensity>` - Adjust lightmap intensity on all glow overlay materials (default: 2.0)
- `shader blendmode <add|alpha>` - Toggle between additive and alpha blend modes for debugging

## Technical Details

### Shader Pattern Detection
The factory analyzes Q3 shader stages to classify them:
- **Base stage** - First non-lightmap texture
- **Lightmap stage** - `$lightmap` reference
- **Glow stage** - Additive blend or texture name contains `_glow`, `_add`, `_bloom`

### GLSL Implementation
```glsl
// Additive mode
finalColor = litBase + glowColor.rgb * glowIntensity;

// Alpha blend mode  
finalColor = mix(litBase, glowColor.rgb, glowColor.a * glowIntensity);
```

## Known Limitations

### `if/endif` Conditional Blocks
Q3/Warsow shaders with `if ! deluxe` / `if deluxe` blocks are not parsed correctly. All stages from all blocks are merged, causing incorrect rendering for some shaders like `textures/boqu/lightstripe_blue_800`.

### `material` Directive
The `material` directive used in deluxe lighting paths is not supported.

### Complex Multi-Stage Shaders
Shaders with more than 3 stages or unusual blend combinations may not render correctly.

## Testing
Tested with Warsow maps `wdm1`, `wdm11` - most light shaders now glow correctly.
