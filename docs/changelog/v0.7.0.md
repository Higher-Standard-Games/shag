# v0.7.0 - PK3 Texture Support

**Release Date:** January 2, 2026

## Summary

Full support for loading textures from Warsow/Quake PK3 packages, including TGA parsing, KTX1 compressed textures, and automatic companion map detection (_gloss, _norm).

## Features

### PK3 Package Loading

- **JSZip integration** for reading PK3 (ZIP) archives
- **Priority ordering** - higher numbered packages override lower (e.g., `tex_001.pk3` > `tex.pk3`)
- Load multiple packages simultaneously
- File listing and directory browsing within packages

### Texture Format Support

- **TGA** - Full support including RLE compression
- **KTX1** - GPU compressed textures (DXT/S3TC, ETC, ASTC)
- **JPG/PNG** - Standard formats from PK3
- Automatic fallback to placeholder texture for unsupported formats

### Companion Map Detection

Automatically loads companion textures following Quake/Warsow conventions:
- **Normal maps** (`_norm`) - Applied as bump texture
- **Gloss maps** (`_gloss`) - Applied as specular texture

### Console Commands

New `pk3` command with subcommands:
- `pk3 load <file.pk3>` - Load a PK3 package
- `pk3 list [pattern]` - List files (wildcard support)
- `pk3 dir [path]` - Browse directory contents
- `pk3 info` - Show loaded packages
- `pk3 texture <path>` - Test load a texture
- `pk3 sets [dir]` - Find texture sets with companions
- `pk3 cache` - Show texture cache
- `pk3 unload` - Unload all packages

New `mem` command for memory/performance stats:
- `mem` - Overview of textures, meshes, materials
- `mem textures` - List all textures with VRAM estimate
- `mem meshes` - Mesh and vertex counts
- `mem engine` - WebGL capabilities and compressed format support
- `mem js` - JavaScript heap usage (Chrome)
- `mem pk3` - PK3 package stats

### Dynamic Map Loading

Maps not in the initial config can now be loaded at runtime via the `map load` command.

## Technical Details

- `PK3Loader` - Singleton managing loaded packages with priority system
- `KTX1Loader` - Parses KTX v1 headers and uploads compressed data to WebGL
- `PK3TextureLoader` - Unified texture loading from PK3 with format detection
- `TextureManager` integration - PK3 textures checked first in loading priority
