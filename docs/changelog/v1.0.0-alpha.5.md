# v1.0.0-alpha.5

**Release Date:** unreleased — living changelog

## Changes

- Loadout weapon previews read packaged models through the shared asset loader,
  fixing missing previews and loose GLB requests that returned 404 in production.

- Packaged weapon models without optional attachment overrides no longer make
  repeated loose `tags.txt` requests that return 404. Custom loose models retain
  their sidecar lookup.

- Regional deployment follows engine `main` again, using that commit's matching
  game revision. Successful updates automatically restart both backends even
  with connected players. Explicit pinned pairs remain available for rollback.

- The winner on the end-of-match screen shows its armour and detail again. It
  was drawn with a forced full-bright glow and outline, which washed the model
  into a flat shape of the player's colour. It keeps the colour, lit by a light
  of its own; players in a match look as before.
