# v0.9.32

**Release Date:** unreleased — living changelog

## Changes

- Warmup cannot time out without opposition: FFA needs two active players;
  team modes need both sides populated. A countdown cancels when opposition leaves.
- Procedural ammo pickups no longer preload the obsolete `ammobox.md3` model.
- Rebuilt all 3,197 KTX2 sidecars from the installed media, removing stale
  artwork such as DM2's gold Warsow sign from the previous texture banks.

- Duel and FFA both offer Washoi DM2, Washoi DM5 and Washoi DM11; DM2 is now
  included in the FFA lobby pool too.

- Production levelshots live in their map PK3s. Index/build generation publishes
  lightweight JPG previews, fixes settings backgrounds and resolves old demo
  thumbnail names without downloading whole maps for lobby cards.

- Spectator freefly disables collision and reenables reused camera controls.
- Added session-only `cl_hud 0/1` for clean levelshots, hiding HUD, crosshair,
  spectator instructions, FPS and debug overlays while keeping menus usable.

- Packaged ammo-crate artwork in `washoi_gfx.pk3`, preserving icon paths and
  loading its indexed archive before rendering either pickup model style.

- The crosshair reads the same equipped weapon/ammo state as the HUD warning,
  showing a red graphical X when empty. Its default size is 32 instead of 24.
- Enlarged the Tab scoreboard by 50% on desktop (15% on narrow screens), including names, scores, deaths and ping,
  with brighter supporting stats and viewport limits for smaller screens.
- Updated production package recipes and weapon loading for the washoi-prefixed
  media banks; regenerated the discovery/index metadata after archive renames.
- Removed Relay Yard from the Amphi lobby pool after archiving its supporting
  media; wamphi1 remains available.
- Renamed the shipped Duel BSP IDs/packages to washoi_dm2, washoi_dm5 and
  washoi_dm11. Texture/shader paths and BSP contents are unchanged; old demo
  map IDs resolve to the renamed media without modifying the recordings.
- Refined the nonfree audio inventory using real playback selectors and installed
  BSPs, separating active cues from preloads, unsupported speakers and dormant features.
- Consolidated the three curated maps' textures, shaders and referenced map media
  into `washoi_textures.pk3`, deduplicating shared content and preserving source manifests.
- Cartoon hit artwork loads from indexed `effects.pk3` instead of loose image
  URLs, with unchanged color/alpha and cleanup when asynchronous loading is cancelled.
- Renamed the display titles of wdm2, wfdm5 and wfdm11 to Washoi DM2,
  Washoi DM5 and Washoi DM11 in lobby map votes, match listings and demo lists.
- Repackaged wdm2, wfdm5 and wfdm11 into map and texture dependency banks with
  unchanged BSP/media bytes and source/hash manifests. Archived obsolete map
  builds and fully shadowed source banks outside the served media directory.
- Added repeatable map-media extraction and nonfree-origin audio audits. Of 41
  source-referenced sound paths, 36 are on the configured map pool's playback
  replacement list; copied nonfree-origin sounds remain present until replacement.
- CLI server, demo recording and movement smoke-test defaults use washoi_dm2
  so the curated media set keeps those commands usable.
