# v0.8.12 - Tree-shaking Optimization

**Release Date:** 2026-01-06

## Summary

Major build size optimization through Babylon.js ES6 module migration, reducing bundle size by ~58%.

## Changes

### Build Optimization

- **Babylon.js ES6 module migration** - Migrated from `@babylonjs/core` barrel imports to granular ES6 module imports
  - Enables tree-shaking to eliminate unused Babylon.js code
  - Bundle size reduced by ~5.8MB (58% reduction in Babylon.js portion)

- **Package deduplication** - Resolved duplicate Babylon.js packages in dependency tree

- **CLI tools** - Added npm scripts for headless CLI tools (`cli:game`, `cli:bsp`)

### Filter Blend Shader

- **Q3 decal support** - Added `FilterBlendShaderMaterial` for Q3 `blendFunc filter` (GL_DST_COLOR, GL_ZERO) decals
  - Custom shader computes alpha from inverse luminance (white=transparent, colored=visible)
  - Parameters: `alphaThreshold`, `alphaPower`, `colorDarken`, `alphaMultiplier`

### QA & Polish

- **Map loading improvements** - Better loading screen UX and error handling
- **General cleanup** - Various QA fixes and optimizations

## Files Changed

- `package.json` - Added CLI npm scripts
- `src/engine/**/*.ts` - Migrated to granular Babylon.js imports
- `src/engine/loader/shader/FilterBlendShaderMaterial.ts` - New filter blend shader
- `docs/research/BABYLONJS_TREE_SHAKING_MIGRATION.md` - Migration documentation
