# v0.6.1 - Loading Screen Smoke Effect

**Release Date:** January 1, 2026

## Summary

Enhanced loading screen with a dreamy colored smoke effect that replaces the previous bottom glow animation.

## Features

### Smoke Animation

Pure CSS smoke effect on the "tap to start" screen:

- **30 colored puffs** rising from the bottom
- Uses brand palette colors (Orange, Yellow, Teal, Pink, Green)
- Each puff keeps its own fixed color
- **Varied sizes**: 40-250px for visual depth
- **Varied speeds**: 8-25 seconds per cycle
- Random horizontal drift and rotation
- Fades out by halfway up the screen
- Heavily blurred for soft, dreamy appearance

### Technical Details

- Pure CSS animation using `@keyframes` and CSS custom properties
- No JavaScript animation loop - GPU-accelerated CSS transforms
- Smooth color transitions via CSS transitions
- Z-indexed layering keeps ripple indicator above smoke

## Visual Style

The smoke creates an ambient, atmospheric background that:
- Draws attention without being distracting
- Cycles through brand colors naturally
- Provides visual interest while waiting for tap

## Files Changed

- `src/engine/ui/LoadingScreen.ts` - Smoke puff generation
- `src/engine/ui/UIStyles.ts` - Smoke CSS animations
