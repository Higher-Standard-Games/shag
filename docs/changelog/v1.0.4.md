# v1.0.4

**Release Date:** unreleased — living changelog

## Changes

- **Weapons fall as rigid bodies.** A dropped weapon is a Havok body the size
  of the gun, thrown on the game server: it tumbles, bounces off the map and
  off other dropped guns, and comes to rest lying as it fell. Snapshots carry
  its position and rotation, so every player and every demo shows the same
  throw. A paused demo or highlight reel holds it still. Before, each client
  invented its own spin, which kept turning while a demo was paused. Map
  weapons are tossed the same way when the map loads. The server, the browser
  and bots land each one at the same position and rotation from the same map,
  checked bit for bit between Node and the browser on washoi_dm2. The map's
  solids for Havok are its BSP brushes, which are convex, plus its curved
  patches, so a gun collides with what players do.
- **Demo format v9** adds how each thrown weapon lies: entity flag `0x80` now
  marks an extension byte, whose bit 0 carries an int16 quaternion. v1–v8
  demos still play; their dropped weapons lie on their side.
