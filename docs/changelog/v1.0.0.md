# v1.0.0

**Release Date:** Nov 20, 2026

The first full release of Washiki Washoi. It is v1.0.0-rc.1 with the change
below; everything before it is in the earlier changelogs, from the alphas
through the release candidate.

## Changes

### Menus and pages

- **Washoi mouse cursors.** The menus, lobby, settings, demo viewer and editor
  use a gold cursor with a black outline and a soft drop shadow, a little
  larger than the system arrow, with matching gold cursors for hover (a
  pointing hand), disabled controls and text fields. A 32 px copy of the same
  art is the fallback where the browser will not draw a larger cursor. Tool
  cursors in the editor (grab, resize, crosshair) stay the system ones.
