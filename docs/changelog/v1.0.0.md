**Release Date:** unreleased — living changelog

## Changes

### Menus and pages

- **Washoi mouse cursors.** The menus, lobby, settings, demo viewer and editor
  use a gold cursor with a black outline, a little larger than the system
  arrow, with matching gold cursors for hover (a pointing hand), disabled
  controls and text fields. A 32 px copy of the same art is the fallback
  where the browser will not draw a larger cursor. Tool cursors in the editor
  (grab, resize, crosshair) stay the system ones.
