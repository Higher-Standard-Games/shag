# v0.8.10 - Graphical Fixes

**Release Date:** 2026-01-05

## Summary

Small graphical fixes release focused on BSP rendering quality improvements.

## Changes

### BSP Lightmap Rendering

- **Fixed lightmap UV alignment artifacts** - Blocky shadow patterns on surfaces are now resolved
  - Changed mesh grouping from texture-only to (texture + lightmap) pairs
  - Each mesh now has exactly one lightmap, ensuring UV2 coordinates always reference the correct lightmap texture
  - Previously, faces with the same texture but different lightmaps were merged, causing lightmap UVs to reference wrong lightmap data

- **Fixed texture application for multi-lightmap meshes** - Textures now correctly apply to all mesh instances
  - Changed `applyTextures` to use `filter()` instead of `find()` to apply textures to all meshes sharing the same texture index
  - Previously, only the first mesh per texture received its diffuse texture

### Technical Details

The root cause was that Q3/Warsow BSP faces are assigned to individual lightmap atlases. When faces with the same texture but different lightmap indices were merged into a single mesh, their UV2 (lightmap) coordinates became invalid because they referenced different lightmap textures.

The fix groups faces by `(textureIndex, lightmapIndex)` instead of just `textureIndex`, producing more meshes but with correct lightmap alignment.
