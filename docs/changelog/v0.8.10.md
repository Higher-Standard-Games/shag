# v0.8.10 - Graphical Fixes & Console Search

**Release Date:** 2026-01-05

## Summary

Graphical fixes for BSP rendering plus new console log search functionality for debugging.

## Changes

### BSP Lightmap Rendering

- **Fixed lightmap UV alignment artifacts** - Blocky shadow patterns on surfaces are now resolved
  - Changed mesh grouping from texture-only to (texture + lightmap) pairs
  - Each mesh now has exactly one lightmap, ensuring UV2 coordinates always reference the correct lightmap texture

- **Fixed texture application for multi-lightmap meshes** - Textures now correctly apply to all mesh instances
  - Changed `applyTextures` to use `filter()` instead of `find()` to apply textures to all meshes sharing the same texture index

### Autosprite/Billboard Support

- **Added Q3 shader autosprite parsing** - `deformVertexes autosprite` and `autosprite2` directives now parsed
- **Implemented per-frame billboard rotation** - Autosprite faces now rotate to face the camera
  - `autosprite`: Full billboard (faces camera on all axes)
  - `autosprite2`: Cylindrical billboard (rotates around Y axis only, like Warsow light halos)
- **Separated autosprite faces into individual meshes** - Required for correct billboard behavior
- **Fixed texture loading for autosprite meshes** - Sprite textures now included in texture loading

### Debug Console Enhancements

- **New `find` command** - Search through console log history with wildcard patterns
  ```
  find BspMeshBuilder       # Find exact matches
  find *Sprite*             # Wildcard search
  find *error* 100          # Limit results
  ```
- **New `log_history` command** - Configure log history size (100-50000 lines, default 5000)
- **Persistent log history** - All console output stored in memory for searching even after scrolling out of view
- **Settings saved to localStorage** - Log history size persists across sessions

- **Shader aim debugging**
  - `shader info` (no args) inspects the surface under the crosshair and prints material + texture bindings
  - `shader aim 1` highlights the aimed surface (outline/edges)

### Technical Details

**Lightmap fix:** Q3/Warsow BSP faces are assigned to individual lightmap atlases. The fix groups faces by `(textureIndex, lightmapIndex)` instead of just `textureIndex`.

**Autosprite:** Vertices are reconstructed each frame to face the camera while preserving texture coordinates. Corner mapping calculated from original vertex positions relative to sprite center.
