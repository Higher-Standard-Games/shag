# v0.8.13 - Bug Fixes

**Release Date:** 2026-01-07

## Summary

Bug fixes for camera system, render variables, and skybox loading.

## Changes

### Camera Fixes

- **Isometric controller** - Fixed `ArcRotateCamera` creation when switching to isometric controller
- **Camera height command** - Now falls back to `CameraSystem.setHeight()` when direct camera access fails

### Render Variables

- **Debug vars not persisted** - `r_wireframe` and `r_showtris` no longer save to localStorage (debug-only)

### Skybox Loading

- **Textured skybox fallback** - Sky shaders without `skyparms farbox` now render as proper infinite-distance skybox
  - Added `loadSkyboxFromTexture` method to `SkyboxLoader` for single-texture skybox
  - `BspMeshBuilder` extracts stage textures from sky shaders
  - `applySkybox` falls back to textured skybox when no cubemap farbox exists

- **Sky sphere rendering** - Use sky sphere instead of cube for single-texture skies (seamless appearance)
  - Create sky sphere texture via canvas for reliable display
  - Use negative scale to flip sphere and `diffuseTexture` correctly

- **PK3 texture loading** - Load textured skybox from PK3 data instead of `pk3://` URL

## Files Changed

- `src/engine/camera/CameraSystem.ts` - Camera height fallback
- `src/engine/camera/controllers/IsometricController.ts` - ArcRotateCamera creation fix
- `src/engine/loader/bsp/BspMeshBuilder.ts` - Sky texture extraction
- `src/engine/loader/bsp/SkyboxLoader.ts` - Textured skybox support, sky sphere
- `src/engine/debug/RenderVars.ts` - Don't persist debug vars
