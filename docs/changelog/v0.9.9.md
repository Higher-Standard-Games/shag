# v0.9.9

**Release Date:** TBD

## Summary

Blade weapon with charged projectile, per-weapon speed modifiers, ragdoll death system, team colors, movement safety fixes (ledge grab ceiling check, walljump fresh press), BSP shader precompilation, hitbox tuning, gib system fixes, cartoon hit effects, and HUD improvements.

## Changes

### Blade Weapon [NEW]

- **Charged energy projectile** — hold fire for 1s to charge, releases `blade_blast` projectile (50 damage, 90 splash radius, 2500 speed)
- **First-person slash animation** — 3-phase melee swing (windup → swing → return) with multiple slash presets cycled per fire
- **Slash trail effect** — red emissive ribbon trail follows blade tip during melee swing, supports multiple concurrent trails with independent fade-out
- **Third-person slash animation** — remote players play `blade_slash` at 2x speed for snappy visual feedback
- **Blade explosion** — 50% scale of rocket explosion with red-themed colors (white-hot core, deep red flames)
- Slash trail suppressed during charged projectile release (only appears on melee swings)

### Per-Weapon Speed Modifiers [NEW]

- **Weapon-specific movement speed bonuses** applied via `speedBonus` field on `WeaponDef`
- **Blade**: +10 speed (410 run) — agile melee
- **Riotgun**: +5 speed (405 run) — light shotgun
- **RL / Electrobolt**: -25 speed (375 run) — heavy weapons
- **All others** (MG, PG, LG, GL, Gunblade, Instagun): 0 (400 run base)
- Server applies speed bonus via `FPSMovementSubsystem.setSpeedBonus()` per entity
- **Client-side prediction sync** — `V2NetworkClient.setSpeedBonus()` mirrors server bonus for correct UPS counter and jitter-free movement

### Keybinds [NEW]

- **Mouse3 (middle click)** added as default bind for crouch/crouchslide (in addition to C and Ctrl)

### Movement Tuning [CHANGED]

- **Sprint speed** increased from 350 → **400** for faster, more cartoonish feel
- **Walljump** retuned: height **280**, bounce **1.2** (more forward push, less upward), boost **1.5**
- **Crouchslide** speed multiplier increased from 1.2 → **1.4** for speed boost while sliding
- **Autosprint fix** — client now correctly transmits inverted sprint bit when `cl_autorun` is enabled

### Walljump — Fresh Press Required [FIXED]

- **No more accidental walljumps during bunny hop** — grounded jump now consumes walljump's `keyReleased` flag, preventing held-space from triggering walljumps when flying past walls
- Player must release and re-press space to walljump (same as Warsow behavior)
- **Prediction parity** — `keyReleased` is preserved during reconciliation reset (not forced to true or false), giving the best approximation of server state and eliminating prediction snaps

### Ledge Grab — Ceiling & Hull Check [FIXED]

- **Upward ceiling trace** — traces from player position to target pull-up height to verify the vertical path is clear; prevents climbing out of map
- **Full player hull traces** — all destination checks (solid, ceiling, standing room) now use the full player bounding box (32×64 AABB) instead of point traces, preventing getting stuck in corners where center is clear but hull clips geometry

### MD3 Normal Map Alignment [FIXED]

- **Weapon normal maps now correctly aligned** — MD3 UVs are V-flipped (`1.0 - v`) during parsing to convert from Quake's bottom-left origin. The normal map texture was authored for the original UV space, so now:
  - Bump texture V sampling is flipped (`vScale = -1, vOffset = 1`)
  - Tangent space axes inverted (`invertNormalMapX/Y`) to correct bump direction
- Eliminates the visible "wrong bumps" on all first-person weapon models

### Shader Precompilation [FIXED]

- **Wall flicker on first projectile fire eliminated** — `EffectPreloader` Phase 2 now force-compiles ALL scene materials (not just BSP) with the PointLight shader variant during map load
- **Render frame settling** — Phase 2 waits a full render frame with the PointLight active before disposing, ensuring the GPU processes compiled shaders. Phase 3 waits another frame for "without light" variant to settle, preventing dirty-flag cascade flicker
- Covers pickup models, weapon models, and all other scene geometry in addition to BSP surfaces

### Cartoon Hit Effects [NEW]

- **Warsow-style POW! sprites** — billboard sprites spawn at victim's position on hard hits (damage ≥ 75)
- Randomly selects from `cartoonhit1.png` / `cartoonhit2.png` sprites
- Grows from 80% → 110% scale with overshoot pop, fades over 800ms

### Speedometer [FIXED]

- **HUD attachment timing** — waits for HUD container before creating element
- **Orphan detection** — checks `isConnected` for spectator mode re-creation
- **`cl_showspeed`** now defaults to **1** (on)

### Walljump & Ledge Grab — Angled Wall Detection [FIXED]

- **Walljump on 45° walls** — bounded box traces (8×32×8), 8 trace directions, relaxed velocity threshold
- **Ledge grab on 45° ledges** — 5-direction fan (forward + ±30° + ±60°), picks closest wall hit

### Ragdoll Death System [NEW]

- **Per-bone Havok ragdoll** — 15-bone skeleton with joint limits for stiff-body feel
- **Directional knockback** — explosions push from blast center, hitscan in shot direction
- **Speed trail** — team-colored TrailMesh on hips bone, fades over 1s
- **Reduced gravity** — 0.4× per-bone for floatier arcs
- **Lifecycle**: 5s simulation → fade-out → gib explosion, max 4 simultaneous

### Team Colors [NEW]

- **PBR albedoColor tinting** — material cloning with HDR color multiplication
- **Alpha**: bright teal/cyan · **Bravo**: neon hot pink
- Currently uses entity ID hash (TODO: wire to server team data)

### Player Hitbox & Eye Level [CHANGED]

- Hitbox: 56 → **64 units** tall (PLAYER_MAXS_Z: 32 → 40)
- Eye level: 26 → **34 units**, PLAYER_MINS_Z kept at -24

### Remote Player Rendering [FIXED]

- **Player model disappearing after kill** — `markAlive()` on respawn events
- **Animation speed** — `playOnce()` accepts `speedRatio` for tunable playback

### Gib System [FIXED]

- Wrong scene reference → `CameraSystem.getCamera().getScene()`
- Stale singleton re-initialization, fresh mesh per gib

### Player-Player Collision [IMPROVED]

- Symmetric pair resolution with velocity clipping along collision normal

### Walljump Collision Desync [FIXED]

- Reconciliation skip during walljumps + 10-cycle cooldown, prevents cumulative camera desync

## Technical Notes

- Weapon speed: `WeaponDef.speedBonus` → `MovementProfile.wishspeed`. Server: `WeaponSystem → FPSMovementSubsystem.setSpeedBonus()`. Client: `V2NetworkClient.setSpeedBonus()` on `weapon_state` sync.
- BSP shader fix: `forceCompilation(mesh, callback)` needs actual mesh for vertex attributes. Temporary PointLight range=999999 forces "has lights" variant.
- Team colors: PBRMaterial `albedoColor` × albedoTexture. HDR >1.0 for vivid looks.
- Scene reference: use `CameraSystem.getInstance().getCamera()?.getScene()` not `EngineStore.LastCreatedScene`.
