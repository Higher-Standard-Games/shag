# v0.9.9

**Release Date:** TBD

## Summary

Team colors, hitbox tuning, gib system fixes, projectile spawn tuning, and player collision improvements.

## Changes

### Team Colors [NEW]

- **PBR albedoColor tinting** — Remote player models are tinted with team colors using material cloning and HDR color multiplication
- **Alpha team**: Bright teal/cyan (blue-biased to compensate for warm base texture)
- **Bravo team**: Neon hot pink
- `PlayerModelManager.applyTeamColor(instance, team)` — new API for applying team colors to any player model instance
- Currently uses entity ID hash for team assignment (TODO: wire to actual server team data)

### Player Hitbox & Eye Level [CHANGED]

- Player hitbox increased from 56 → **64 units** tall (PLAYER_MAXS_Z: 32 → 40)
- Eye level / viewheight raised from 26 → **34 units** (closer to model's actual eyes)
- PLAYER_MINS_Z kept at -24 to preserve step climbing behavior
- Updated all related constants across physics, collision, weapon, debug, and movement cvar systems

### Gib System [FIXED]

- **Wrong scene reference** — GibSystem, DamageNumbers, DroppedWeaponRenderer, and ProjectileManager were all initializing with `EngineStore.LastCreatedScene` which returned the UI scene instead of the gameplay scene. Replaced with `CameraSystem.getCamera().getScene()`
- **Stale singleton** — `GibSystem.init()` now allows re-initialization when scene changes (disposes old resources, creates new)
- **Mesh clone issue** — Replaced `templateMesh.clone()` with fresh `createTriangleMesh()` per gib to avoid vertex buffer sharing problems

### Projectile Spawn [TUNED]

- Projectile spawn Y offset adjusted from viewheight (34) to **31** (between eye level and muzzle) for better crosshair alignment

### Player-Player Collision [IMPROVED]

- Upgraded from one-sided post-movement nudging to **symmetric pair resolution**
- **Velocity clipping** along collision normal — players lose speed on contact (like wall collisions in Q3)
- Updated PLAYER_MAX_Y from 32 → 40 to match new hitbox
- Cascading position updates for correct multi-player resolution

### Walljump Collision Desync [FIXED]

- **Reconciliation skip during walljumps** — Mirroring the existing ledge grab pattern, V2NetworkClient now skips Q3-style reconciliation during active walljumps + 10-cycle cooldown (~0.33s at 30Hz), preventing cumulative camera desync from replayed wall traces

## Technical Notes

- Team color approach: PBRMaterial `albedoColor` multiplies with albedoTexture. HDR values >1.0 produce vivid, glowing looks. Blue channel biased higher for teal to counteract warm brownish base texture.
- Mask-based approach (vanguard_team_mask.png generated) available for future refinement where only specific UV regions get tinted.
- Scene reference fix: `EngineStore.LastCreatedScene` is unreliable when multiple scenes exist (game + UI). Always use `CameraSystem.getInstance().getCamera()?.getScene()` for gameplay scene.
