# v1.0.1

**Release Date:** unreleased — living changelog

## Changes

- **Hosted build for itch.io** (`npm run build:itch`, `build:itch-staging`). It
  opens on a region picker (the regions in washoi.net's `/regions.json`, with
  their ping and the nearest marked), then plays against that region's lobby
  and loads `/data/` from its host. The build carries no game data and keeps
  the account key in memory only. The staging build adds a "Local" region for
  testing against a local lobby, also from an itch.io draft page. Nothing
  changes for the web build.
- **Dev server:** its `/data/` route sends CORS headers to local origins and
  `https://html-classic.itch.zone`, and it no longer watches the hosted build
  folders (a rebuild there stopped it).
