# v1.0.1

**Release Date:** Nov 20, 2026

## Changes

- **Hosted build for itch.io** (`npm run build:itch`, `build:itch-staging`). It
  opens on a region picker, washoi.net's /play launcher as the native client
  draws it (the dot-matrix world, a pin, ping and Nearest per region, the
  regions from washoi.net's `/regions.json`), then plays against that region's
  lobby and loads `/data/` from its host. The build carries no game data and
  keeps the account key in memory only. The staging build adds a "Local"
  region when served from this machine. A ✕ plate in the lobby's top-right
  corner goes back to the itch.io page, which itch.io's full-window mode
  offers no way to do; the game's own reloads (after a match, a region
  switch) replace their history entry, so Back still does that. Nothing
  changes for the web build.
- **Hosted build accounts:** the key is never stored. The lobby hands a hosted
  build a login token per region (`auth` `hosted`/`token`, `welcome.token`),
  replaced at every login; a replaced token that comes back after 60 seconds
  ends its chain (`token_reused`), and logging in with the key ends the
  account's other chains on that host. `players.db` goes to schema version 2
  (`hosted_tokens`); `lobby:server --revoke-tokens <host>` drops a host's
  tokens. The welcome guide gets a last step, "Your account", with the key (blurred
  until shown) to copy or save as a file. Every client shows it; a hosted build
  only in the session that made or pasted the key.
- **Room codes, all clients:** a room shows its code (`eu:3fa9c2d1`) with Copy
  code beside the link; Join lobby via invite, at the foot of the Play page, takes a code or a room
  link from any region, and chat messages naming a room get a Join key. A room
  in another region switches region first. The hosted build shows no links.
- **Copying works inside itch.io's frame:** the key, room codes and links and
  the boot diagnostic fall back to `execCommand("copy")` when the Clipboard
  API is blocked.
- **Hosted build hardening:** the package index stays in memory, the
  account's synced settings win over the browser's on login, and links to
  other sites open in a new tab.
- **Dev server:** its `/data/` route sends CORS headers to local origins and
  `https://html-classic.itch.zone`, and it no longer watches the hosted build
  folders (a rebuild there stopped it).
