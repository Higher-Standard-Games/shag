# v0.9.7

**Release Date:** 2026-02-23

## Summary

Spectator mode, movement simulation refactor, and HUD polish. Full freefly camera spectating with `J` to join, improved crosshair/pickup suppression during spectate and pause, and Washiki-themed spectator panel with responsive scaling.

## Changes

### Spectator System (SpectatorOverlay.ts) [NEW]

- **Freefly spectator mode** — WASD + mouse free camera with Shift for speed boost; activates on connect before joining
- **Spectator HUD panel** — Washiki-themed key binding panel (3×2 grid layout) with corner brackets and orange neon accents; aligned with health/armor bars
- **Responsive scaling** — All spectator panel dimensions use `calc(... * var(--ui-scale, 1))` for resolution independence
- **Join/spectate dialog** — Washiki-styled dialog with `J` to join game, `ESC` for menu
- **Spectator-aware ready bar** — Shows "SPECTATING" text when in freefly mode; shows ready counter only for joined players

### HUD Improvements

- **Phase message + ready bar repositioned** — Moved from screen center to just below clock/frags bar (`top: 76px` / `top: 120px` scaled); placed in `top-center` HUD zone instead of `center`
- **Phase title downsized** — Reduced from 52px to 28px font for less intrusive warmup/phase display
- **Crosshair hidden during pause** — `pointerlockchange` listener hides crosshair when pointer lock is released (ESC menu)
- **Pickup prompts suppressed** — Suppressed during spectator mode and pause menu to prevent phantom UI
- **Pickup toast theme** — Orange palette matching Washiki HUD accents

### Movement Simulation Refactor

- **Movement modules extracted** — Split monolithic `FPSMovementProfile.ts` into focused modules:
  - `MovementConfig.ts` — Centralized movement constants and configuration
  - `MovementProfile.ts` — Core movement profile with ground/air physics
  - `Acceleration.ts` — Q3/CPM acceleration logic
  - `Slide.ts` — Slide mechanics
  - `WallJump.ts` — Wall jump detection and execution
  - `LedgeGrab.ts` — Ledge grab system
  - `Vec3Helpers.ts` — Vector math utilities

### Network & Protocol

- **Spectate message type** — Added `spectate` message to binary protocol for client→server spectator state
- **JoinGame message type** — Added `joinGame` message for transitioning from spectator to player
- **Bot/remote player visibility** — Fixed entity rendering during spectator mode

### Engine Changes

- **FPSController** — Scoped mouse events to canvas; speedometer cleanup on spectate transition
- **CameraSystem integration** — Ready bar uses `CameraSystem.getActiveController()` to detect freefly vs FPS mode

## Technical Notes

- **Architecture:** `SpectatorOverlay` is a standalone class instantiated by `FPSGameManager`. It manages its own DOM elements (freefly cue panel, join dialog) and listens for camera controller changes.
- **HUD zones:** Phase message and ready bar use `position: fixed` with explicit `top` values. They must be in `top-center` zone (not `center`) to avoid the center zone's `top: 50%` layout overriding their positioning.
- **Feature branches:** `feature/spectator` (shag parent repo), `feature/spectator` (fps submodule)
