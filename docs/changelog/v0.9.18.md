## Changes

### In-Game Chat [ADDED] — feature/ingame-chat

Plan + decisions: `docs/research/ingame-chat.md`.

- **Wire**: `MessageType.Chat (0x89)` client→server (reliable); server sanitizes (control-char filter, whitespace collapse, 128-char cap) and rate-limits (600ms min interval + 5-per-5s burst, drops log-only) then rebroadcasts as a `chat` snapshot one-shot event (`senderId, senderName, team, text` — self-contained for demos). No local echo (Q3): your message appears on the round-trip.
- **Talk mode**: T opens (only in gameplay: pointer locked, no menus/console), Enter sends, Esc cancels. New `InputSystem` text-field guard — game binds don't fire while any text input has focus (keyup still clears held keys). Mouse look keeps working while typing.
- **History dialog**: one 100-message store; closed = last 5 as a fading overlay (8s); talk mode expands into a scrollable washoi print-slab dialog (navy scan panel, cyan edge-bar, gold SAY stamp, sender stamps team-colored udon-cyan/soba-magenta, `[SPEC]` prefix + dim for spectators). Renderer uses `textContent` (XSS-safe; the codec is transparent by design).
- **Demos**: recorded automatically (post-D16 shared snapshot instance); `DemoService` replays chat at the recorded ticks through a read-only chat widget. Regression: a queued chat appears exactly once in a recorded frame (real scheduler over a fake transport).
- Deferred (noted in the research doc): team chat / Y say_team (needs per-client event filtering in the broadcaster), mute/ignore, chat commands, sounds (no audio system usage game-wide yet).
