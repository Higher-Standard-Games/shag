# v0.9.8

**Release Date:** 2026-03-03

## Summary

Remote player rendering fully operational. Players visible as animated 3D models (vanguard.glb) with movement-driven animation state machine. Fixed two critical rendering bugs: `EngineStore.LastCreatedScene` returning the wrong scene, and BinaryProtocol losing rotation data when only position changed. Crouch state transmitted over the network. Wireframe hitboxes toggleable via `cl_remotehitbox`.

## Changes

### Remote Player 3D Model Rendering [NEW]

- **PlayerModelManager integration** — `RemotePlayerRenderer` now loads `vanguard.glb` via `PlayerModelManager`, creating cloned instances per remote player with independent skeleton and animation state
- **Animation state machine** — Derives animation from network data (velocity, grounded, yaw):
  - `idle` (speed < 50), `walk` (50–300), `run` (300+), `jump` (airborne + vy > 50)
  - `strafe_l` / `strafe_r` when lateral movement exceeds forward by 1.5×
- **Speed ratio scaling** — Walk/run animation playback speed scales to match actual movement; backward movement reverses playback
- **Root motion reset** — Mesh position and rotation zeroed each frame to prevent animation drift
- **Weapon stub** — `weaponMesh` and `currentWeaponId` fields prepared for future weapon-in-hand rendering

### Remote Player Rendering [FIXED]

- **Scene reference fix** — `FPSGameManager` was using `EngineStore.LastCreatedScene` which returned the `LogoCanvas` scene (3D lobby logo) instead of the gameplay scene. Fixed by using `CameraSystem.getInstance().getCamera()?.getScene()`
- **Wireframe hitbox rendering** — Green wireframe boxes sized to Q3 hitbox dimensions (32×56×32 standing, 32×36×32 crouching), toggleable via `cl_remotehitbox` cvar
- **Rotation loss fix** — `BinaryProtocol` decode path lost rotation when position changed (flag `0x01`) without rotation delta (no `0x08`): the entity was freshly created, so `existingTransform` was null and rotation defaulted to yaw=0. Now falls back to `baselineTransform.rotation`

### Crouch State Over the Wire [NEW]

- **BinaryProtocol flag 0x10** — Transmits `isCrouching` and `isSliding` as packed booleans (1 byte)
- **SnapshotBuffer integration** — `crouching` field in `EntitySnapshot` and `InterpolatedEntity`, carried through `lerpEntity()` and extrapolation
- **Hitbox height switching** — Mesh rebuilt on crouch/uncrouch (56→36 units)

### Known Bugs Documented

- **Walljump collision desync** — Critical: walljumps cause rendering/collision mismatch. Documented in `docs/known_bugs.md`

## Technical Notes

- **`EngineStore.LastCreatedScene` hazard:** Any lazy-initialized renderer using this global may render to the wrong scene. Audit: `DroppedWeaponRenderer`, `GibSystem`, `DamageNumbers`, `ProjectileManager`
- **BinaryProtocol rotation baseline:** Delta encoding must fall back to baseline rotation, not zero, when building fresh entities with only position deltas
- **Feature branch:** `feature/remote-player-hitbox`
