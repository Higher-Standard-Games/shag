# v0.9.8

**Release Date:** 2026-03-03

## Summary

Remote player rendering fully operational. Players visible as animated 3D models (vanguard.glb) with movement-driven animation state machine including Warsow-style jump animation. Fixed three BinaryProtocol delta encoding bugs (rotation loss, grounded loss, baseline fallback). Sprint restricted to forward-only. Debug console close button added.

## Changes

### Remote Player 3D Model Rendering [NEW]

- **PlayerModelManager integration** — `RemotePlayerRenderer` loads `vanguard.glb` via `PlayerModelManager`, creating cloned instances per remote player with independent skeleton and animation state
- **Animation state machine** — Derives animation from network data (velocity, grounded, yaw):
  - `idle` (speed < 50), `walk` (50–300), `run` (300+), `jump` (all airborne)
  - `strafe_l` / `strafe_r` when lateral movement exceeds forward by 1.5×
- **Speed ratio scaling** — Walk/run/strafe playback speed scales to match actual movement speed, eliminating foot sliding. Natural speed constants tuned to Q3 game speeds (walk=40, run=100, strafe=29)
- **Warsow-style jump** — Ascending plays forward to tucked pose, peak freezes, descending reverses back to extended. Driven by vertical velocity, non-looping
- **Root motion reset** — Mesh position/rotation zeroed each frame to prevent animation drift
- **Weapon stub** — `weaponMesh` and `currentWeaponId` fields prepared for future rendering

### Remote Player Rendering [FIXED]

- **Scene reference fix** — `FPSGameManager` using `EngineStore.LastCreatedScene` returned wrong scene. Fixed with `CameraSystem.getInstance().getCamera()?.getScene()`
- **Wireframe hitbox rendering** — Green wireframe boxes (32×56×32 standing, 32×36×32 crouching), toggleable via `cl_remotehitbox` cvar
- **Rotation loss fix** — Decoder lost rotation when position changed without rotation delta. Falls back to `baselineTransform.rotation`
- **Grounded state loss fix** — Decoder lost `grounded` when velocity changed (flag `0x02`) without grounded flag (`0x04`): baseline grounded was only read in the `else if` branch. Now always reads baseline grounded first

### Movement [CHANGED]

- **Sprint forward-only** — Sprint speed (350) only activates when holding +forward. Strafing (A/D) and backward (S) capped at walk speed (280)

### Crouch State Over the Wire [NEW]

- **BinaryProtocol flag 0x10** — Transmits `isCrouching` and `isSliding` as packed booleans
- **SnapshotBuffer integration** — `crouching` field carried through interpolation and extrapolation
- **Hitbox height switching** — Mesh rebuilt on crouch/uncrouch (56→36 units)

### Debug Console [IMPROVED]

- **Close button** — ✕ button in header bar for closing console without keyboard (essential for Mac/non-US keyboard layouts)
- **Diagnostic spam removed** — Removed per-frame render logging from `RemotePlayerRenderer`

### Walljump Collision Desync [FIXED]

- **Reconciliation skip during walljumps** — Walljumping caused cumulative camera desync (view clipping through floor). Root cause: V2NetworkClient's Q3-style reconciliation replayed inputs through a fresh WallJump state machine, but wall traces hit at slightly different sub-tick positions after server reset. Each walljump compounded the error. Fixed by skipping reconciliation during active walljumps + 10-cycle cooldown (~0.33s), mirroring the existing ledge grab pattern.

## Technical Notes

- **BinaryProtocol delta encoding pattern:** Three separate baseline fallback bugs found — rotation, grounded, and position all had cases where baseline data wasn't preserved when only some flags changed. The decoder must always read baseline values BEFORE checking specific flags
- **Reconciliation skip pattern:** Both ledge grabs and walljumps require skipping Q3-style reconciliation during execution. The MovementProfile's sub-tick state machines (wall traces, grab detection) produce non-deterministic results when replayed from slightly different server-reset positions. Pattern: set skip counter while active, decrement after, resume reconciliation once normal movement converges.
