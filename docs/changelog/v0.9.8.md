# v0.9.8

**Release Date:** TBD

## Summary

HUD architecture refactoring — monolithic `FPSHud.ts` (2,582 lines) split into 19 focused widget modules. Cleaner file structure and naming for improved maintainability.

## Changes

### HUD Widget Extraction [REFACTOR]

- **Widget module system** — Extracted 19 inline widget classes from `FPSHud.ts` into individual files under `client/hud/widgets/`, reducing `FPSHud.ts` from 2,582 to 396 lines (−85%)
- **Shared interface** — `HudWidget.ts` extracted as standalone interface file to break circular dependencies between `FPSHud` and widget implementations
- **Clean file naming** — Dropped redundant `FPS` prefix from widget filenames (e.g., `FPSValueBar.ts` → `ValueBar.ts`) since they're already scoped under `fps/client/hud/widgets/`
- **Cross-widget exports** — `WEAPON_SLOTS` constant exported from `WeaponRack.ts` for reuse in `PickupToast.ts`

### Bug Fixes

- **UTF-8 encoding fix** — Repaired double/triple-encoded Unicode characters (♥, 🛡, —, →, ✓, ✕, ∞, ⬡) corrupted during automated file extraction

## Technical Notes

- **Architecture:** `FPSHud.ts` retains the HUD manager (container, layout, widget lifecycle, update loop). Individual widgets are self-contained classes implementing the `FPSHudWidget` interface with `getElement()`, `update()`, `show()`, `hide()`, `destroy()`.
- **Feature branch:** `refactor/file-splits`
