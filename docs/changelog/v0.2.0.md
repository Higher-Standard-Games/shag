# v0.2.0

**Release Date:** December 28, 2025

## Summary

UI Scaling System and Generic HUD Framework - a major update focused on cross-platform UI consistency.

## Major Features

### UIScale System
- Cross-platform UI scaling with CSS variables
- Reference resolution scaling (1920x1080 base)
- Scale modes: fit, fill, width, height
- Safe area insets for mobile devices
- Minimum touch target enforcement (44px)

### HUD System
- Declarative, data-driven HUD with JSON configuration
- Components: Pill, PillProgress, PillGroup, Button, Accordion
- 100ms update loop with dirty checking
- Theme support (default, dark)
- User preference persistence (collapsed state, hidden elements)
- List bindings with custom item renderers

### CLI Commands
- `ui scale <value|auto>` - Set UI scale factor
- `ui mode <fit|fill|width|height>` - Set scale mode
- `ui debug` - Toggle debug overlay
- `ui info` - Show current scale info
- `hud info` - Show HUD status
- `hud interval <ms>` - Set update interval
- `hud show/hide/toggle <id>` - Element visibility
- `hud theme <name>` - Switch themes
- `hud collapse/expand <id>` - Accordion control
