# v1.0.5

**Release Date:** unreleased — living changelog

## Changes

### Engine: diorama rendering building blocks (not wired in)

New modules for an HD-2D style game, added as files that nothing in the
engine or in Washoi imports yet, so no existing rendering changes. A game
opts in by constructing them.

- `src/engine/effects/DioramaPostProcess.ts`: depth-based tilt-shift, height
  haze, colour grade, lookup tables, a shaped and coloured vignette and grain,
  in one pass.
- `src/engine/effects/GradeProfiles.ts`: named colour-grade profiles that
  blend by weight from a base profile, distance zones and faded layers.
- `src/engine/lighting/CasterShadowMap.ts` and
  `src/engine/loader/bsp/BspCasterShadowPlugin.ts`: a real-time shadow map
  for sprites and props cast onto lightmapped BSP surfaces, with drifting
  cloud shadows and normal-map relief under the sun.
- `src/engine/sprites/LitSprite.ts`: pixel-art sprites lit from the BSP light
  grid.
- `src/engine/effects/LightShafts.ts`, `SmokePlumes.ts`, `StylizedWater.ts`:
  placed light beams, GPU-animated chimney smoke and a stylised water surface
  with shore foam.
- `src/cli/blockmap/` and `npm run blockmap`: compiles a JSON box map
  (with stairs and arches) to an IBSP with baked lightmaps, light grid,
  occlusion and collision.
