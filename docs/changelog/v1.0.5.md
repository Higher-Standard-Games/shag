# v1.0.5

**Release Date:** unreleased — living changelog

## Changes

- **Dependency security update.** `npm audit` drops from 61 findings (5
  critical, 33 high) to 21, none in what players or servers run. Updated
  within their majors: `ws` 8.23, `vite` 6.4.6, `vitest` 3.2.7,
  `@modelcontextprotocol/sdk` 1.32.2, `@gltf-transform/cli` 4.5.1,
  `electron-builder` 26.18, `concurrently` 9.2.5, and transitive fixes from
  `npm audit fix` (`axios`, `undici`, `body-parser`, `lodash`, `js-yaml`,
  `markdown-it`, `postcss`, `shell-quote`, `tmp` and others). Electron moves
  to 45. An override lifts `ts-trueskill`'s `mathjs` to 15.2; 200 random
  matches rate bit for bit as they did on mathjs 13.
- `sharp`, `vite-node` and `@types/node` (24, the Node major production runs)
  are declared dependencies. Map texture packaging, every vite-node script and
  the type check used them only through other packages. The type check's
  `lib` is ES2022, which declares the `.at()` the code already calls; the
  emitted target stays ES2020.
- vite-node runs a script outside the tree again, such as a test helper in the
  system temp directory. Vite 6.4.6 applies the dev server's file allow list
  to vite-node as well; vite-node now lifts it, and the dev server keeps it.
- What `npm audit` still reports is in development tools only, with no fix
  inside their current majors: vitest 3 (its worker pool and mock server),
  vite 5 and esbuild 0.21 inside VitePress 1, mermaid 11's KaTeX, and
  `minimatch`/`glob` inside electron-builder, typedoc and gltf-transform.
