# v0.9.31

**Release Date:** unreleased — living changelog

## Summary

The v0.9.31 papercuts cycle builds on v0.9.30, reducing collision tracing work,
correcting ramp support and ledge traversal, and improving fence and teleporter
shader compatibility. Arc Blade adds updated visuals and movement-aware lunges;
fullscreen gameplay protects movement shortcuts with optional Keyboard Lock.

## Changes

- Dedicated server map loading skips render vertices, lighting and mesh data,
  and releases temporary PK3 archive ownership after indexed extraction. PVS
  owns a compact buffer instead of pinning the raw BSP. Authoritative collision,
  patch controls and visibility retain parity with the full map parser.

- Dedicated and lobby servers use Node 24 or newer by default, with experimental
  `:bun` alternatives and matching runtime inheritance for spawned matches. Production server
  bundles remove per-match Vite/npm/shell overhead. Memory benchmarks, runtime
  equivalence and real lobby/match/result probes make these changes measurable.
  Owned child shutdown finishes recordings before the forced-kill fallback.

- Fixed point traces missing patch cap centers and shared edges. Collision
  tessellation preserves flat coordinates, bevels retain the facet backing
  thickness, and packed planes keep enough precision for rotated and translated
  patch seams. Native round-preset QA covers both point and small-hull contacts.

- SHAGGED adds cylinder, hollow tube, cone and disk-cap patch presets, with
  thickness, end caps, reversed winding, multi-surface previews and grouped
  placement. MCP exposes the same shapes as `patch.round`. Native patch export
  now writes column-major control grids, fixing compiler failures on non-square
  patches such as arches. Historical editable sidecars remain recoverable.

- SHAGGED clips/splits brushes by a numerical plane and subtracts box or convex
  cutters from selected brushes. MCP exposes `brush.clip` and `brush.subtract`;
  existing carve/doorway operations also cut convex geometry. Cuts preserve
  surviving face mappings, ownership, editor groups and undo. Previously
  overlapping convex brushes blocked carve and doorway generation.

- Restored Proving Grounds (`wdm2`) to the Duel map pool.

- SHAGGED supports Ctrl/Cmd-click multiple selection, 2D marquee selection and
  named editor groups. Move, duplicate, delete and frame mixed selections of
  brushes, patches and point entities with undo. Groups survive local/server
  saves without changing compiler geometry or brush entity ownership. MCP can
  create, inspect, move, duplicate and ungroup them. Previously objects had to
  be selected and moved individually.

- SHAGGED locks brush textures during movement, duplication, rotation, bounds
  resizing and vertex edits. Skew preserves mappings produced by non-uniform
  deformation, and mirrored textures retain their orientation. Legacy fixed
  mappings remain locked without claiming known image dimensions. Previously
  geometry edits could slide or rotate the texture independently of the brush.
  The bounds inspector also accepts fractional coordinates produced by rotation.

- Convex brush faces can be Shift-picked, Alt-sampled and textured individually
  in SHAGGED. Numbered side buttons and polygon highlights expose the selection;
  shift/scale/rotation, Fit, Natural and Wrap work on angled faces using their
  actual planes. Previously the graphical alignment workflow only handled boxes.

- SHAGGED has a graphical Vertices tool (G) for boxes and convex brushes:
  drag projected vertex groups, select individual corners, enter exact positions
  or move several together. Edits rebuild a convex solid with undo, preserve
  side materials and reject collapsed geometry. MCP exposes the same edit as
  `brush.vertices`.

- SHAGGED supports convex solids, polygon prisms and brush rotation for diagonal
  bridges, wedges and reactor platforms. Editor previews show the real shape;
  ownership, bounds edits, undo and compiler export retain it. Malformed
  convex edits reject atomically. Compiler collision-only placeholder warnings
  are checked against BSP draw usage instead of blocking valid bevels.

- SHAGGED boxes and generators support natural texture alignment with automatic
  image-size lookup, avoiding the tiny repeats seen in the first Relay Yard
  prototype. Existing scripts keep their alignment; room joins preserve old
  wall materials. Texture catalogs respect the configured media root.

- SHAGGED recognizes compiler-only brush groups and projected decal/text
  entities, documents their keys and distinguishes them from runtime classes
  in MCP discovery instead of reporting them as unlisted classes.

- SHAGGED MCP and CLI discover packaged and loose prop models, with searchable
  paths, ownership and optional ASE/OBJ mesh or MD3 frame dimensions.

- SHAGGED MCP and CLI inspect installed reference maps through the package
  index, exposing world bounds, spawns and paged material usage by face count.

- Development and CI use Node.js 24, the minimum supported version; setup
  documentation no longer directs contributors to Node.js 22.

- SHAGGED MCP and CLI can read complete authoring snapshots and query objects
  by region, kind or ID with stable pagination and brush ownership. Inspection
  includes patch controls and face alignment; edits can reject stale revisions.

- SHAGGED coordinates native builds, source saves, MCP edits and publication
  across local processes. Reuse now checks compiler, recipe, profile and media
  contents; explicit forced rebuilds are available through CLI, MCP and HTTP.
  Changing inputs during compilation blocks publication of an inconsistent build.

- SHAGGED compile jobs retain complete transcripts and durable status, expose
  native phases and warning summaries through MCP, and block publication when
  native tools report missing assets, errors or leaks despite a zero exit code.

- Relay Yard now has recessed slime basins with escape steps and dry routes,
  crossing reactor underpasses, original wfdm5 lamps and architectural props,
  projected signage, loose paving, service machinery and a layered skyline.
  Its oversized prototype was reduced by 25% on each axis; solid decorative
  brushes use compiler detail classification.

- SHAGGED box operations can mark decorative brushes as detail geometry,
  preserving their material collision while keeping trim out of structural
  visibility partitioning. The flag survives carving and map export.

- SHAGGED scripting and MCP can edit validated worldspawn settings with
  `world.keys`, preserving map atmosphere and compiler lighting keys in exports.

- SHAGGED accepts compiler-native ASE prop references, making the original
  Warfork map detail collection available to scripted maps. ASE appearance is
  reviewed in compiled playtests; browser mesh preview is not provided.

- The Amphi lobby pool offers Relay Yard alongside wamphi1 for testing, replacing
  the DA arenas. Numbered SHAGGED map packages are recognized by their base map
  name, keeping newly compiled revisions selectable.

- Added the reproducible Sol Amphi 1 / Relay Yard mapping experiment: a compact
  two-level industrial arena authored through SHAGGED MCP, with wfdm5 materials,
  a reactor, offset fighting decks, Warfork props and a surrounding night skyline.
  Source, edit batches, validation reports and previews are kept under
  `experiments/shagged/solamphi1/`.

- SHAGGED prepares the tracked Washoi compiler profile beside repository-local
  MakeBSP/MakeLight binaries, where those tools actually look for profiles.
  This prevents a silent QFusion fallback that searched the wrong media folder
  and could publish maps with missing props and incorrect shader treatment.

- SHAGGED's scripting and MCP edit API can create curved `patchDef2` surfaces
  through `patch.create`, with document validation and atomic batch rollback.
  This supports the Sol Amphi mapping experiment's curved reactor geometry.

- Fullscreen gameplay requests Keyboard Lock for bound movement keys in
  supporting browsers, protecting against accidental Ctrl+W tab closes. Capture
  releases for menus, typing, focus loss and fullscreen exit; Escape stays free.

- Blade swings step forward only while forward is held and the player is
  already moving forward. Stationary swings, backward motion and sideways-only
  motion no longer cause an unwanted lunge; forward diagonals still qualify.

- Replaced the Blade model with Arc Blade, preserving its authored PBR metal,
  normal and energy-emission textures. Its export length matches the previous
  blade, and it uses the existing first-person pose, procedural swings and
  charge effects. Artist attribution is included in the weapon package manifest.
- Made Arc Blade metal readable with a dedicated specular light tinted by BSP
  lighting. Charging grows a turquoise outline from 0.6 to 4.8 world units;
  swing trails use light grey instead of the previous red silhouette, with
  much lower opacity and feathered edges for a softer motion streak.
- Matched Blade projectile, tail, impact and pickup effects to its teal energy
  colour. Swing flashes linger twice as long and include a smaller spark near
  the model's tip, with slight random placement variation.
- Corrected the Blade projectile's solid square glow by masking its teal tint
  with the source texture.

- Retained the wfdm5 teleporter's star-field environment background as a
  separate shader pass beneath its blended centre and animated shine. Added
  `surroundmap` stage handling and ordered texture-cubemap branch selection.
- Corrected back-side deluxe diffuse lighting on two-sided fences. Vertex-lit
  metal material stages can receive game lights and gloss while preserving
  authored baked shadows; BSP `lightingDiffuse` retains vertex lighting.
- Documented the wfdm11 stair collision investigation and a staged plan for
  cheaper tracing and collision geometry that preserves intended movement.
  The plan requires a validated commit checkpoint after every feature.
- Added a headless collision-route benchmark with exact baseline comparisons
  for standing/crouched hulls, point traces, steps and ground probes.
- Sweep collision visits each static surface/brush once per query, avoiding
  repeated facet/plane tests when a hull overlaps multiple BSP leaves or a clip
  brush also appears in the fallback scan.
- Collision shader properties are prepared at load time, and face eligibility
  is checked before iterating triangles instead of repeating name/flag parsing
  for every facet.
- Static brush plane tests now have conservative bounding-box rejection. A
  spatial index limits the clip-brush fallback to nearby candidates while
  retaining brushes that lack provable bounds or BSP leaf references.
- Patch-facet collision uses a static BVH of conservative facet bounds instead of
  testing every triangle in an overlapping draw surface. Candidate order and
  the existing plane solver are preserved, including embedded contacts.
- Collision preprocessing identifies strictly contained compatible static
  brushes and skips their plane tests for hulls starting outside the containing
  brush. Embedded recovery and canonical BSP/point-content data are retained.
- Sweep collision now uses authored BSP brushes and patch collision, removing
  extra colliders generated from triangle-soup draw surfaces. Decorative draw
  geometry no longer adds contacts or tracing work to independently clipped maps.
- Fixed repeated ground loss while walking up smooth ramps. Uphill support now
  uses the walkable contact plane and movement direction, preserving support
  without requiring a fresh impact each tick. Jumps and slide bumps moving away
  from the floor remain airborne.
- Patch collision indexing retains partial bounds instead of testing a facet
  unconditionally whenever one axial constraint is missing. Proven bounds cull
  distant facets while uncertain directions remain unbounded; contact geometry
  and source ordering are preserved.
- Reduced temporary allocation in collision queries by reusing spatial candidate
  buffers and query bounds, and using scalar brush-plane offsets. Returned
  contacts remain independently owned by their caller.
- Fixed ledge detection failing on reachable diagonal and curved walls: targets
  now use the actual wall contact and projected standing-hull width. Pull-up
  lifts clear of the lip before moving inward instead of passing through the
  wall. Obstructed grabs release with a brief retry delay rather than freezing
  against the obstruction.

## Validation and remaining limits

The final source checkpoint passes typechecking, 4,964 tests (one skipped),
Biome, production build, simulation/physics tests, server tick/fuzz checks,
headless map/replay checks and the engine documentation build. Teleporter
environment passes were checked on WebGL2 and WebGPU.

Some metal frame vertices contain black baked lighting in the map itself;
that data remains intact. The exact prolonged corner-hanging report and full
ledge-state reconciliation still need further live validation. Detailed
evidence and limitations are in the research notes for
[ledge corners](../research/v0.9.31-ledge-corner-collision.md) and
[fence/environment shaders](../research/v0.9.31-fence-environment-shaders.md).
