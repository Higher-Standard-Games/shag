# v0.9.31

**Release Date:** unreleased — living changelog

## Summary

The v0.9.31 papercuts cycle builds on v0.9.30.

## Changes

- Documented the wfdm11 stair collision investigation and a staged plan for
  cheaper tracing and collision geometry that preserves intended movement.
  The plan requires a validated commit checkpoint after every feature.
- Added a headless collision-route benchmark with exact baseline comparisons
  for standing/crouched hulls, point traces, steps and ground probes.
- Sweep collision visits each static surface/brush once per query, avoiding
  repeated facet/plane tests when a hull overlaps multiple BSP leaves or a clip
  brush also appears in the fallback scan.
- Collision shader properties are prepared at load time, and face eligibility
  is checked before iterating triangles instead of repeating name/flag parsing
  for every facet.
- Static brush plane tests now have conservative bounding-box rejection. A
  spatial index limits the clip-brush fallback to nearby candidates while
  retaining brushes that lack provable bounds or BSP leaf references.
- Triangle collision uses a static BVH of conservative facet bounds instead of
  testing every triangle in an overlapping draw surface. Candidate order and
  the existing plane solver are preserved, including embedded contacts.
- Collision preprocessing identifies strictly contained compatible static
  brushes and skips their plane tests for hulls starting outside the containing
  brush. Embedded recovery and canonical BSP/point-content data are retained.
- Revisited whether generated triangle-soup collision is needed alongside the
  BSP's authored brushes and patches. Recorded source-layout, spawn-support and
  traversal checks without changing the production collision-source policy.
- Sweep collision now uses authored BSP brushes and patch collision, removing
  extra colliders generated from triangle-soup draw surfaces. Decorative draw
  geometry no longer adds contacts or tracing work to independently clipped maps.
- Fixed repeated ground loss while walking up smooth ramps. Uphill support now
  uses the walkable contact plane and movement direction, preserving support
  without requiring a fresh impact each tick. Jumps and slide bumps moving away
  from the floor remain airborne.
