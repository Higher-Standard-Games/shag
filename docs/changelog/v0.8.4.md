# v0.8.4 - Shader Animation System (tcMod)

**Release Date:** January 3, 2026

## New Features

### ShaderAnimationSystem
Centralized animation system for Q3/Warsow shader effects:

- **tcMod scroll** - UV scrolling for water, lava, conveyor belts
- **tcMod scale** - Static UV scaling
- **tcMod rotate** - UV rotation for fans, spinners
- **tcMod stretch** - Wave-based UV scaling (pulsing)
- **tcMod turb** - Simplified turbulence (oscillating offset)
- **rgbGen wave** - Animated color modulation
- **alphaGen wave** - Animated alpha modulation

### Wave Function Evaluator
Full Q3 wave function support:
- `sin`, `triangle`, `square`, `sawtooth`, `inversesawtooth`, `noise`

### Console Commands
```
shader anim status   - Show animated materials
shader anim pause    - Pause all animations
shader anim resume   - Resume animations
shader anim toggle   - Toggle on/off
shader anim speed <n> - Set time scale multiplier
shader anim clear    - Clear registered animations
```

## Experimental

### Q3NodeMaterialBuilder (Disabled)
NodeMaterial generator for multi-stage Q3 shaders:
- Builds Babylon.js NodeMaterial from shader stage definitions
- Supports blend modes: replace, blend, add, multiply/filter
- UV offset inputs for per-stage animation
- **Currently disabled** - broke transparency and animation, needs more work

## Known Limitations
- Single-stage animation only (multi-stage NodeMaterial disabled)
- Turbulence is simplified oscillation, not true vertex distortion
- No support for: tcGen, deformVertexes, animMap, fogParms

## Testing
Verified with wdm11 - water surfaces scroll correctly.
