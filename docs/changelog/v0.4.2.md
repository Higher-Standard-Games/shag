# v0.4.2 - Electron Desktop Support

**Release Date:** January 1, 2026

## Summary

Added Electron.js support for native Windows and Linux desktop builds, alongside the existing Android/Capacitor mobile support. Introduced centralized game configuration via `game.json`.

## Major Features

### Electron Desktop Builds
- Native desktop application support for Windows and Linux
- Development mode with hot reload via Vite integration
- Production builds with electron-builder for installers

### Centralized Game Configuration
- New `src/game/game.json` for platform-agnostic game metadata
- Single source of truth for app name, IDs, window settings
- Used by both Electron and electron-builder

## Features

- **Window Management**: Configurable window size, minimum dimensions, fullscreen toggle (F11)
- **Native Menus**: Game menu with fullscreen, View menu with dev tools, Help menu
- **Single Instance Lock**: Prevents multiple game windows
- **Secure Preload**: Context isolation with `window.electronAPI` bridge

## New Files


## npm Scripts

| Script | Description |
|--------|-------------|
| `electron:dev` | Development with hot reload |
| `electron:preview` | Build and run locally |
| `electron:build` | Create distributable installers |

## Build Outputs

- **Windows**: NSIS installer (.exe) + portable executable
- **Linux**: AppImage (universal) + .deb (Debian/Ubuntu)

## Dependencies Added

- `electron` - Desktop runtime
- `electron-builder` - Installer creation
- `concurrently` - Parallel process runner
- `wait-on` - Dev server wait utility
