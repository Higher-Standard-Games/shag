# v0.8.2 - Sky Shader Support

**Release Date:** January 3, 2026

## New Features

### Q3/Warsow Sky Shader Support
- **Sky surface detection** - Surfaces with `surfaceparm sky` are now detected and excluded from BSP geometry rendering
- **Skyparms parsing** - The `skyparms` directive is now fully parsed to extract skybox texture paths
- **Skybox texture loading** - Loads 6-face skybox textures from PK3 archives (supports TGA, JPG, PNG)
- **Seamless skybox rendering** - All 6 faces align correctly with proper coordinate system conversion from Q3 (Z-up, right-handed) to Babylon.js (Y-up, left-handed)

### New Console Commands
- `bsp sky` / `bsp sky info` - Display sky shader information from loaded BSP
- `bsp sky apply` - Create and apply skybox from detected sky shader
- `bsp sky toggle` - Toggle skybox visibility
- `bsp sky remove` - Remove skybox from scene

## Technical Details

### Skybox Face Mapping
Discovered that Babylon.js RawCubeTexture uses face order `[nx, px, py, ny, nz, pz]` (not commonly documented order).

**Final working transforms:**
- Side faces (left, right, front, back): `flipH` for handedness correction
- Ceiling (up): `rotate90CCW_flipH` compound transform
- Floor (down): `rotate90CW_flipH` compound transform

### Files Added/Modified
- **New:** `src/engine/loader/SkyboxLoader.ts` - Skybox texture loading and mesh creation
- **Modified:** `src/engine/loader/Q3ShaderParser.ts` - Skyparms parsing with token boundary detection
- **Modified:** `src/engine/loader/Q3ShaderRegistry.ts` - Sky shader resolution
- **Modified:** `src/engine/loader/BspMeshBuilder.ts` - Sky face detection and skipping
- **Modified:** `src/engine/debug/EngineCommands.ts` - New bsp sky commands

## Known Limitations
- Skybox texture PK3s (e.g., `tex_env.pk3`) must be manually loaded before applying skybox
- Cloud layer animation (`tcMod scroll`) not yet implemented

## Testing
Tested with Warsow map `wdm11` using `textures/sky/stormydays` shader.
