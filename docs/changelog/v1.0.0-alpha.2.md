# v1.0.0-alpha.2

**Release Date:** October 23, 2026

Bot hotfix: more responsive opponents, purposeful movement and stronger Duel positioning.

## Changes

- The Higher Standard Games link in the credits dialog opens the studio website
  instead of the GitHub organization.
- Automatic bot invitations now choose at least Hard; new or lower-rated players
  could previously receive opponents that were too easy.
- Bots immediately pursue fresh footsteps and other audible enemies. Continuously
  refreshed sounds previously disappeared from chase selection, and prediction
  incorrectly used a 60 Hz clock instead of the server's 125 Hz clock.
- Heard enemies behind a bot can trigger a line-of-sight check and engagement,
  while walls and reaction delays still apply.
- Duel bots prefer reachable upper-floor control, patrol timed items, and retain
  height against opponents below instead of repeatedly dropping to lower floors.
- Blocked navigation now backs away and replans. A progress watchdog also recovers
  from approaches that keep issuing movement without moving, including ledge hangs.
- Chasing uses crouchslides and strafe jumps. Skilled bots can also attempt a
  slide-to-ledge boosted jump after collision simulation verifies its landing.
- Tuned bots toward running and crouchsliding: trigger approaches and recovery
  use running input, wall avoidance no longer forces walking, and optional
  strafe jumps require running speed. Removed random patrol jumps, automatic
  wall hops and distance-only combat hopping. Dodge jumps are single pulses
  with a cooldown, and a stalled slide no longer tries to jump-cancel in place.
- Duel bots leading by more than two frags receive a small, fixed reaction delay
  that disappears when the lead narrows, without reducing their aim accuracy.
