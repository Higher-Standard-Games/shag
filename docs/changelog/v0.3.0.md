# v0.3.0

**Release Date:** December 28, 2025

## Summary

Major fixes to the plant growing pipeline and BuildableSystem integration. Pots now place instantly, indicators work correctly, and the debug console has improved help formatting.

## Plant Pipeline Fixes

- **Fixed harvest indicator not appearing** - `ready_to_harvest` event condition was always false due to incorrect logic
- **Fixed pot action indicator not showing** - `BuildingSystem.currentMapId` was never set, causing map ID mismatch
- **Fixed water prompt UI** - Event names now match between `PlantSystem` and `WaterPromptUI`
- **Fixed indicator for instant builds** - `complete` event now emits for `buildTime: 0` templates
- **Emit plant state changed event** - `building:plant_state_changed` now fires when plant is planted to hide pot indicator

## BuildableSystem Improvements

- **Instant pot placement** - Pots now have `buildTime: 0` for immediate placement
- **Single stage pots** - Pots use single `pot_100.map` stage (plant visuals TBD)
- **Complete event for instant builds** - `BuildableSystem.create()` now emits `complete` event when `buildTime === 0`
- **Map ID tracking** - `BuildingSystem.setCurrentMap()` called on map load

## Debug Console

- **Improved help command** - Commands now displayed with:
  - Alphabetical sorting within categories
  - Category grouping (System, Debug, Game, Other)
  - Color-coded output (commands in blue, labels in yellow)
  - Visual separators and formatted layout
  - Usage tips in footer
- **HTML preservation** - Console output preserves HTML formatting for styled help
- **Newline support** - `\n` converted to `<br>` for proper line breaks

## Technical

- Added `hl-command` CSS class for command highlighting
- `formatMessage()` detects pre-formatted HTML and skips escaping
- `EventBus.emit("building:plant_state_changed")` for pot/plant state sync
- Fixed circular dependency that caused `BUILDABLE_ITEMS` to be empty
