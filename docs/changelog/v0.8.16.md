# v0.8.16 - GamePaths Refactor & Build-Time Game Selection

**Release Date:** 2026-01-09

## Summary

Major refactoring of the game directory structure to support build-time game selection. Each game now has its own source and asset directories under `src/games/` and `public/games/`, enabling clean multi-game development and self-contained builds.

## Changes

### Directory Structure Refactoring

- **Source code**: `src/game/` → `src/games/default/`
- **Public assets**: `public/game/` → `public/games/default/`
- Multiple games can coexist in `src/games/` and `public/games/`

### Build-Time Game Selection

Games are now selected at **build time**, not runtime:

```bash
# Build default game (from engine.json)
npm run build

# Build specific game with environment variable
GAME=demo npm run build          # Linux/macOS
$env:GAME="demo"; npm run build  # Windows PowerShell
```

### @game Import Alias

New TypeScript path alias for game imports:

```typescript
// Resolves to src/games/{selectedGame}/ at build time
import { GameScene } from "@game/GameScene";
import { SaveManager } from "@game/SaveManager";
```

Configuration in `tsconfig.json`:
```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@game/*": ["src/games/default/*"]
    }
  }
}
```

### Vite Configuration Updates

- Reads `defaultGame` from `engine.json` at build time
- Supports `GAME` environment variable override
- Sets `@game` alias dynamically based on selected game

```typescript
// vite.config.ts
const engineConfig = JSON.parse(fs.readFileSync('public/engine.json', 'utf-8'));
const selectedGame = process.env.GAME || engineConfig.defaultGame || 'default';

export default defineConfig({
  resolve: {
    alias: {
      '@game': path.resolve(__dirname, `src/games/${selectedGame}`)
    }
  }
});
```

### GamePaths Updates

- Asset paths now use `/games/[gamename]/` prefix
- Removed `?game=` URL parameter (no longer needed)
- Removed `allowGameOverride` config option

```typescript
// Before
paths.maps('level.map')  // → /game/maps/level.map

// After  
paths.maps('level.map')  // → /games/default/maps/level.map
```

### engine.json Simplification

```json
{
  "defaultGame": "default",
  "engineAssetsPath": "/engine",
  "title": "My Game"
}
```

- `allowGameOverride` removed (build-time selection replaces runtime switching)
- `defaultGame` now refers to directory under `src/games/` and `public/games/`

- Updated project structure docs for new `src/games/` layout

- Added `@game` alias documentation

### Console Color Customization

- **SHAG palette for console** - Debug console now uses vibrant SHAG logo colors
  - Teal primary accent (`#2EC4B6`) instead of plain green
  - Yellow for warnings, magenta for numbers, green for strings
  - Unified color scheme between console and loading screen

- **CSS variables** - All console colors now use CSS variables
  - `--console-primary`, `--console-error`, `--console-warn`, etc.
  - Enables runtime theming and game customization

- **Game customization API** - `UIStyles.setConsoleColors()` allows games to override
  ```typescript
  UIStyles.setConsoleColors({
    primary: '#ff6600',
    error: '#ff4444',
  });
  ```

### PK3 Index Auto-Validation

- **Automatic indexing on startup** - PK3 index now runs during loading screen
- **Smart caching** - Uses localStorage cache if valid, rebuilds only when PK3 files change
- **`ensureIndex()` method** - Validates cache checksum against current PK3 file list
- **Loading screen integration** - Shows indexing progress ("Validating PK3 index...", "Building PK3 index...")

### Code Cleanup

- **EngineVersion** - Removed duplicate `quotes` array, now uses `getEngineTagline()` for debug console header (SHAG acronym jokes)

## Migration Guide

If upgrading from v0.8.15:

1. Move `src/game/` to `src/games/default/`
2. Move `public/game/` to `public/games/default/`
3. Update `engine.json`: set `defaultGame` to `"default"`, remove `allowGameOverride`
4. Update imports in `main.ts` to use `@game/` instead of `./game/`
5. Fix relative imports in game files: `../engine/` → `../../engine/`
