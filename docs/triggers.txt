================================================================================
                         TRIGGER SYSTEM
================================================================================

This document describes the trigger system and supported trigger actions.

--------------------------------------------------------------------------------
HOW TRIGGERS WORK
--------------------------------------------------------------------------------

1. DETECTION
   Any brush entity with a texture containing "trigger" in the name
   (e.g., common/trigger) is automatically detected as a trigger volume.

2. RENDERING
   Triggers are rendered as:
   - Red color (RGB: 1, 0, 0)
   - Transparent (alpha: 0.3)
   - Wireframe mode
   - Double-sided (backFaceCulling: false)

3. INTERACTION
   Triggers respond to pointer/mouse clicks via Babylon.js pointer observable.
   When clicked, the engine checks the entity's properties for actions.


--------------------------------------------------------------------------------
TRIGGER ACTIONS
--------------------------------------------------------------------------------

OPEN DIALOG (windowTarget)
--------------------------
Opens a UI dialog window.

Property:
  "windowTarget" "dialog_name"

Behavior:
  Calls UIManager.getInstance().openDialog(dialog_name)

Example:
  {
  "classname" "trigger_multiple"
  "windowTarget" "intro_dialog"
  { ... trigger brush ... }
  }


MAP SWITCH (targetMap)
----------------------
Loads a different map file.

Property:
  "targetMap" "mapname.map"

Behavior:
  Calls loadMap(mapname.map), which:
  - Clears existing meshes and lights
  - Clears texture cache
  - Parses and loads the new map

Example:
  {
  "classname" "trigger_multiple"
  "targetMap" "level2.map"
  { ... trigger brush ... }
  }


--------------------------------------------------------------------------------
TRIGGER TEXTURES
--------------------------------------------------------------------------------

The following texture names are recognized as trigger textures:

  - common/trigger
  - trigger
  - Any texture path containing "trigger" (case-insensitive)

These textures are:
  - NOT loaded from disk
  - Replaced with the red wireframe material
  - Marked with isTrigger: true in mesh metadata


--------------------------------------------------------------------------------
METADATA STRUCTURE
--------------------------------------------------------------------------------

Trigger meshes have the following metadata structure:

  mesh.metadata = {
    isTrigger: true,
    properties: {
      classname: "trigger_multiple",
      targetname: "...",
      windowTarget: "...",    // optional
      targetMap: "...",       // optional
      message: "...",         // optional
      // ... any other entity properties
    }
  }


--------------------------------------------------------------------------------
ADDING NEW TRIGGER ACTIONS
--------------------------------------------------------------------------------

To add a new trigger action:

1. Define a new property name (e.g., "customAction")

2. Add handling in src/index.ts in the pointer observable:

   scene.onPointerObservable.add((pointerInfo) => {
     if (pointerInfo.type === PointerEventTypes.POINTERPICK) {
       const mesh = pointerInfo.pickInfo?.pickedMesh;
       if (mesh && mesh.metadata && mesh.metadata.isTrigger) {
         const properties = mesh.metadata.properties;
         
         // Existing actions
         if (properties.windowTarget) { ... }
         if (properties.targetMap) { ... }
         
         // Add your new action here
         if (properties.customAction) {
           // Handle custom action
         }
       }
     }
   });

3. Use the property in your map file:

   {
   "classname" "trigger_multiple"
   "customAction" "value"
   { ... trigger brush ... }
   }
