sidecars already match production. Historical unused cache files are outside
this plan. Do not delete remote files or sync the entire local cache blindly.
Do not upload `washoi_textures.pk3` (unpublished source bank), demos,
`pk3_index.json` or `pk3_manifest.json` (generated during build).
No runtime packages have been renamed or retired in this round.

## When publication is authorized

1. Recheck hashes if local media or production has changed since this audit.
2. Back up each replaced destination into a versioned media backup on each host.
3. Transfer only the listed files under temporary names, preserving existing
   ownership/mode, and rename them into place. Publish the cache manifest last.
4. Verify destination checksums against the supplied SHA-256 list.
5. Promote/push code only under separate production authorization. Deployment
   builds from the asset store and copies the result into the served web root.
6. After activation, verify changed-file responses on both regions, load DM1/DM3
   and check the logo and levelshot previews.

This document prepares publication; the current request merges code into local
staging only.
