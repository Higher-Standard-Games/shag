Visual language

Zones stay invisible in play: a faint label shows until each side has been used once. Only the buttons draw, as ink discs with cream line icons and the HUD's offset print shadow, at one shared opacity. A press lights a button cyan (fire magenta) and drops its shadow, so a thumb gets feedback without looking. The move stick rests as a ghost where thumbs usually land, and jumps to wherever the thumb actually touches.

Build order

  1. Input device state. Last input used (touch, mouse and keyboard) drives which HUD shows.
  2. In play without pointer lock. One "in play" state replaces the pointer-lock checks; look gets one shared entry point.
  3. Stick into movement. An optional move axis in sendInput; no protocol change.
  4. Touch buttons as bindings. The reserved gesture binding, so buttons become ordinary actions.
  5. This HUD. One overlay widget, a finger per control, Pointer Events.
  6. Fullscreen and landscape from the boot screen's tap, and the rotate-your-phone screen.
  7. Settings and layout editor. The rows in this mockup's menu, plus dragging buttons into place.
  8. Aim assist for touch look: needs remote player positions and a line-of-sight check on the client.
  9. Gyro aim, optional.
