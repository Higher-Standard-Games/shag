# v1.0.0-beta.13 release review

A code review and bug-fix pass before the last beta, on branch
`review/beta13-hardening` in both repositories (from `staging`, 2026-11-17).
It covered the cycle's new code (campaign, match runners, bots in the lobby,
highlight reels, Survival, the WebAssembly trace) and the systems around it:
lobby and results, the game server's combat and movement, the network
protocol, demos, audio, the engine UI and core, loaders and deployment.

Each finding was checked against the code before it was fixed. Every fix but
two has a test that fails without it (marked ✗→✓); the other two are marked
with how they were checked.

## Reviewed and left as they are

| Finding | Why not changed |
| --- | --- |
| Campaign matches in rated gametypes are rated, bosses included | Owner's decision ("count toward ratings, for fun", `docs/research/campaign.md`). |
| `switchPlaylist` cancels a playlist still loading | Intended: the newest music request wins. |
| A blade charge's stop event on a weapon switch | Already sent: `equip()` calls `endCharge`. |
| Every `lobby:error` fails a campaign start in progress | The errors arriving then come from the player's own room actions; no cross-talk found. |
| Campaign model and scale by name | Campaign bot names are reserved from accounts, and the server applies scales to bots only. |
| A robot with `ads: false` holding alt-fire can't sprint, shows the aim pose | Its shots keep hip spread as intended; firing already stops sprinting. Cosmetic. |
| Bot decisions skipped on alternate snapshots use the last state | At most one snapshot late, inside the bots' tuned reaction time. |
| `HudFrameCapture` rechecks unmatched selectors each frame | Offline export path; a speed trade-off, not a fault. |
| Reel scene cost overestimates a frag sequence; one speed wipe lengthens a rewind flash | Reel quality, not correctness; #19 bounds the worst case. |
| `--campaign-rules` parsed shallowly on the game server | The lobby validates the file fully; the game server takes the argument only from the lobby. |
| `lobby:server:bun` starts runners with V8 heap flags | Dev-only script; production runs the Node bundles. |
| `LagCompensation.setCapsuleScale` only reaches the unused `traceHitscan` | No effect on play; hit checks scale in WeaponSystem. |
| A per-call client scan in `campaignScaleOf` | Returns at once outside campaigns; at most ten clients. |
| Local axis swaps in `BotPvs` and `CompiledWorldTrace` | Inside the BSP-space boundary, matching the kernel's tables. |
| The world-trace line uses `console.log` | The deploy runbook's verification step reads it from the journal. |
