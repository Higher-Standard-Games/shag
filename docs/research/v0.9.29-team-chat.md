## Player behavior

- **T / Enter:** global chat.
- **Y:** team chat, with a **TEAM** prompt and `[TEAM]` message marker.
- **`/say_team <message>` in chat** or **`say_team <message>` in the console:**
  send team chat without using Y.
- **`/mute <playername>` / `/unmute <playername>` in chat:** local, case-insensitive
  full-name filter for this match. Commands are never transmitted. Muting removes
  existing chat lines and discards future matching global/team/spectator messages.
  Unmuting restores future messages, not previously ignored ones. Notices and
  kill-feed events remain visible.

The filter is deliberately name-based, with no persistent account/blocking list.
Changing a name means the new name must be muted separately. A supplied name is
accepted as a filter even if it has not spoken yet. Quotes around names are
optional. Empty arguments show a usage hint; unmuting an absent name says so.
Destroying match chat clears the list. A continuous server clears it when it
leaves post-game, including a snapshot that skips the brief warmup phase.

## Routing and recording

`NetworkGameHost` uses the existing Chat packet, prefixing team requests with
`/say_team `. The server removes the request prefix before sanitizing/capping
message content at 128 characters. Global/team requests share the existing
600 ms interval and five-message/5-second budget. Rejected team requests consume
that budget too, so notices cannot be generated without limit.

The server derives the sender's side from authoritative match state. A spectator
or a player without a team seat receives a private notice; the request is never
silently converted into a public message. Recipient entity keys are captured
from connected, nonspectating teammates when the message is submitted.

The pending event carries server-only recipient metadata. `SnapshotBuilder`
preserves it; `SnapshotBroadcaster` filters each client's events before encoding,
whether or not PVS is active. `BinaryProtocol` keeps its existing four-string chat
payload; no protocol version/format change was introduced. An empty recipient
list delivers to nobody, not everybody. The shared snapshot is left intact for
other clients and the server recorder.

Server demos capture the whole match, including both sides' team chat marked
`[TEAM]`. The client ignore list does not alter recorded data. Live team delivery
and omniscient replay are separate behavior, documented in the game manual.
