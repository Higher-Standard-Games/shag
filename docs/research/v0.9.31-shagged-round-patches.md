# SHAGGED round patch presets and native export

Implemented 2026-10-17 on `v0.9.31-shagged-amphi-experiment`.

## Behavior

Curves offers cylinder, tube, cone and disk-cap placement in every orthographic
pane. Footprints come from the drag; extrusion follows the hidden axis and
Depth setting. End caps, tube wall thickness and reversed winding are saved
with the editor view. The generator validates footprint/depth and tube radii.
All components preview before committing and cancel without changing history.
One placement is one undo step; multiple components form an editor group.

`patch.round` exposes the same generator through typed API/MCP edits. Axis is
explicit (Z default), bounds use Quake coordinates, and callers may disable end
caps or automatic grouping. Named suffixes are checked against existing IDs;
failed requests do not save changes. Grids remain ordinary editable patches.

Each circular profile uses four joined quadratic spans (9 controls). Walls
use seam U=0/1 and length V=0/1; caps use planar UVs. Handedness is consistent
across the three editor panes. Tube caps are annular; cones taper to the higher
coordinate. These are circle/ellipse approximations, not rational exact circles.
Patches do not seal a map, and annular thickness is a radius subtraction rather
than a constant perpendicular offset around an ellipse.

## Native format finding and compatibility

The first native test failed at the 9-by-3 patch with
`MatchToken( ")" ) failed ... found '('`. The editor writer had serialized
row-major controls while native `patchDef2` expects width columns of height
controls. Square grids hid the dimension mismatch; editor parser readback used
the same mistaken ordering and did not prove native compatibility.

The writer now transposes at export, and MapParser normalizes native columns
back into row-major internal grids. Nonsquare historical row-order input can
also be recovered. A square legacy source without a sidecar is ambiguous;
the parser treats square input as native. Faithful general external map import
remains a separate project.

Immutable server sources/sidecars are not rewritten. MapStore and graphical
server opening accept an exact match against either native output or historical
SHAGGED patch row output. Fresh exports/save revisions use native order. Tests
verify legacy recovery, new revisions and rejection of mismatched sidecars.

The focused round passed 67 tests, including geometry, winding in all three
orthographic frames, UVs, deterministic source/parser round trips, invalid
requests, recovery, multi-ghost cleanup, cancellation and undo. The native
compile test verifies finite BSP data, finite-size cap/side contacts, a cone
slope and an unobstructed tube center. The complete suite passed 615 files,
5,080 tests with one skipped. Typechecking, Biome, production build, all listed
simulation/physics/server/headless regressions and the documentation build passed.

Real Edge/WebGL2 on RTX 4070 SUPER created all four shapes with native mouse
drags: ten surfaces, three groups, finite preview normals and zero leftover
ghosts. Undo removed the last placement. `.cache/shagged-round.png` was visually
reviewed. The expanded menu also stays on-screen and scrolls at a 650-pixel
viewport height; `.cache/shagged-round-menu.png` records that check.
No shader errors or failed HTTP resources; existing template warnings
remain. Private browser/server processes were closed after the probe.

The real MCP SDK smoke test created and compiled a grouped tube and rejected
invalid wall thickness without advancing the document revision. Compile reuse,
forced builds, full inspection and concurrent MCP/CLI edit checks also passed.
Logs are under `.cache/shagged-round-*`; the MCP report is
`.cache/shagged-mcp-validation/report.json`.

Assumptions: this extends editor authoring; no runtime physics or networking
rules were changed. WebGPU and a full gameplay traversal were not checked.
Zero-size traces missed some flat cap/patch seam fixtures despite successful
finite-size sweeps. Evidence and the separate follow-up are in
`v0.9.31-patch-point-trace-investigation.md`; this limitation is not a passing
point-contact claim.
