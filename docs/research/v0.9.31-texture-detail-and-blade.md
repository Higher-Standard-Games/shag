# Texture detail and blade lunge papercuts

The blade's configured forward dash is 64 units, up from 48. Forward input,
existing forward motion and collision clamping retain their existing rules.

Video → Advanced adds map texture detail for every preset. `r_picmip` defaults
to 0 (Full); Smooth selects 1 (Soft), Balanced and Pretty select 0. Levels 1–7
divide base-texture dimensions by powers of two, with a minimum of one texel;
8 is Flat color, a single averaged texel. UI choices are 0, 1, 2, 4 and 8.
The setting persists, resets with Video and takes effect on the next map load.

Reduction applies to static opaque BSP base textures. It excludes sky, animated,
alpha-tested, blended and billboard surfaces, model texture paths, and shaders
with `nopicmip` or `nomipmaps`. Lightmaps, normal/gloss maps, weapon/player assets
and effect textures remain independent. Flat color retains surface lighting.
Reduced variants use separate loader cache keys, protecting full-quality uses
of the same asset. Source image pixels are reduced before GPU upload. KTX1
chains are repacked after dropping top levels, preserving the reduced container
for context recovery. Supported incomplete chains use software reduction.

Reduced variants bypass full-resolution KTX2 sidecars and use the source media.
Image variants upload as RGBA, so resolution alone does not establish a VRAM
improvement over every compressed full-quality sidecar. FPS/performance gains
have not been benchmarked. Exotic KTX formats without enough authored mips or
a software decoder rely on the existing source-image fallback.

## Choice-button layout follow-up

`FPSSettingsView.css` gives segmented buttons a content-sized flex basis,
prevents shrinking below their labels, and keeps each label on one line. The
existing flex row wraps whole buttons when necessary. The changelog records
the correction. No renderer or gameplay behavior changes in this follow-up.

`npm run test:run -- src/games/fps/client/settings/__tests__` passed 30 tests;
`npm run gate:biome` passed. `node .cache/settings-button-probe.mjs` checked the
real Advanced controls at 390px and 260px row widths: every button's scroll
width equalled its client width, labels stayed on one line, and the row wrapped.
Screenshots were visually inspected. Results and captures are ignored under
`.cache/settings-button-report.json` and `.cache/settings-buttons-*.png`.
