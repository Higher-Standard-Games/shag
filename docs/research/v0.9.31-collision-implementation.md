## Per-query visit deduplication

Baseline checkpoint: `def91057`. Brushes and faces use generation stamps, reset
on map initialization, disposal and integer wraparound. Brushes reached through
BSP leaves are not retested in the clip fallback. Embedded brushes/faces retain
their repeated visits because recovery normals/contents depend on that order.

The initial general deduplication failed 243/4,200 seeded near-surface traces
across seven maps, despite matching the walking route. Preserving embedded
visits resolves all 243: zero differences over wfdm11, wfdm5, wdm2, wdm1, wdm17,
wbomb6 and wtutorial1, including rays, different hulls and content masks.
Focused tests also cover generation wraparound, reinitialization, embedded
ordering and leaf/fallback duplication. Command:
`npx.cmd vitest run src/engine/__tests__/SweepCollisionBackend.test.ts` (26 passed).
Scratch oracle command: `npx.cmd vite-node .cache/collision-corpus.ts`;
the reference class is the baseline revision's backend with import paths
rewritten for its ignored scratch location.

`npx.cmd vite-node src/cli/benchmark-collision.ts --baseline .cache/collision-baseline.json --out .cache/collision-dedup.json`
passes with zero changed route samples. Final local query-batch median/p95/p99:
1.181/2.295/3.531 ms. Timing varies with concurrent validation load; use final
unloaded comparison for performance claims. Required gates/regressions passed
under `.cache/collision-dedup-*.log`; the full tests repeated after the
embedded-order correction also passed (`collision-dedup-final-tests.log`).

## Brush bounds and clip spatial lookup

Filtering checkpoint: `94d6aba8`. Exact axial collision-plane constraints produce
conservative bounds with a 0.125 plane-distance margin. Missing/nonfinite bounds
remain unculled; near-axial normals are not assumed axial. A deterministic BVH
queries clip candidates and returns source order. Static/moving brush plane
tests also reject disjoint swept bounds in their own coordinate space.

wfdm11 has 847 bounded brushes out of 850 and 112 indexed clip brushes. Seeded
seven-map traces and the 580 route samples match the original exactly. Local
route median/p95/p99: 0.291/0.538/0.789 ms. New tests cover spatial-index order,
boundary overlap, missing constraints, linear-oracle comparisons, and clip
brushes absent from leaf references. All gates/regressions passed: 590 files,
4,930 tests passed, one skipped. Logs: `.cache/collision-brush-*.log`.

## Triangle BVH

Brush checkpoint: `8ef69e65`. Per-face BVHs use conservative bounds from packed
facet planes and return sorted triangle indices, preserving equal-contact and
embedded ordering. 101,976 of wfdm11's 108,430 facets have finite proven axial
bounds; the rest remain unconditional candidates within their original face.
Initialization in this run increased from about 365 to 449 ms, including BSP
parsing and existing facet construction. Index memory has not been separately
measured. Canonical facet planes and geometry are retained.

The exact 580-sample route comparison and 4,200 seeded traces across seven maps
pass. Local query-batch median/p95/p99: 0.038/0.082/0.128 ms, versus baseline
1.167/3.307/4.568 ms. These are separate local runs, not a controlled live FPS
comparison. A dense synthetic soup test compares the BVH against its linear
solver at ordinary, edge and embedded starts. All gates/regressions passed:
590 files, 4,931 tests passed, one skipped. Logs: `.cache/collision-bvh-*.log`.

Authoring clarification from Jal: corner softening affects draw surfaces, not
the compiler's collision brushes. SHAG separately generates collision facets
from triangle-soup draw surfaces; that extension is the measured expensive
path. The origin of model-generated BSP brushes has not been audited. Do not
attribute brush-count growth to draw-surface smoothing without compiler evidence.

## Conservative contained-brush pruning

Triangle checkpoint: `3bf115d7`. Load-time preprocessing proves strict inclusion
of a brush's conservative AABB behind every container plane, with matching raw
contents and effective query masks. Containers must occur in every leaf that
references the child; a clip fallback child also needs a fallback container.
Inline models, ladder brushes, uncertain bounds and boundary-touching pairs are
excluded. Original BSP data remains available to point-content queries.

Queries starting inside the container retain the child solver, preserving
embedded recovery normals. The 580 route samples and 4,200 seven-map traces
match the original. wfdm11 has no provable strict brush redundancies under these
rules, so this feature is not credited for its speedup. A preliminary geometry
audit found 13 raw containment candidates in wfdm5, before reference/semantic
checks. Focused tests cover strict containment, embedded starts, touching bounds,
different masks and missing container leaf references. All gates/regressions
passed: 590 files, 4,933 tests passed, one skipped.
Logs: `.cache/collision-contained-*.log`.

## Final QA and full-route comparison

Containment checkpoint: `75f172cc`. The final comparison covers all 4,634
recorded intervals, with zero serialized collision/movement-result differences
against the backend at `def91057`. Both runs use the same indexed BSP and demo.
Local query-batch median/p95/p99 fell from 1.1663/3.4982/4.9262 ms to
0.0368/0.0722/0.0934 ms. Initialization including parsing/facet construction
was 386.7 versus 460.1 ms. These measure a batch of collision queries, not FPS
or individual trace latency. Additional index memory remains unmeasured.

```powershell
npx.cmd vite-node .cache/benchmark-reference.ts --stride 1 --out .cache/collision-full-baseline.json
npx.cmd vite-node src/cli/benchmark-collision.ts --stride 1 --baseline .cache/collision-full-baseline.json --out .cache/collision-full-final.json
```

The scratch reference runner imports the original backend extracted from
`def91057`; it is not a second production backend. The durable CLI now rejects
missing option values, mismatched result counts, and an output path that would
overwrite its reference file. The latter rejection was checked against the
reference file's SHA before and after execution.

Headless Edge on real GPU/WebGL2 loaded the actual demo and compared 580 sampled
route positions against the original backend: zero differences. Browser workload
p95 was 2.4 versus 0.1 ms; browser timer quantization prevents interpreting zero
samples as zero cost. The rendered stairs screenshot was inspected. A separate
ammo MD3 loader/plugin error occurred; its cause was not investigated here.
This was not an uninterrupted live-input gameplay or FPS measurement.
Local artifacts: `.cache/collision-browser-results.json`,
