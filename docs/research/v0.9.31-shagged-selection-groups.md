# SHAGGED multiple selection and editor groups

Implemented 2026-10-17 on `v0.9.31-shagged-amphi-experiment`.

## Behavior and scope

Ctrl/Cmd-click toggles objects in the 2D and 3D panes. Select-tool drags starting
in empty 2D space intersect projected object bounds; Ctrl/Cmd adds those hits.
Hidden objects in the same projection can be included. Selection itself does
not create document history. Mixed selections move, duplicate, delete and frame
together; a drag previews before committing and Escape cancels it.

Flat named `editorGroups` contain brush, patch and point-entity IDs. Clicking
one member in Select selects the group. Grouping existing groups merges their
members. Metadata survives local recovery, server saves and JSON inspection but
does not enter compiler source or change brush-entity ownership. Complete
compiler owners duplicate independently. Partial graphical copies join their
owner; partial API copies remain detached, matching the existing API policy.
Deletion prunes stale members and removes groups smaller than two objects.

The API accepts group IDs for movement, duplication and deletion, and exposes
`editorGroup.create`, `editorGroup.ungroup` and `editorGroup` spatial queries.
Compile saves compare sidecars as well as source, so a metadata-only change
creates a saved revision even when the compiler source is identical.

Assumptions: this is an editor authoring feature, with no gameplay, networking
protocol or collision changes. Editor groups are separate from compiler
`func_group` entities. Shared rotation/resizing remains unimplemented; vertex,
patch-point and face tools edit individual objects. Bounds-based marquee is
deliberately conservative rather than polygon-precise. ASE/GLB preview limits
are unchanged. WebGPU and macOS Cmd interactions were not tested live.

The complete suite passed 612 files, 5,061 tests with one skipped. The final
focused round passed 59 tests, including a subsequently added individual patch
copy case and vertex-tool selection isolation. Final source was typechecked
again. Tests cover mixed object transforms, deduplication, compiler ownership,
invalid group rejection, carve membership, local recovery and server sidecars.

Real Edge/WebGL2 on RTX 4070 SUPER verified native Ctrl-click in both view types,
two-object movement by 16 units, unchanged unselected geometry, undo, grouping,
duplication and deletion. Screenshot `.cache/shagged-selection.png` was visually
reviewed. No shader errors or failed HTTP resources; existing shader-template
warnings remain. The private server/browser were closed after the probe.

The real MCP SDK smoke test queried groups, duplicated/ungrouped/deleted copies
and compiled a metadata-only edit. The saved revision advanced, compiler-source
hash stayed unchanged and the persisted sidecar contained the new group. The
same run passed native compile/reuse/forced-build and concurrent MCP/CLI checks.

Logs and browser JSON reports are under `.cache/shagged-selection-*`; the MCP
report is `.cache/shagged-mcp-validation/report.json`.
