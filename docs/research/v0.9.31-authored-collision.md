# Authored collision trial

Date: 2026-10-16. Follows the [authority audit](./v0.9.31-collision-authority.md).

The sweep backend now generates facets only for type-2 patches. Authored BSP
brushes, contents, clip fallback, inline models and moving brush collision are
retained. Type-3 draw surfaces no longer create colliders, regardless of shader
name. The unused triangle-soup builder and shader-prefix exclusions were removed.
This is a deliberate collision-source change, not an exact-parity optimization.

Tests cover draw-only surfaces staying noncolliding, a brush floor retaining its
contact beneath raised draw geometry, patch floor/ceiling hull asymmetry, and
facet acceleration/embedded ordering using patch fixtures. Initial focused tests
failed on two stale facet-call counts after replacing a two-triangle soup with
an actual tessellated patch. Updated fixture expectations pass all 34 tests.

The six-map audit was repeated against checkpoint `81cb88e9`: all 97 spawn probes
retain support; one wfdm11 support height differs by eight units and one wdm17
spawn is embedded in both policies. Of 580 recorded wfdm11 samples, 142 downward
probe heights differ, no support disappears, and no recorded-displacement move
endpoint differs by more than 0.01 units. Recorded displacements do not reconstruct
the original input simulation.

All 4,634 intervals of the route benchmark run successfully. Local batch
median/p95/p99: 0.0095/0.0156/0.0214 ms, initialization 129.7 ms. wfdm11 facet
count falls from 108,430 to 5,900. These are local query workload timings, not FPS.
Exact result parity with the former draw-surface policy is not expected.

Synthetic movement tests seed 32 grounded positions/headings from the stair
recording and run 125 fixed ticks each with forward input and jump disabled.
The previous policy produces 119 grounded-to-rising edges above 60 units/sec;
authored collision produces 116. This demonstrates that draw-surface removal
alone does not resolve the jump-sound loop. These are synthetic straight runs,
not a re-simulation of the player's missing recorded inputs. Audio code is
unchanged. Uphill support classification needs its own investigation/checkpoint.

Local reproduction:

```powershell
npx.cmd vite-node .cache/collision-authored-policy-audit.ts
npx.cmd vite-node .cache/collision-authored-movement.ts
npx.cmd vite-node src/cli/benchmark-collision.ts --stride 1 --out .cache/collision-authored-full.json
```

The first two runners and JSON artifacts are ignored scratch files. The durable
benchmark is in `src/cli/benchmark-collision.ts`. Complete gameplay coverage,
projectile contacts throughout every map, and live client/server reconciliation
remain unverified; maps relying on draw-only solidity can change behavior.

Checkpoint validation: `npm.cmd run typecheck`, `npm.cmd run test:run`
(590 files, 4,934 passed, one skipped), `npm.cmd run gate:biome`,
`npm.cmd run build`, `npm.cmd run test:simulation`, `npm.cmd run test:physics`,
`npm.cmd run server:tick`, `npm.cmd run server:fuzz -- --ticks 1000`,
`npm.cmd run cli:game -- --exec "bsp load wdm2; bsp info; quit"`,
`npm.cmd run cli:game -- --exec 'sim replay \"W+CROUCH 60; JUMP 1; W 30\"; quit'`,
and `npm.cmd run docs:build` all passed. Biome initially reported formatting
errors in the two edited TypeScript files; formatting those files fixed the
gate without changing behavior. Logs: `.cache/collision-authored-*.log`.
