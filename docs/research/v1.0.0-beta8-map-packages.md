## Rebuilding

After importing an updated BSP into its `map_<name>.pk3` and any updated source
media/definitions into the master, use the normal packager:

```text
node scripts/package-map-media.mjs --maps washoi_dm1,washoi_dm3,washoi_dm5,washoi_dm7 --master-package washoi_textures.pk3 --output-dir .agent/map-packages/final
node scripts/generate-pk3-index.mjs
node scripts/convert-ktx2.js --dry-run
```

Install the reviewed outputs before regenerating the index. For a BSP-only DM3
recompile, restrict `--maps` to `washoi_dm3` and recheck its material report.
Shared material corrections also require rebuilding every affected map bank.

Texture conversion initially could not find Khronos tools on PATH. The cached
tool was then selected explicitly and completed without errors:

```powershell
$env:KTX_TOOLS_PATH = (Resolve-Path '.cache/ktx-tools/extracted/bin').Path
node scripts/convert-ktx2.js
```

417 sidecars were regenerated, 759 reused, with zero conversion errors. A final
author refresh regenerates eight sidecars; the custom levelshots regenerate two.
There are now 1,181 sidecars. Final audit results are recorded below.
