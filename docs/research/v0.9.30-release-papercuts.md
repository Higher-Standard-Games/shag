## P1 — Launcher ADS gating and Electrobolt hipfire

Implemented the user-approved behavior: hold fire through the raise; release
before the delay completes cancels the shot. RL/GL wait for the configured
ADS duration: RL/GL 160 ms (20 ticks at 125 Hz). Both were doubled
from 80 ms at the user's request on 2026-10-15. Automatic aim retains a 1° rocket / 4°
grenade spread cone. Manual ADS only becomes accurate after uninterrupted manual
aim for the same duration; pressing fire partway through manual aim waits out
the remaining raise. EB fires immediately from the hip with a 20° cone, and has
zero spread after completed manual ADS. Close-range displacement is naturally
smaller with angular spread; there is no special distance cutoff.

The client marks primary-fire automatic aim with `InputButtons.AUTO_ADS` in
existing bit 12 (alias ACTION1). ALT_FIRE remains set for movement and watched
views. The server tracks automatic/manual raise times separately, resets them
on equip/death/release, and uses the shot's deterministic direction for both
its fire event and launcher projectile velocity. EB no longer skips the spread
path. New input semantics fit the existing packet and demo button bitmask;
there is no layout/version change. Historical demos still replay recorded shot
events, but authoritative re-simulation of older weapon-balance rules is not
guaranteed. Client and server must run matching gameplay code for live play.

RL/GL/EB view-model aim transitions now reach their final pose in weapon ADS time
rather than asymptotically approaching it. Other weapon behavior is retained;
the Plasma Gun fires immediately from the hip with its existing projectile spread
path and aims only on manual input. Its leftover `hipfireBlocked` flag was removed
after user testing identified the unintended automatic sight raise. The obsolete
one-tick ADS bypass branch and its timer were removed from WeaponSystem; only
RL/GL opt into the full firing gate.
The core ADS speed uses weapon data; `cl_ads_time` remains cosmetic for other
weapons. Existing aimed-shot fixtures hold ADS for the complete raise: 20 ticks
for both RL and GL.
