# v0.9.30 Qfusion soft particles

## Behavior

Authored `softParticle` now reaches transparent Standard/PBR primary materials
in the BSP and MD3 loaders. It uses opaque camera-space depth, including
alpha-tested cutouts, and Qfusion's default scale 0.02:

```text
d = clamp((opaqueViewZ - effectViewZ) * 0.02, 0, 1)
softness = 1 - (1 - d)^4
```

Source-alpha blending multiplies alpha by softness. Pure additive `ONE ONE`
multiplies RGB instead, preserving its alpha. The shader variant is keyed by a
define so Babylon's effect cache cannot reuse the alpha-only code for pure add.
The cleared background leaves the effect unchanged. The distance-ramp fade
continues to apply independently.

Source verified against the local warfork-qfusion tree:
`assets/data0_21pure/glsl/include/softparticle.glsl`,
`assets/data0_21pure/glsl/defaultQ3AShader.frag.glsl`,
`source/ref_gl/r_shader.c` and the 0.02 default in `source/ref_gl/r_register.c`.

A scene shares one privately owned depth capture among its soft materials.
It follows the rendering world camera, pauses outside the effects' frustum,
excludes sky/viewmodels/blended submeshes and soft surfaces themselves, and
releases its target and observer with the last owning material. It does not use
the depth renderer cache shared by outlines. Water's capture is unchanged.

## Assumptions and limits

The reported lamp cones are wfdm11's `halo` / `halo_large` assets. Shader source
and runtime metadata confirm their `softParticle` directive. This implements
intersection fading, not a global opacity reduction or an edit to the texture's
silhouette. It adds a full-resolution depth pass while affected geometry is
in the camera frustum. Low-end performance and live multiplayer were not measured.
Devices without float render targets keep the authored effect without fading.
Custom overlay ShaderMaterials are outside this Standard/PBR path. Exact matched-
camera Qfusion screenshot parity and split-screen/sub-viewport rendering were
not verified.

Final production validation: npm.cmd run build passed, including PK3 prebuild and sourcemap postbuild (.cache/soft-build-final.log). The final shader pixel probe also passed on both backends (.cache/soft-pixels-final.log).
