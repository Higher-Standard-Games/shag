# v0.9.30 health shells and lamp cone distance fades

## Findings and changes

The procedural mega-health uses the FPS pickup geometry, not the upstream MD3
health model. Babylon StandardMaterial adds opacity Fresnel to material alpha.
Combining a substantial base alpha with Fresnel made the shell obscure its inner
cross. The shell now uses Fresnel alone (12% centre, 90% rim). Mega/ultra cross
caps share the body's billboard mode and 0.9 scale.

The actual wfdm11 `halo` / `halo_large` lamp shaders use
`alphaGen wave distanceramp 0 1 80 400`. The parser previously treated the
unknown function as a sine, turning the distance limit into a 400 Hz frequency.
The parser now preserves a distinct distance-ramp generator. A material plugin
implements Qfusion's per-vertex smoothstep using camera distance projected onto
the deformed surface normal. Autosprites update their normals with positions.
No depth bias or map/model edits are required.

Source comparison: local warfork-qfusion `flareshalos.shader`,
`glsl/include/rgbgen.glsl` and `source/ref_gl/r_program.c`. General arbitrary-axis
`autosprite2` support and custom overlay shader distance ramps are outside this
change; the existing world-Y cylindrical billboard geometry remains in use.

## Validation

Targeted command:

```powershell
npx.cmd vitest run src/engine/__tests__/Q3ShaderParser.test.ts src/engine/loader/bsp/__tests__/BspAutosprites.test.ts src/engine/loader/shader/__tests__/TextureTransforms.test.ts src/games/fps/world/pickups/procedural/__tests__
```

Passed: 5 files, 103 tests. Parser tests preserve zero-valued distance-ramp
parameters; billboard tests check camera-facing normals; pickup tests check
native Fresnel opacity and cap/body alignment.

Real GPU checks, using a private Vite server on port 3100:

```powershell
node .cache/lamp-ramp-pixels.mjs
node .cache/lamp-map-stability.mjs
node .cache/mega-both.mjs
$env:QA_RENDERER='webgpu'; node .cache/mega-both.mjs
```

Both WebGL2 and WebGPU pass, with no HTTP or GPU/runtime errors. The isolated
frozen-material ramp produces identical pixels on both backends at distances
80, 240 and 400. The actual wfdm11 `halo_large` produces mean RGB sums of 0,
1.55517578125 and 3.119384765625 at those distances. Five stationary middle-distance
frames all retain exactly 1.55517578125, verifying temporal stability. Health
captures show the cross through the shell on both backends. Artifacts live in
`.cache/lamp-ramp-pixels.json`, `.cache/lamp-map-stability.json` and
`.cache/mega-after-{webgl2,webgpu}.png`.

Assumptions: FPS procedural health visuals and the indexed wfdm11 lamp shader
are the reported assets. The probes isolate visuals; they do not change or test
server collection logic. Live combat/lobby sessions, low-end hardware performance,
matched-camera Qfusion image parity and distance ramps in custom shader overlays
were not verified. The reported lamp uses StandardMaterial; the PBR plugin path
is typechecked but not covered by this pixel fixture.
