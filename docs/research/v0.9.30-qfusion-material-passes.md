# Ordered Warfork material passes

The wfdm5 industrial supports use `models/mapobjects/industrial/support01/albedo`
from `scripts/mapobjects.shader`, not the similarly named vertex-only pillar
textures. Its stages are:

1. A lit material multiplied by vertex RGB.
2. The same lit material with identity RGB, alpha-blended over stage 1.
3. An additive AO image multiplied by constant RGB (.05, .05, .05).

The classic path treated the last image as full-strength emission plus a .05
constant. PBR already multiplied its emission by .05, but both paths omitted
the second material stage. Temporary classic-path overrides reproduced the
white-out and demonstrated that restoring the three passes restores the grey
body and orange strips. The model and texture data are valid.

## Implementation

`resolveMaterialPasses` recognizes an opaque material base followed by one or
more alpha-blended material layers and optional additive image stages, using
base texture coordinates. It resolves the selected deluxe/non-deluxe branch
before selecting individual stages. Other stacks retain the compatibility
resolver; this is not arbitrary Q3 multi-pass support.

BSP loading creates ordered meshes/materials for the supported passes. Secondary
passes retain independent vertex RGB/alpha ownership, constant alpha, UV/frame
animation and explicit depth-write. They retain world PVS metadata and are not
collision/picking targets. Separate geometry buffers prevent neutralizing an
identity pass's RGB from whitening the vertex-coloured base. Each pass has
private mutable texture objects sharing the underlying GPU images. Map teardown
disposes those private objects and pass materials; animation entries unregister
with their material.

`Q3StageColorPlugin` applies constant RGB to the source contribution before fog
and framebuffer blending, on GLSL and WGSL. It can also multiply an additive
source by vertex RGB. A constant colour is not added to StandardMaterial's
emissive texture. Authored material shine stages draw separately so their gain,
UV animation and base alpha remain independent. The primary material animation
path works for both Standard and generated PBR materials.

This covers baked BSP triangle-soup models, including the supports and the
`industrial/crates/albedovc` coloured overlay. Dynamic MD3 layered materials,
environment-coordinate stacks and arbitrary blend/deformation combinations are
outside this change. It introduces extra draw passes and secondary geometry
buffers. Combining compatible passes into one shader is a later optimization;
no low-end performance claim is made.
