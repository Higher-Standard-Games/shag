**Date**: 2026-01-10  
**Goal**: Systematically verify implementation matches design philosophy

## Design Philosophy (Reference)

**Primary**: Babylon.js native collision (`camera._collideWithWorld`)  
**Augmentation**: Use BSP data to enhance Babylon collision

**Strategy**:
1. **ADD collision**: Generate Babylon meshes for non-rendered BSP brushes
   - Fullclip (invisible barriers)
   - Playerclip (player-only barriers)
   - Caulk (structural sealing brushes)
2. **REMOVE collision**: Exclude detail brushes (visual-only)
