# SHAGGED plane clipping and convex subtraction

Implemented 2026-10-17 on `v0.9.31-shagged-amphi-experiment`.

## Implementation

`ConvexCsg.ts` clips outward polygon faces against a normalized half-space,
welds intersection points, removes collinear corners and builds an outward cap.
Every generated hull passes the existing closed/convex/volume validation.
Subtraction first checks actual convex intersection, then peels off the outside
of each cutter plane. The result is a deterministic set of convex fragments
whose interiors do not overlap. Disjoint solids retain their representation,
including cases whose AABBs overlap.

`brush.clip` supports front, back and both halves. `brush.subtract` accepts
explicit target brush IDs and one cutter, optionally deleting the cutter.
Existing `brush.carve` and `gen.connect` retain their fast axis-aligned box path
and use convex subtraction for hull targets. Surviving faces retain world-space
texture mappings. New faces default to the target's base shader and legacy UVs;
the two new operations accept explicit `capMaterial` overrides.

Fragments inherit detail flags, compiler ownership and editor group membership.
The first retains the source ID; additional IDs avoid all existing object/group
IDs. Complete removal prunes empty compiler owners and undersized editor groups.
Operations validate atomically; graphical edits are one undo step and preserve
the original document on failure. Face indices must be inspected again after cuts.

The single-brush inspector exposes numerical plane clip/split controls. The
multiple-selection inspector offers a cutter dropdown and optional removal.
Only selected brushes are subtraction targets; mixed patches and entities stay
unchanged. MCP advertises and executes the same typed operations.

The accompanying papercut restores `wdm2` (Proving Grounds) to the Duel pool in
`config/maps.json`. JSON parsing and the configured assignment were checked,
and headless BSP loading confirms the installed map is usable. The lobby reads
the configuration at startup; no running lobby was restarted.

## Assumptions and limits

This is solid-brush authoring, not runtime collision simplification. Collision
and draw data still come from the native BSP compiler. Patches and model meshes
cannot be cutters or targets. Plane input uses Quake Z-up coordinates and
`normal dot point = distance`; both normal and distance are normalized together.

The implementation uses floating-point tolerances. Degenerate fragments and
hulls exceeding the existing 128-vertex/64-side limits reject the transaction.
This does not promise exact arithmetic or minimum-piece decomposition. Shared
rotation/resizing remains a separate follow-up.

The experiment encountered a graphical API limitation: there is no interactive
plane placement or cut preview. Numerical controls provide precise authoring;
drag handles/previews remain in `SHAGGED_NEEEDED_FEATURES.md`. WebGPU was not
tested for this checkpoint; browser verification used WebGL2.

The final focused round passed 66 tests. Coverage includes oblique cuts through
edges/vertices, normalized planes, tangent/disjoint cases, complete removal,
UV/cap materials, atomic invalid-input rejection, owner/group propagation and
undo. An additional stress test checks conserved volume for 24 cutters rotated
around all three axes. The complete suite passed 613 files and 5,071 tests,
with one skipped. The subsequently added three-axis stress case passed in the
final focused round. Typechecking, Biome, production build, all listed
simulation/physics/server/headless regressions and the documentation build
passed. Final test sources were typechecked again.

A native MakeBSP/MakeLight test compiles a subtracted rotated wall and a clipped
slope. Sweep collision passes through the opening, hits the wall beside it and
lands at the expected slope height. The existing convex compile/UV test passes
as well. Real MCP SDK testing compiles clip/split/subtract output and verifies
the resulting bounds and cutter removal, alongside compile reuse and concurrent
edit checks.

Real Edge/WebGL2 on RTX 4070 SUPER verified the inspector controls, two split
meshes, an opening bounded at X=-16 and X=16, cutter removal and undo. The
screenshot `.cache/shagged-csg.png` was visually reviewed. There were no shader
errors or failed HTTP resources; pre-existing missing-template warnings remain.
The isolated browser/server were closed after the probe.

Logs are under `.cache/shagged-csg-*`; the MCP report is
`.cache/shagged-mcp-validation/report.json`.
