# Patch bounds and hot-loop allocation work

Date: 2026-10-16. Baseline: `ff7de2b0`.

## Partial bounds checkpoint

Near-axial facet planes can replace exact axial bevel planes during duplicate
suppression. `planeBounds` correctly refuses to treat these as axial, but the
old index then discarded every proven side if any side was missing. The index
now retains exact axial constraints as possibly half-infinite bounds. Missing
directions stay infinite; primitives with no proven side remain unconditional
candidates. A finite partition anchor prevents infinity arithmetic from producing
NaN when building the BVH. Candidate output remains in original source order.

This avoids deriving a triangle-vertex box that might be smaller than the
plane-offset solver's accepted contacts. No planes, tessellation, masks,
grounding or movement constants change. Brush bounds keep their finite-only
policy; only patch facet indexing opts into partial bounds.

The `boundedTriangleCount` statistic still counts fully finite facets.
`partiallyBoundedTriangleCount` reports facets indexed with infinite sides.

Tests cover mixed finite, half-infinite and unknown boxes against a linear
overlap oracle, near-axial exclusions, source order and unchanged collision
results. Two old facet-count expectations initially failed because culling
reduced the calls; the repeated-visit counts were updated from 96/48 to 52/26.

Differential checks against the baseline:

- 16,800 seeded patch-near traces over wfdm11, wfdm5, wdm2, wdm1, wdm17,
  wbomb6 and wtutorial1: zero differences, including embedded starts and multiple
  hull sizes/masks.
- All 4,634 recorded wfdm11 intervals: zero differences in serialized trace and
  step/ground outputs.

The synthetic patch-near workload runs step-slide movement plus two downward
probes, often starting embedded. Facet solver calls per batch:

The recorded stair samples perform no patch facet solves in this workload.
These are operation counts, not CPU-time shares or live FPS measurements.
