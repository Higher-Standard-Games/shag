# Patch bounds and hot-loop allocation work

Date: 2026-10-16. Baseline: `ff7de2b0`.

## Partial bounds checkpoint

Near-axial facet planes can replace exact axial bevel planes during duplicate
suppression. `planeBounds` correctly refuses to treat these as axial, but the
old index then discarded every proven side if any side was missing. The index
now retains exact axial constraints as possibly half-infinite bounds. Missing
directions stay infinite; primitives with no proven side remain unconditional
candidates. A finite partition anchor prevents infinity arithmetic from producing
NaN when building the BVH. Candidate output remains in original source order.

This avoids deriving a triangle-vertex box that might be smaller than the
plane-offset solver's accepted contacts. No planes, tessellation, masks,
grounding or movement constants change. Brush bounds keep their finite-only
policy; only patch facet indexing opts into partial bounds.

The `boundedTriangleCount` statistic still counts fully finite facets.
`partiallyBoundedTriangleCount` reports facets indexed with infinite sides.

Tests cover mixed finite, half-infinite and unknown boxes against a linear
overlap oracle, near-axial exclusions, source order and unchanged collision
results. Two old facet-count expectations initially failed because culling
reduced the calls; the repeated-visit counts were updated from 96/48 to 52/26.

## Allocation checkpoint

Partial-bounds checkpoint: `7d1a53e4`. `CollisionSpatialIndex.queryInto` clears
and fills caller-owned output storage while retaining source order. Ordinary
`query` still returns an independently allocated array. Recursive index visits
and the source-order comparator no longer allocate per-query closures.

Each sweep backend owns separate facet/clip candidate buffers and a query-bounds
tuple. Buffers are recomputed for every query and cleared on disposal. Leaf
face checks compare scalar mesh bounds rather than allocating converted arrays.
Brush plane offsets use scalars, preserving the original floating-point operation
order. Intermediate contact normals can reference canonical plane data because
the public trace boundary constructs independent Babylon vectors.

The existing backend already uses pooled state and is synchronous/non-reentrant;
this work does not introduce shared buffers between backend instances or reuse
candidates across frames. It does not change solver planes, masks, visit order,
movement, or the collision source. Heap/GC pauses have not been directly measured;
the evidence is removal of allocation sites and result-preserving comparisons.

New tests check repeated output-buffer use without stale candidates, independent
ordinary-query results, and returned contacts surviving later traces/caller
mutation. Focused tests: 48 passed. Repeating the 16,800 seven-map traces and
4,634 recorded intervals against `ff7de2b0` gives zero differences.
