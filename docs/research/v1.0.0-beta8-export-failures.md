# Highlight export failure investigation

## Reproduction

Source: `washoi_dm2_duel_20261102_003024.shagdemo`, Player_7511 versus Ramen,
10-minute Washoi DM2 Duel. Settings: 3-minute reel, `noodlesoup_telefragged_me.mp3`,
song start 39 seconds. This is local browser export of a saved recording;
no live server or networking changes are involved.

The first attempt failed the audio listener agreement check at movie frame
4536. The next attempt in the same window failed reading `world` while binding
a StandardMaterial. Both failures reproduced before correction.

## Camera traversal

At frame 4536 both passes had source tick 35705.64126509857, segment 20,
the same playback speed and view direction. Both watched-player samples were
absent following an explosion kill. Camera positions differed along the view
axis, beyond the agreement tolerance. `WatchedDeathView.pose` integrated its
death-camera smoothing with `performance.now()`, making shader waits affect
the audio and encoded passes differently.

Use the existing `presentationNow()` clock. Export owns this clock; live play
retains wall time. Repeated draws at the same movie time have zero integration
delta. The strict audio agreement guard remains unchanged. A regression test
compares different wall-clock waits and repeated draws at equal movie times.
The exact full export then passed and produced a 439,433,434-byte MP4 before
the separate retry failure was corrected.

## Shared bullet-hole material

A shortened reproduction cancels the first preparation after 3,000 frames,
then retries in the same export window. The second preparation fails at source
tick 25144.166666666635, around movie frame 2186. Instrumenting the actual
StandardMaterial bind identifies `wallmark_batch` and `wallmark_shared_mat`.
Its shader pipeline has no initialized uniforms, and the material still has
shader hot swapping enabled despite the export's readiness owner disabling it
for materials in the new scene.

`HitscanEffects.clear()` retains shared batch materials for reuse. Wall-mark
material creation checked only whether a cached reference existed, allowing a
new export scene to borrow the previous scene's disposed material. The pellet
material checked scene identity but did not check same-scene material disposal.

Both caches now require membership in the current scene's materials. Wall marks
also check scene identity. Invalid cached materials are released and rebuilt;
valid ones remain shared. New wall-mark materials reset their initial tint flag.
Regression tests cover a new scene, disposal within the same scene, reuse across
effect clears, and one material per batch. The existing clear/fade tests remain
unchanged.
