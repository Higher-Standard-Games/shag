# Point traces on round patch caps and seams

Observed 2026-10-17 while validating SHAGGED round presets. This is a separate
runtime collision finding, not a remaining round-preset API requirement.

## Reproduction and evidence

The scene in `src/engine/editor/server/__tests__/RoundPatchCompile.test.ts`
compiles a capped cylinder, tube, cone and planar disk through MakeBSP/MakeLight.
It is enclosed in a structural room. All surfaces use `blx/blx_grid`, compiled
with SOLID contents. The native export format has been corrected and the BSP
contains the expected finite patch controls and upward cap normals.

With `SweepCollisionBackend.trace`, Babylon-space point sweeps
`{radius: 0, height: 0}` from height 160 to 16 gave these observed results:

- Cylinder center `(x=0, z=0)` missed its top at height 96. A noncentral
  `(x=8, z=3)` point hit it.
- Tube annular top at `(x=-100, z=3)` missed height 96.
- Disk center `(x=0, z=-128)` missed height 32.
- The cylinder-side point sweep from `(-80,48,0)` to `(80,48,0)` missed the
  expected contact at X=-48.
- A point sweep onto the cone at X=136 hit the sloped surface near height 72.

Finite-size sweeps `{radius: 1, height: 2}` hit the cap/side fixtures. The final
native regression verifies those contacts, the cone slope and passage through
the tube's hollow center. The small hull has the engine's asymmetric vertical
extent (-0.75/+1.25), which is included in expected contact heights.

Temporary diagnostic runs disabled facet spatial indexes and then visited all
BSP leaves. The cylinder point miss persisted. Cap faces had nonzero leaf
references and generated facets. This narrows the investigation toward facet
contact geometry or floating-point edge handling; it does not establish the
root cause. Temporary overrides/logging were removed from the final test.
Diagnostic output remains in `.cache/shagged-round-debug.log` on the test machine.

## Follow-up

1. Reduce the miss to a synthetic flat patch with translated coordinates and
   point, small-hull and player-hull traces at both interior and shared edges.
2. Compare generated and packed facet planes against the triangle's exact
   projected region, including near-axial normals and zero-volume intersections.
3. Check strict outside/enter/leave comparisons and numerical tolerances. Avoid
   changing gameplay contact margins without evidence.
4. Add regression coverage for retained contacts and nearby deliberate misses,
   then run the complete collision/server regression set and native fixture.

No physics code was changed in the round-preset checkpoint. Do not describe
point collision on these caps as verified or assume all patch surfaces fail.
