## Theme

The game manual now owns a VitePress theme: gold navigation rail, ink/cream
reading surfaces, violet edges, angular action buttons, Orbitron headings and
Rajdhani navigation. Inter remains the paragraph font for longer reading. It
defaults to dark and retains a light reading mode, keyboard focus indicators and
reduced-motion handling. Search/navigation use the standard VitePress theme.

Fonts are bundled from the engine's existing assets with their OFL licenses;
Google Fonts links were removed. Theme assets are local and available in the built
site. CSS includes narrow-screen rules; responsive appearance is not visually
verified because the browser connector returned no available browsers/apps.
