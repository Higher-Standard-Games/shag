Release date: October 23, 2026 (Europe/Helsinki).

The release keeps `src/engine/version.txt`, `package.json` and both root version
fields in `package-lock.json` at `1.0.0-alpha`. The next changelog stub is
`v1.0.0-alpha.2.md`; its version bump belongs to the beginning of that cycle.
`AGENTS.md` and the merge-and-release skill record this policy.

## Deployment preparation

The six texture banks were pre-uploaded on October 22 and their hashes were
rechecked in both production directories before release. Details and receipts
are in [the texture packaging investigation](./per_map_texture_packages.md).
The production SQLite online-backup service completed successfully. The served
game, indexes, deployment state and runbook were copied for rollback under
`/srv/washoi/backups/releases/v1.0.0-alpha-20261023/`.

The deployment timer is paused during publication and must be restored after
verification. The production deployment script now protects the existing
`data/washoi_textures.pk3` from rsync deletion, allowing older open clients to
finish loading assets. The new build/index still omit the master. The original
deployment script is preserved in the rollback directory. This compatibility
exclusion can be removed when support for older open clients is no longer
needed.

Production acceptance and final deployed commit IDs belong in the host's
`/srv/washoi.md` runbook. The prepared HTTPS acceptance script validates the
runtime manifest/index pair, all six package hashes, five map entries, all 20
shared billboard owners, entry scripts and a public lobby WebSocket handshake.
Full multiplayer playtesting and WebGPU acceptance are not release claims.
